# ДРАКОН-лист кода: слайды и ДРАКОН-лист урока «Защита аккаунтов» (6 класс)

Код — `slajdy.html` (колода: `vpered`, `pokazat`; построение: `postroit`), `drakon-list.html` (`prostoj`, `strokaTreka`, `pechatProstogo`); данные — `tekst.js`. Правило — ii-komanda `pravila/KOD-PO-GRAFOVSKI.md`, п. 4.

## Действия: учитель нажал «вперёд» на слайдах

```дракон
название: Вперёд
вопрос: на слайде есть скрытые по щелчку элементы?
  да:
    показать первый скрытый элемент
  нет:
    номер = номер + 1
    вопрос: номер больше последнего?
      да:
        номер = последний
      нет:
    показать слайд с номером
    вывод: номер и этап урока внизу
```

## Действия: строка карты треков на ДРАКОН-листе

```дракон
название: Строка трека
ввод: трек и сервис из tekst.js
вопрос: адрес листа кончается на #prostoj?
  да:
    вписать трек и сервис
  нет:
    оставить трек и сервис пустыми
вывод: строка — трек, сервис, пустые защита и риск
```

## Данные

```конспект
тема: Тексты урока в tekst.js
опр: Кадр комикса -> Это номер, этап, картинка и текст.
опр: Миф -> Это утверждение, вывод, почему и источник.
опр: Трек -> Это трек, сервис, защита и риск.
Конспект урока? -> три схемы через ---
Что проверить учителю? -> поле proverit
```

## Тест

- пример: открыт `drakon-list.html#prostoj` → в строке «Школа» вписаны «Школа» и «школьная почта, электронный дневник»
- контрпример: открыт `drakon-list.html` без `#prostoj` → в строке трека есть слово «Школа»
- пример: на слайде 2 скрыт один элемент, нажали «вперёд» → элемент виден, номер слайда тот же
- контрпример: на последнем слайде нажали «вперёд» → номер больше последнего
