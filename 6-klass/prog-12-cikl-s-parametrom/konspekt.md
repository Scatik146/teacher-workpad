# Повторение: задачи на цикл с параметром FOR

Конструкция:

```python
for ИМЯ_СЧЁТЧИКА in range(КОЛИЧЕСТВО_ПОВТОРЕНИЙ):
    ДЕЙСТВИЯ, КОТОРЫЕ НУЖНО ПОВТОРИТЬ
```

Для решения задач ниже количество повторений может быть задано числом или переменной. Переменную-счетчик можно использовать внутри цикла.

Решите задачи, используя цикл FOR и минимальное количество переменных.

1.  Пользователь вводит с клавиатуры 5 чисел, вычислите их сумму, найдите среднее арифметическое и выведите оба значения на экран. Для хранения введенного пользователем значения используйте только одну переменную.

2.  Определить количество трехзначных чисел, у которых сумма цифр равна некоторому числу N. Число N пользователь вводит с клавиатуры.

3.  Вывести на экран все числа в диапазоне от 100 до 999, у которых есть две одинаковые цифры. Для этого в программе, внутри цикла анализируем значение переменной, которую указали в качестве счетчика в цикле. Например, нам подходят числа 100, 101, 110.

4.  Составить программу, которая вычисляет значение квадрата числа n, которое пользователь вводит с клавиатуры, используя следующую закономерность:

1<sup>2</sup> = 1

2<sup>2</sup> = 1 + 3

3<sup>2</sup> = 1 + 3 + 5

4<sup>2</sup> = 1 + 3 + 5 + 7

n<sup>2</sup> = 1 + 3 + 5 + 7 + … + (2n -1)

5.  Пользователь вводит два числа n и m, вычислить произведение этих чисел, не используя умножение

6.  Найти сумму всех чисел в диапазоне от a до b. Числа a и b пользователь вводит с клавиатуры.

7.  Сумма цифр трехзначного положительного числа кратна 7, само число тоже делиться на 7. Выведите все такие числа на экран.

8.  Пользователь вводит целое положительное число. Определить и вывести на экран все делители этого числа.
