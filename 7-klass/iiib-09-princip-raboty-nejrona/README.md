- **Курс:** ИИ и информационная безопасность, 7 класс
- **Строка плана:** № 8–9 (приложение на два урока) — [plan/iiib-5-9.md](../../plan/iiib-5-9.md#7-класс)

## Что есть

- `index.html` — приложение «Нейрон-калькулятор»
- `slajdy.html` — слайды
- `print-a.html` — печать: форма А — протокол обучения

## Заметки

Файлы `02_*` — уроки строк 8–9 (номер сдвинут). Приложение — перцептрон, 5 режимов: один нейрон, слой, сеть из двух слоёв, обучение (коррекция весов по ошибке), заезд «Смекалка» (соревнование). Обучение и заезд учитель добавил позже; ранняя версия на 3 режима — в `9-klass/iiib-05-evolyuciya-modelej/`. Форма В была в двух вариантах: оставлен компактный (на одну страницу), второй отличался только размерами шрифта и ячеек. Оригиналы и прежние имена файлов — в истории git (коммит раскладки черновиков).
