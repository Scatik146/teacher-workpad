# ДРАКОН-лист: «Врата письменности» (приложение ученика)

Урок «Информация и данные. Языки и алфавиты», информатика, 7 класс. Код — `vrata.js` (действия), `tekst.js` (данные).
Правило листа — ii-komanda `pravila/KOD-PO-GRAFOVSKI.md`, п. 4.

## Действия: путь ученика (силуэт)

```дракон
название: Врата письменности
ветка: Заставка
  ввод: Ученик нажимает «В путь»
ветка: Врата 1
  для: каждого задания врат
    пока: Задание не решено?
      ввод: Ответ ученика
      если: Ответ верный?
        да:
          вывод: Отклик и следующее задание
        нет:
          если: Ученик просит подсказку?
            да:
              если: Искры остались?
                да:
                  Минус искра
                  вывод: Следующий шаг подсказки
                нет:
                  вывод: Подними руку
            нет:
              вывод: Пока не то
  вывод: Бронзовый ключ, звание «Читатель согласных»
ветка: Врата 2
  Те же задания и подсказки
  вывод: Серебряный ключ, звание «Расшифровщик алфавитов»
ветка: Врата 3
  пока: Не все четыре записи разобраны?
    ввод: Смысл извлекаем / нет правил / нет средств
  ввод: МАМА и MAMA — одна запись или две?
  ввод: Какой язык однозначен?
  пока: В строке нет слова «правил»?
    ввод: Ученик дописывает строку ДРАКОН-ГРАФ
    вывод: Схема рисуется сразу
  вывод: Золотой ключ, звание «Хранитель данных»
  ввод: Может ли алфавит быть из двух знаков?
  вывод: Все три врата открыты
```

## Данные: состояние пути

```конспект
тема: Что помнит приложение
класс: 7
Где ученик? -> S.ekran: start, vrata1, vrata2, vrata3
Что решено? -> S.resheno: ключ задания → да
Сколько подсказок? -> S.iskry: от 3 до 0
Какие ключи? -> S.klyuchi: бронзовый, серебряный, золотой
```

## Тест

- пример: врата 1, набрано «шлм» → «Верно: ШЛМ», открывается выбор слова
- пример: врата 1, выбран вариант «по этой записи сказать точно нельзя» → бронзовый ключ
- контрпример: врата 1, выбран «шалом» → ключа нет, отклик «Нет. Подумай ещё»
- пример: врата 3, строка «Это информация, записанная по правилам.» → золотой ключ
- контрпример: врата 3, строка «Это буквы» → подсказка «Вспомни ШЛМ…», ключа нет
