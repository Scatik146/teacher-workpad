## Решения автора

- Вариант 1 «Врата письменности»: интерактивный рассказ в стиле TED, без практики сюжет не идёт.
- Данные — это информация, которая имеет смысл, если известны правила его извлечения и есть средства для этого (формулировка учителя 23.11). В тетрадь: «Это информация, записанная по правилам»; смысл — когда знаем правила и есть средства.
- Дерево письменности вместо линии; глаголица — отдельная ветка. Правило: «новый язык берёт готовый алфавит и добавляет знаки».
- Генератор ДРАКОН-ГРАФ на уроке — одна строка в приложении; три схемы целиком — дома по листу 2.
- Бумага — 2 листа: алфавиты (ДЗ) и ДРАКОН-лист. Экранов-врат — 3.
- Врата 2 (решение 23.11): фразы, а не одно слово — глаголица и анбур по очереди; число — словом («девятнадцать»), цифры — «верно по смыслу».
- Анбур — личная нить рассказчика (учитель — коми-пермяк); урок в Подмосковье, «родной край» детей не говорим.
- «Более 100 языков на кириллице» — не говорим; только «десятки языков от Балкан до Тихого океана».
