## Решения автора (кратко)
- Реального ИИ на уроке нет: ответы помощников, мастер и обмен между системами — заранее продуманный сюжет. Учитель почти молчит — всё в приложении.
- Сюжет: Светляку дали не его задачу → второй ИИ → под капотом несколько моделей со своей специализацией. Нет глупых и умных ИИ.
- Обмен между моделями — общий текстовый файл; кто не читает файлы — через посредника (человек или программа).
- Доска: «Готовность мастерской» — номер → блок / «Светляк собран» / «+ дублёр»; общий прогресс, без сравнения бригад.
- Конспект ДРАКОН-ГРАФ: переписать в тетрадь → официальный генератор в новой вкладке → схема рядом с текстом. Исправление ДРАКОН-схемы — в приложении.
