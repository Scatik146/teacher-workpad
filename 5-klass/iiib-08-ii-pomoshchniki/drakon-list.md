# ДРАКОН-лист к приложению «Светляк и его команда»

Код — `index.html` (слова по-фортовски), данные — `tekst.js`. Ниже — главное слово «Стола заказов»: выполнить шаг заказа.

```дракон
название: Выполнить шаг заказа
ввод: Выбранный вариант
вопрос: Вариант верный?
  да:
    Дописать строку в общий файл
    Перейти к следующему шагу
    вопрос: Шаги заказа кончились?
      да:
        Перейти к следующему заказу
      нет:
  нет:
    Показать отказ модели
Сохранить смену и перерисовать экран
вывод: Экран «Стол заказов»
```

```конспект
тема: Как устроен «Стол заказов»?
класс: 5
Где модели оставляют работу? -> В общем файле.
Кто передаёт работу помощнику без файлов? -> Посредник.
Какую модель зовёт шаг? -> Ту, что стажёр поставил на этот вид задач.
```

пример: верный вариант → в общем файле на одну строку больше, номер шага +1
контрпример: неверный вариант → общий файл не меняется, на экране отказ модели
