Глоссарий учителя

Пиксель: одна клетка таблицы, в ней лежит одно число.
Матрица: таблица чисел, представляющая изображение.
Разрешение: количество строк и столбцов в матрице (ширина × высота).
Свёртка: метод поиска примитивов (окно 3×3, скользящее по матрице).
Примитив: простейший элемент (грань, угол, пятно), из которых складываются сложные признаки.
Типографская атака: внесение физических изменений в объект (наклейка, изолента), сбивающих с толку компьютерное зрение.
Галлюцинация: ситуация, когда машина выдумывает ответ, как привиделось во сне; при этом часто говорит увереннее на ~34%.
Бенчмарк: стандартизированный тест для оценки качества модели (VLMCountBench, SpaceCast-Bench).
Обязательные акценты Блока 1:
1. Четыре глагола: распознавать, размышлять по правилам, планировать, создавать новое.
2. Python — главный язык ИИ.
3. Перцептрон учился на своих ошибках.
4. Начинаем с распознавания изображений, потому что зрение — главный канал человека.
Закреплённое размещение языков:
Python — «Распознавать» (главный язык ИИ сегодня), «Планировать» (маршруты и игровые боты), «Создавать новое» (генерация картинок и текстов). Замануха: «на Python вы однажды напишете своего ИИ сами».
Julia — «Распознавать»: язык сверхбыстрых научных расчётов — моделирование лекарств, климата.
LISP — «Размышлять по правилам»: исторический язык ИИ, на нём строили «рассуждающие» программы.
Prolog — «Размышлять по правилам»: язык экспертных систем, ответы через цепочки «если — то».
Haskell — «Размышлять по правилам»: язык строгих правил, ошибка почти невозможна, поэтому его берут банки.
