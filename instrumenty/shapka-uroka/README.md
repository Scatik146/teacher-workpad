# Форма «Шапка урока»

Инструмент учителя: одна страница вместо интервью Алисы на шаге 1 (10–12 сообщений). Поля — по разделу [3] промта Алисы v7.4 (ii-komanda `algoritm/alisa-v7-4-B.md`, в `-A.md` то же самое), плюс школа, учебник и личное учителя.

- Страница скрытая: на сайте на неё нет ссылок, в каталоге (`lessons.js`, `README.md`) её нет, поисковикам закрыта (`noindex`). Открывать по прямому адресу.
- `index.html` — разметка, `stil.css` — оформление (шрифты только с сайта: Nunito из `lib/fonts/`, PT Mono из `lib/drakon-graf/fonts/`), `dannye.js` — поля, варианты, значения по умолчанию, `shapka.js` — действия (по-фортовски), `drakon-list.md` — ДРАКОН-лист и пополнение словаря.
- Ответы запоминаются в `localStorage` этого браузера (ключ `twp-shapka-uroka`); кнопка «Очистить» возвращает значения по умолчанию.
- Шаблоны: «Сохранить как шаблон» — текущие ответы под именем (ключ `twp-shapka-uroka-shablony`); выбор в списке подставляет их. Дата, время, тема, место в блоке, «до» и «после» в шаблон не входят (у полей `svoyo: true` в `dannye.js`). Шаблоны живут в браузере, где сохранены: на другом компьютере их нет.
- «Скопировать шапку» — текст блоком от `=== ШАПКА УРОКА …` до `=== КОНЕЦ ШАПКИ ===`; пустые поля помечены «не заполнено» — Алиса спрашивает только их.
- Раздел 9 «Наши ресурсы» — галочки с адресами файлов (12 ресурсов по проходу 23.11 по всем репозиториям; полный список с описанием — ii-komanda `komanda/RESURSY.md`) и «ещё ресурсы». Алиса эти файлы не читает: она переносит раздел в «Итог для Claude», а читает их Claude (или тот, кто его заменяет) на экспертизе и сборке. Новый ресурс добавлять в `dannye.js`, раздел 9.
- Ctrl+Alt+M — переход к разделу и «заполнить пустое примером» (для проверки).
- Поменялся раздел [3] промта — править только `dannye.js`.
- **Свои предметы** (23.11): у поля «Предмет» — «+ свой» (сокращение и классы, например `ПРОГ-5-7`) и «− убрать свой» (готовые из `dannye.js` не убираются). Свои живут в этом браузере (ключ `twp-shapka-uroka-predmety`). Готовый список дополнен `РПЗ-10-11` — «Информатика: решение практических задач», 10–11 кл., ИТ-профиль.
- **Урок из плана** (23.11): блок в шапке страницы. Курс выбирается по предмету и классу (`planKursy` в `dannye.js`; у своего предмета — вручную), урок — из `plan/<курс>.md` с флагом готовности ✅ ✏️ 📝 —. Выбор заполняет тему, «место в блоке» (номер, тип и неделя по плану, готовность и папка), «что было до» и «что после». Данные — `plan/plan-dannye.js`: собирается `python3 -I tools/plan_v_js.py` из md плана, руками не правится.
- **План «на деле»** (24.11): `plan/na-dele/*.md` тоже собираются (курсы «На деле: …», в `planKursy` — первыми). Выбор урока заполняет ещё журнальную тему и статус (в «месте»), итог прошлого урока (в «до»), «Обязательно на уроке» — «Содержание урока» и «Опора:» из «Углубления» без кодов пунктов (нет их — поле не трогается), дату «дд.мм» (год — `planGod` в `dannye.js`). Нет столбца «урок» — готовность «? не указано».
- **«1. Скопировать промт»** (24.11): копирует промт Алисы v7.4-Б целиком; потом «2. Скопировать шапку». Промт — `promt-dannye.js`, собирается из ii-komanda: `python3 -I tools/promt_v_js.py ../ii-komanda` (версия — `FAJL` в программе), руками не правится.
- **Приёмы и ресурсы — свёрнуты** (23.11, просьба учителя): в форме видна сводка «Выбрано: N — …» и кнопка «Выбрать…»; список открывается окном, столбиком, с прокруткой. Приёмы П-1…П-22 — из каталога (ii-komanda `komanda/chernoviki/teacher-workpad/razbor-vse-uroki/README.md`); в шапку идут только отмеченные, с адресом образца.
- **Свои механики → в список приёмов:** кнопка «Внести мои механики в список приёмов» (раздел 7) или «+ свой приём» в окне. Новые приёмы живут в этом браузере (ключ `twp-shapka-uroka-priemy`), сразу отмечены и идут в шапку с пометкой «придумано учителем — Claude: обобщить и внести в каталог». Claude на экспертизе или сборке обобщает их и вносит в каталог и в `dannye.js` (поле `priemy`) — тогда они видны во всех браузерах.
