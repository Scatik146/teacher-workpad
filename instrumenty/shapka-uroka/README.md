# Форма «Шапка урока»

Инструмент учителя: одна страница вместо интервью Алисы на шаге 1 (10–12 сообщений). Поля — по разделу [3] промта Алисы v7.4 (ii-komanda `algoritm/alisa-v7-4-B.md`, в `-A.md` то же самое), плюс школа, учебник и личное учителя.

- Страница скрытая: на сайте на неё нет ссылок, в каталоге (`lessons.js`, `README.md`) её нет, поисковикам закрыта (`noindex`). Открывать по прямому адресу.
- `index.html` — разметка, `stil.css` — оформление (шрифты только с сайта: Nunito из `lib/fonts/`, PT Mono из `lib/drakon-graf/fonts/`), `dannye.js` — поля, варианты, значения по умолчанию, `shapka.js` — действия (по-фортовски), `drakon-list.md` — ДРАКОН-лист и пополнение словаря.
- Ответы запоминаются в `localStorage` этого браузера (ключ `twp-shapka-uroka`); кнопка «Очистить» возвращает значения по умолчанию.
- Шаблоны: «Сохранить как шаблон» — текущие ответы под именем (ключ `twp-shapka-uroka-shablony`); выбор в списке подставляет их. Дата, время, тема, место в блоке, «до» и «после» в шаблон не входят (у полей `svoyo: true` в `dannye.js`). Шаблоны живут в браузере, где сохранены: на другом компьютере их нет.
- «Скопировать шапку» — текст блоком от `=== ШАПКА УРОКА …` до `=== КОНЕЦ ШАПКИ ===`; пустые поля помечены «не заполнено» — Алиса спрашивает только их.
- Раздел 9 «Наши ресурсы» — галочки с адресами файлов (ДРАКОН-ГРАФ, дракон-схемы, двоичная и троичная логика, словарь, древние письменности) и «ещё ресурсы». Алиса эти файлы не читает: она переносит раздел в «Итог для Claude», а читает их Claude (или тот, кто его заменяет) на экспертизе и сборке. Новый ресурс добавлять в `dannye.js`, раздел 9.
- Ctrl+Alt+M — переход к разделу и «заполнить пустое примером» (для проверки).
- Поменялся раздел [3] промта — править только `dannye.js`.
