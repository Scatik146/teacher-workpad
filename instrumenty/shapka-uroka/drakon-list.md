# ДРАКОН-лист: форма «Шапка урока»

Код — `shapka.js` (действия), данные — `dannye.js` (`SHAPKA_DANNYE`: разделы, поля, варианты, значения по умолчанию по [3] промта Алисы v7.4). Правило — ii-komanda `pravila/KOD-PO-GRAFOVSKI.md`, п. 4.

## Действия: открыли страницу

```дракон
название: Запуск формы
ввод: сохранённые ответы из localStorage
значения = по умолчанию из dannye.js
для: for pole in vse_polya
  вопрос: поле есть в сохранённых?
    да:
      значение поля = сохранённое
    нет:
нарисовать разделы 1–8
вывод: готовая шапка и счётчик пустых полей
подключить меню Ctrl+Alt+M
```

## Действия: учитель изменил поле

```дракон
название: Обновить шапку
ввод: событие в форме
прочитать все поля формы в состояние
записать состояние в localStorage
для: for razdel in razdely
  выбор: вид первого поля раздела
    вариант: список
      строка = номер, раздел, механики по номерам
    вариант: галочки
      строка = номер, раздел, артефакты да/нет и число экранов
    вариант: ресурсы
      строка = номер, раздел, отмеченные ресурсы с адресами и «ещё ресурсы»
    вариант: прочие
      строка = номер, раздел, «поле: значение» через «; »
вывод: заголовок, правило для Алисы, строки 1–8, конец шапки
```

## Действия: «Скопировать шапку»

```дракон
название: Скопировать шапку
обновить шапку
вопрос: есть буфер обмена браузера?
  да:
    записать текст в буфер
  нет:
    выделить поле «Готовая шапка» и копировать
вопрос: получилось?
  да:
    вывод: «Скопировано»
  нет:
    вывод: «Выделите текст справа и нажмите Ctrl+C»
```

## Действия: «Очистить»

```дракон
название: Очистить форму
вопрос: учитель подтвердил?
  да:
    стереть ответы из localStorage
    значения = по умолчанию из dannye.js
    нарисовать разделы 1–8
    вывод: «Форма очищена»
  нет:
```

## Действия: шаблоны

```дракон
название: Шаблон
выбор: что нажали
  вариант: Сохранить как шаблон
    обновить шапку
    ввод: имя шаблона
    вопрос: имя пустое?
      да:
      нет:
        шаблон = значения полей без своих полей урока
        записать шаблон в localStorage под этим именем
        вывод: «Шаблон сохранён»
  вариант: выбрали шаблон в списке
    значения = значения + шаблон
    нарисовать разделы 1–8
    вывод: «Шаблон подставлен — допишите урок»
  вариант: Удалить
    вопрос: учитель подтвердил?
      да:
        стереть шаблон из localStorage
      нет:
```

## Данные

```конспект
тема: Шапка урока — разделы по [3] промта v7.4
связка: Поля | По умолчанию
Раздел 1: класс и работа -> предмет, класс, возраст, человек, работа | пусто
Раздел 2: коллектив -> успешность, управляемость, дифференциация, особенности | 3, 3, смешанная
Раздел 3: урок -> дата, время, минут, тема, тип, место, до, после | 40, открытие нового знания
Раздел 4: кабинет -> техника учеников и учителя, интернет, печать, мебель | A4 книжная
Раздел 5: школа и учитель -> регион или город, учебник, личное | личное: нет
Раздел 6: рамки -> обязательно, нельзя, сюжет | пусто
Раздел 7: механики -> нумерованный список | пусто
Раздел 8: артефакты -> галочки, у приложения число экранов | все нет
Раздел 9: наши ресурсы -> галочки с адресами файлов, ещё ресурсы | ничего, нет
```

## Тест

- пример: выбрать предмет ИНФ-7-9Б и нажать «Скопировать шапку» → в буфере строка «1) Класс и работа. Предмет: ИНФ-7-9Б; …», пустые поля помечены «не заполнено»
- пример: перезагрузить страницу → предмет и класс остались
- пример: сохранить шаблон с предметом ИИИБ-1-4, очистить, вписать тему «Новая тема», выбрать шаблон → предмет ИИИБ-1-4, тема «Новая тема»
- пример: отметить «троичная логика» → в шапке «9) … - троичная логика (трит) — ii-komanda logika/svod.md, …»
- контрпример: ничего не отмечено → в разделе 9 «не заполнено»
- контрпример: выбрать шаблон → тема заменилась темой из шаблона
- контрпример: после «Очистить» и перезагрузки → предмет ИНФ-7-9Б остался
