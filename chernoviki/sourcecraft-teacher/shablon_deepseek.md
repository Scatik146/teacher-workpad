## 1. Параметры группировки решений

## 2. Этапы урока
Для каждого этапа укажи:
- **Название и хронометраж** (сумма всех этапов = [МИНУТ] минут)
- **Цель этапа**
- **Формат работы** (фронтальная / парная / групповая / индивидуальная)
- **Ключевые моменты** — что происходит, какой методический приём используется
- **Формулировки для учителя** — как объяснить простым языком для данного возраста
- **Связь с предметом** — точки пропедевтики ИИ / инфобеза / информатики (если применимо)
- **Деятельность ученика** — что конкретно делают дети

Этапы должны включать (адаптируй состав под тип урока):

1. Организационный момент
2. Мотивация и актуализация знаний
3. Изучение нового материала
4. Физкультминутка / динамическая пауза (если возраст ≤ 10 лет)
5. Практическое закрепление
6. Рефлексия и итог
7. Домашнее задание (если предусмотрено)

Учитывай уровень успешности [УСПЕШНОСТЬ]:

- 3 → базовые понятия без перегруза, 1–2 шага рассуждения
- 4 → расширение, самостоятельный поиск, частично-поисковые задания

# Правила

- **Возраст [ВОЗРАСТ] лет:** формулировки короткие, понятные, без сложных терминов. Для 6–8 лет — максимум наглядности и игровых форм. Для 9–11 — можно вводить простые схемы и таблицы. Для 12+ — аналитика, дискуссии, проекты.
- **Управляемость [УПРАВЛЯЕМОСТЬ]:**
  - 2 → смена деятельности каждые 3–5 минут, короткие блоки, больше интерактива и игр
  - 3 → смена каждые 5–7 минут, чередование фронтальной и парной работы
  - 4 → блоки по 7–10 минут, допустима самостоятельная работа
  - 5 → длинные блоки, меньше удержания внимания, больше автономии
- **Успешность [УСПЕШНОСТЬ]:** не перегружай, но и не упрощай до примитива. Один шаг рассуждения для уровня 3.
- **[МИНУТ] минут:** реалистичный хронометраж. Если время короткое — убирай этапы, не ужимай каждый до минуты.
- Каждый этап должен иметь чёткий образовательный результат.
- Не дублируй материал из шага 2 — используй его как основу для решений.
- Не придумывай факты, которых нет в материале — если не хватает, так и скажи.
- Без компьютерного практикума, если на рассадку за ПК нет времени (урок ≤ 30 минут).
