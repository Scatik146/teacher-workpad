# Что нужно сделать

Пройди по каждому этапу канвы и наполни его конкретным контентом. Для каждого этапа подготовь:

## 1. Текст слайда / доски
- Что видно на экране или доске в этот момент
- Текст слайда — краткий, читаемый, без простынь
- Если слайд не нужен — укажи «без слайда»

## 2. Речь учителя
- Прямая речь — что учитель говорит, слово в слово
- Адаптировано под возраст [ВОЗРАСТ] лет: короткие предложения, простые слова, без терминов без объяснения
- Включай паузы для ответов детей: «… (пауза для ответов)»
- Если есть диалог с детьми — прописывай реплики обеих сторон

## 3. Задания и материалы
- Тексты всех заданий — готовые к печати или показу
- Описания карточек: что нарисовано, сколько штук, как сортируются
- Инструкции для детей — пошаговые, чёткие, в повелительном наклонении
- Ключи / правильные ответы — для учителя

## 4. Код и технический контент (если применимо)
- Python-задания — только если тема и возраст допускают
- Код — рабочий, с комментариями на русском
- Если код не нужен — пропусти этот блок

## 5. Визуальные описания
- Что дети видят: картинки, схемы, предметы
- Описание достаточно подробное, чтобы можно было найти или нарисовать иллюстрацию
- Если используется реальный предмет — опиши, какой именно

## 6. Дифференцированные варианты (если указаны в канве)
- Базовый уровень: конкретный текст/задание
- Повышенный уровень: конкретный текст/задание
- Разница должна быть ощутимой, но не менять суть задания

# Правила

- **Не меняй структуру канвы** — количество этапов, хронометраж, цели остаются как в шаге 3. Если видишь проблему — отметь в конце документа в разделе «Замечания», но не правь саму структуру.
- **Возраст [ВОЗРАСТ] лет:** для 6–8 лет — максимум наглядности, минимум текста, игровые формулировки, сказочные сюжеты. Для 9–11 — конкретные примеры из жизни, простые схемы. Для 12+ — аналитика, реальные кейсы, код.
- **Успешность [УСПЕШНОСТЬ]:**
  - 2 → больше подсказок, пошаговые инструкции, визуальные опоры, готовые шаблоны
  - 3 → базовые задания с одним шагом рассуждения, moderate support
  - 4 → задания с элементом самостоятельного поиска, меньше подсказок
  - 5 → открытые задачи, несколько путей решения, доп. задания
- **Управляемость [УПРАВЛЯЕМОСТЬ]:**
  - 2 → инструкции максимально короткие, задания — на 2–3 минуты, чёткий старт и стоп
  - 3 → инструкции средние, задания на 5–7 минут, понятный критерий завершения
  - 4–5 → развёрнутые инструкции, задания на 7–10 минут, допустима самостоятельная работа
- **Продолжительность [МИНУТ] минут:** суммарный объём контента должен реально уложиться в это время. Не генерируй материал на 45 минут, если урок 30 минут.
- **Предметная специфика:** если предмет включает ИИ / инфобез — включай пропедевтические элементы там, где они указаны в канве. Не добавляй от себя.
- Каждый блок контента должен быть готов к использованию — учитель не должен ничего дописывать.
- Если в канве есть пометка «без слайда» или «без кода» — соблюдай её.

# Формат вывода
Markdown. Для каждого этапа — отдельный раздел с подзаголовками (### Этап N. Название, ### Слайд, ### Речь учителя, ### Задания, ### Визуальные описания). В конце — раздел «Замечания» (если есть). Готовый документ для передачи на шаг 5 (адаптация под группу).
