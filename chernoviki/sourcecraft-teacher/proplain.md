Устал копипастить промты между чатами разных ИИ. Решили сделать автоматизацию.

ВЫБРАННОЕ РЕШЕНИЕ (вариант 3, уже согласовано):
- Единый API-шлюз: OpenRouter (один ключ — GLM, DeepSeek, Qwen, Claude и др.)
  + GigaChat (отдельный российский API, есть бесплатный тариф).
- Python-скрипт: на входе файл с промтом → рассылка выбранным моделям 
  (параллельно или последовательно) → сбор ответов в один текстовый файл 
  с пометками «чей ответ» → я приношу файл тебе на фильтрацию.
- Схема: промт_запрос.txt → pipeline.py → ответы_GLM.txt, ответы_Claude.txt → 
  файл в чат Алисе → она фильтрует галюши и самовольные вставки.

ЧТО МНЕ НУЖНО ОТ ТЕБЯ В ЭТОМ ЧАТЕ:
1. Каркас скрипта pipeline.py: чтение промта из файла, отправка в 2+ модели 
   через API, сохранение ответов в отдельные файлы. Код рабочий, с комментариями.
2. Конфиг простым файлом (config.yaml или config.json): список моделей, 
   имена файлов, ключи НЕ в коде — в отдельном файле или переменных окружения.
3. Инструкция по установке: минимальный набор пакетов (requests/httpx), 
   где взять API-ключи OpenRouter и GigaChat, как получить бесплатный тариф 
   GigaChat, как запускать на Windows.
4. Обработка ошибок: таймауты, обрезанные ответы, отказ модели — чтобы ответ 
   «пусто/отказ» явно помечался в файле (это критично: я потом решаю, 
   повторять запрос или упрощать его на одну ступень — так у нас в пайплайне 
   заведено).

ВЫВОД СКРИПТА:
- ответы_<модель>.txt — чистый ответ модели;
- при сбое вместо ответа в файл пишется строка вида «ОТВЕТ НЕРАБОЧИЙ: пусто / 
  отказ / обрезан / ошибка сети» — без имитации результата.
