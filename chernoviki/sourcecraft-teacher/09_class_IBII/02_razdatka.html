Практическая работа с ИИ

№ Поле Что записать
1 Мой промпт Полный текст запроса к нейросети
2 Сервис GigaChat / YandexGPT (подчеркните)
3 Ответ модели 2–3 предложения из ответа
4 Факт для проверки Один факт, дату или имя для перепроверки
5 Источник проверки Ссылка или название источника
6 Результат Подтвердился / ошибочный (галлюцинация)
7 Вывод Полезный / галлюцинация / много «воды»
Базовый: строки 1–4 обязательны, 5–7 по желанию. Повышенный: все строки + анализ нарушений ограничений.

Схема-опорка: Как работает ИИ

Как ИИ читает текст (NLP)

1
Токенизация
«Нейросеть» → «Нейро» + «сеть»
2
Лемматизация
«бежал» → «бежать»
3
Векторизация
Слова → числа (координаты смысла)

Три этапа обучения LLM

1
Pre-train
Читает интернет, учит язык
2
Fine-tune
Учится понимать инструкции
3
RLHF
Люди оценивают ответы
