## Цель и планируемые результаты {#cel-i-rezultaty}

**Цель 1.** Научить структурировать документ в Markdown: оглавление, сноски, ссылки на литературу в отдельном файле, вставка растрового изображения.

**Цель 2.** Научить переводить табличные данные между Markdown и табличным редактором и экспортировать диаграмму в SVG.

**Метапредметный результат.** Перевод информации из одной знаковой системы в другую: одни данные существуют как таблица редактора, как текст Markdown, как CSV и как векторный рисунок.

**Ученик умеет:** строить оглавление ссылкой на заголовок; оформлять сноску; ссылаться на источник из другого файла; вставлять картинку; переносить таблицу в редактор и обратно; строить график и выгружать его в SVG.

**Ученик знает:** растр и вектор; что CSV — текстовый формат с разделителем; что кодировка и региональные настройки ломают импорт; что поведение разметки зависит от того, чем её рендерят.

**Получит возможность:** увидеть, что один и тот же текст по-разному рендерится в разных редакторах (`[TOC]`, инлайн-сноски, `{#якорь}`).

## Ход урока {#hod-uroka}

### Блок 1. Структура (3–11)

Учитель показывает на эталонной папке, ученики повторяют в своих.

**Оглавление.** Ссылка ведёт на заголовок, якорь задан явно и латиницей:

```markdown
## Оглавление

1. [Введение](#vvedenie)
2. [Результаты](#rezultaty)
```

Правило для якорей: латиница, строчные, дефис. Авто-якорь из кириллического заголовка каждый редактор строит по-своему, поэтому в ученической работе он должен быть задан руками.

**Сноска.**

```markdown
Метод надёжен[^1], но требует калибровки.

[^1]: Калибровка по эталону №4.
```

**Ссылка на литературу в соседнем файле.**

```markdown
См. [Иванов, 2021](bibliography.md#ivanov-2021).
```

Открытие соседнего файла работает почти везде, докрутка до якоря внутри него — нет. Это проговаривается вслух, а не прячется.

**Картинка.**

```markdown
![Рис. 1. Погрешность](chart.jpg)
```

Растр — пиксели, при увеличении сыпется. Вектор — формы и кривые, масштабируется свободно.

**Одна строка про `[TOC]`.** Показать, что StackEdit собирает оглавление сам по метке `[TOC]`, а при переносе файла на GitHub та же метка остаётся текстом. Вывод для записи в тетрадь: оглавление руками — не архаика, а единственное, что переезжает вместе с файлом.

### Блок 2. Таблица (11–23)

**Рамка.** Одни данные — три артефакта: таблица редактора, текст Markdown, файл CSV.

Ученик заводит таблицу 6 строк на 3 столбца с правдоподобными данными.

| Переход | Что делать | Ловушка |
|---|---|---|
| Таблица → Markdown | Копировать столбцы в одну колонку, затем «Текст по столбцам», разделитель — pipe | Палки по краям дают два пустых столбца; строку `|---|` удаляем руками |
| Excel → Markdown | Служебный столбец: `="| "&A1&" | "&B1&" | "` | Строку выравнивания дописывать руками |
| Calc → Markdown | «Сохранить как CSV», разделитель — pipe | Кодировка UTF-8 **с BOM**, иначе кириллица встанет палками |

Точный путь к пункту «Текст по столбцам» учитель показывает на своей версии и вписывает в карточку.

### Блок 3. SVG (23–27)

Каждый ученик делает сам: выделение данных → график → правый клик по диаграмме → экспорт в SVG → открыть файл в браузере.

Три проверки на экране: рамка не обрезана, подписи осей на месте, числа на графике совпадают с таблицей.

Объезд, если Calc съел подписи: скопировать диаграмму в Draw и экспортировать оттуда.

### Взаимная проверка (27–32)

Папка копируется на флешку соседа, каждый открывает чужую папку у себя. Если рендера нет — пункты 1 и 2 чек-листа проверяются по исходному тексту, динамически их проверяет учитель на своём ноутбуке.

## Карточка ученика {#kartochka-uchenika}

1. Предложение синхронизировать или войти — отказ.
2. Якорь пишем руками, латиницей: `{#ivanov-2021}`.
3. Картинка и файлы — в одной папке, имя файла с кириллицей не использовать.
4. CSV: UTF-8 **с BOM**, разделитель — pipe.
5. Экспорт графика в SVG делаешь сам и открываешь его в браузере.
6. Экспорт папки на флешку после каждого этапа.
7. Сдача: папка → архив → флешка → открытие на ноутбуке учителя при тебе.

Если опередил: добавь выравнивание столбцов `:---:`, вторую картинку с подписью, вторую сноску.

Папка, в ней: `00-toc.md`, `01-vvedenie.md`, `02-rezultaty.md`, `bibliography.md` на 3 источника, одна картинка `jpg`.

**Последний шаг обязательный:** экспорт из StackEdit в реальную папку на флешке. Работа, оставшаяся в браузере, к сдаче не существует.

## Чек-лист приёмки {#chek-list-pryomki}

1. Ссылка ведёт в `bibliography.md` и докручивается до нужного пункта.
2. Сноска есть и её текст что-то объясняет.
3. Картинка отображается, файл лежит рядом.
4. В CSV нет пустых крайних столбцов и мусорной строки.
5. SVG открывается в браузере, подписи осей видны.
