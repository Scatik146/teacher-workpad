# HTML-презентация — ТЗ для Qwen

## ВАЖНО
Не делай технологическую карту, конспект, печатные материалы или анализ. Нужен только **один HTML-файл** — презентация из 6 слайдов. Весь текст готов ниже — сверстай в HTML.

---

## ТРЕБОВАНИЯ К ВЁРСТКЕ

- Один HTML-файл, открывается в браузере двойным кликом
- Чистый HTML+CSS+JS в одном файле, без внешних библиотек и CDN
- Тёмный фон (#1a1a2e или аналогичный), светлый текст (#e0e0e0 или белый)
- Крупный шрифт: заголовки слайда — минимум 40px, основной текст — минимум 24px
- Переключение слайдов: стрелки клавиатуры (ArrowLeft/ArrowRight), пробел, клик мышью
- Номер слайда в нижнем углу (например, «3 / 6»)
- Подсказка по навигации на первом слайде, мелким шрифтом
- Минимум анимации — простой fade или slide
- Без логотипов, без изображений, без внешних ресурсов
- `@media print` — скрыть навигацию, показать все слайды на одной странице

## ТЕКСТЫ СЛАЙДОВ

### Слайд 1: Титульный

**Заголовок (крупно, по центру):**
Мини-проект: «Разработка паспорта учебного проекта»

**Подзаголовок:**
Тема: Оформление информационных стендов

**Дата:**
17.09.2026

*(Мелким шрифтом внизу: «Переключение — стрелки ← → или пробел»)*

---

### Слайд 2: Задача

**Заголовок слайда:**
Задача

**Три пункта, каждый в отдельном блоке с лёгкой подсветкой:**

1. **3 фетровые доски:** История, Труд, Информатика
2. **Цель:** создать структуру с зонами для материалов, работ и новостей
3. **Формат:** Заголовок + 3 якорные зоны + 1–2 зоны по выбору

---

### Слайд 3: Карта контроля (5 баллов)

**Заголовок слайда:**
Карта контроля — 5 баллов

**Нумерованный список, каждый пункт с указанием баллов:**

1. Соблюдение ТБ — 1 балл
2. Организация рабочего места — 1 балл
3. Паспорт заполнен (все 8 пунктов) — 1 балл
4. Этапы отражены последовательно — 1 балл
5. Аккуратность (нет грязи, зачёркиваний) — 1 балл

---

### Слайд 4: Сохранение файлов

**Заголовок слайда:**
Сохранение файлов

**Четыре пункта:**

- **Сетевая папка** (ярлык на рабочем столе)
- **Имя файла:** `ГруппаX_Зона` (например, `Группа1_Заголовок`)
- **Дедлайн:** 2 минуты
- **Резерв:** флешка

*(Имя файла — моноширинным шрифтом, в рамке-блоке)*

---

### Слайд 5: Тайминг урока

**Заголовок слайда:**
Тайминг урока

**Пять блоков, каждый с временным диапазоном слева и описанием справа:**

| Время | Этап |
|---|---|
| 0–10 мин | Выбор, эскиз, паспорт (п. 1–4, 6) |
| 10–16 мин | Цифровой цех (набор, сохранение) |
| 16–23 мин | Печать и резка рамок |
| 23–31 мин | Сухая раскладка и монтаж |
| 31–40 мин | Уборка, паспорт (п. 8), приёмка |

---

### Слайд 6: Рефлексия (Светофор)

**Заголовок слайда:**
Рефлексия

**Три строки, каждая с цветным кружком слева:**

- 🟢 **Зелёный:** Паспорт заполнен, доска оформлена, могу объяснить выбор
- 🟡 **Жёлтый:** Есть вопросы по структуре или не всё успели
- 🔴 **Красный:** Тема вызывает затруднения

*(Цветные кружки — через CSS: зелёный #4CAF50, жёлтый #FFC107, красный #F44336. Не через эмодзи, а через `border-radius: 50%` с фоновым цветом.)*
