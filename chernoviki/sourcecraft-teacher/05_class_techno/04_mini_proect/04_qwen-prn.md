# Печатные материалы — ТЗ для Qwen

## ВАЖНО
Не делай технологическую карту, конспект, презентацию или анализ. Нужен только **один HTML-файл** — печатные материалы на 6 страницах. Весь текст готов ниже — сверстай в HTML.

---

## ТРЕБОВАНИЯ К ВЁРСТКЕ

- Один HTML-файл, открывается в браузере
- Чистый HTML+CSS в одном файле, без внешних библиотек и CDN
- Белый фон, чёрный текст
- Каждый материал — на отдельной странице через `page-break-after: always`
- `@media print` — скрыть навигацию, поля 1.5 см, формат A4
- Шрифт: основной — 12pt, заголовки — 16–18pt, карточки — 10–11pt
- Чёрно-белая печать (цвет не нужен, но допустимы серые заливки для выделения)
- Без изображений, без логотипов, без внешних ресурсов
- Простая навигация по страницам: кнопки «Назад / Дальше» или прокрутка (только на экране, скрыть при печати)
