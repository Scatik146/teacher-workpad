# Алгоритм разработки урока с ИИ-ассистентами (v8.4, финальная)

Статус: версия для запуска.

Четыре несущих правила:
1. Урок готовится только в вечер перед проведением. Впрок — только сырьё модуля.
2. Тип урока определяет тема (вывод §5.1), не день недели и не воля автора. День даёт бюджет, тема даёт тип, перерасход уходит в пол.
3. Единственный источник времени — §9. §5 и §1.6 из неё выводятся, отдельно не правятся.
4. Полный А2 требует прожитого мышления по модулю (ВС-2); если его нет, тип = А2-экспресс с долгом. Разница — состояние модуля, не день недели.

**Перед стартом блока, одной цифрой:** статус вчерашней ночи + счётчик зон текущей недели (жёлтые/красные). Не для анализа, а как знак в момент, когда «беру ли ещё урок» ещё решает свежая голова. В 2 часа ночи эту цифру уже не увидишь.

**Пятница вечером работы нет.** Якорь восстановления, не резервный слот.

### 1.2. Аукцион 22:00 — вердикты, не исполнение

Пять минут, таймер, до заморозки, ничего не исполняется. Неготовое получает вердикт в одну из корзин:

1. **Понижение** (урок пойдёт по П) — исполнение только в жёлтой зоне как выбранный артефакт.
2. **Fallback** — печатный fallback из пакета или баночная канва с флагом.
3. **Добивание** — один артефакт одного урока.

Корзины 1 и 3 исполняются только как «один выбранный артефакт жёлтой зоны». Понижение в 22:00 не исполняется никогда: 15-20 минут на него выдавливают заморозку, а неотформатированный пакет утром не раздаётся.

**Осуществимость корзин проверяется не в 22:00, а в течение вечера** (30 секунд при необходимости): есть ли типовой печатный лист по модулю — нет, значит корзина «понижение» недоступна и остаётся только fallback.

Коридор не является способом выполнить квоту. Неготовые три урока из четырёх — три записи в пол по §1.8. Регулярный коридор означает «квота завышена относительно ёмкости», лечится §18, а не ночами.

### 1.3. Коридор: две зоны с разной ценой

| | Жёлтая 0:30-2:00 | Красная 2:00-4:30 |
|---|---|---|
| Природа | Терпимый размен, один артефакт | Мозг против одного вечера |
| Что делать | Только артефакт с аукциона | Только добивание |
| Обрыв | 2:00, если не добито | 4:30, абсолютный |
| Следующий вечер | «Тяжёлый»: строка «40 минут» §18, бюджет −1 очко, ретелл пассивно | Бюджет 0: тип 0 из банка и аварийный пол, ретелл отменён |
| Техника безопасности | **Надзор усилен: с режущим и нагревательным инструментом дети работают только под прямым контролем.** 4,5 ч сна — дефицит контроля моторики и оценки риска | **Труд и лабораторные без самостоятельной работы с инструментом, максимальный надзор.** Вопрос безопасности детей, не качества урока |
| Запись в заметку | «жёлтая до HH:MM» | «красная до HH:MM» + **причина одной строкой** |
| Порог | ≥3 за неделю → следующий ВС в режиме восстановления банка | ≥2 за неделю → восстановление + вопрос вне алгоритма |

Причина красной обязательна: без неё через месяц не отличить «сломался вечер» от «квота нереальна», а лечатся эти болезни противоположно.

Честная рамка, которую алгоритм держит в тексте: размен «красная зона против разрушения мозга» принят на этот год осознанно. Цена считается счётчиками, порогами и обнулением следующего вечера. При хроническом дефиците та способность, которую защищают процедуры, падает раньше, чем человек это замечает, поэтому пороги механические, а счётчик вынесен на видное место. ≥3 красные больше месяца — вопрос вне алгоритма.

### 1.4. Суббота

9:00-16:30 уроки без подготовки, офлайн. Банк-блок 45 мин сразу после уроков, только механика (раскладка, переименование, транскрибация). Запрещено: аналитика, новые артефакты, модульные проходы, аудит, любое производство. Сон ≤1:00 не разменивается.

### 1.5. Воскресенье

Свои уроки (10:00-11:30 / 16:30-18:00, бывает 0-2): тип 0, из банка, без ретелла и производства.

| Блок | Содержимое |
|---|---|
| ВС-1, 60 мин | Карта пробелов по заметкам, счётчики, флаги, погашение долгов §7.5, событийные сверки ФИПИ |
| ВС-2 | Только сырьё и скелеты: 0.5+2, ТЗ-рамки, 3, 4, скелеты канвы, аудит модуля |
| ВС-П | Полный цикл понедельника: 5 → 6 → 8 → 9 |
| ВС-3 | Догон, пересборка канв с флагом, `сорвался` |

**Разрыв между ВС-2 и ВС-П ≥1,5 часа с едой, для всех вариантов воскресенья.** ВС-2 — работа высшего внимания; ВС-П поверх неё без разрыва даёт приёмку на автопилоте, что шаг 9 запрещает делать молча.

| Вариант воскресенья | ВС-2 | ВС-П (стена) | Ориентировочная ёмкость понедельника |
|---|---|---|---|
| 0 уроков | 3-3,5 ч | 90-120 мин, после разрыва | до 5 лёгкими или 1 полный А2 или 1 А2-экспресс + 2 лёгких |
| 1 урок | 2,5-3 ч | 75 мин | до 4 |
| 2 урока | 3 ч (13:00-16:00) | 60 мин (не ранее 17:30) | до 3 |

Ёмкость — не квота: сколько тем тянет бюджет, столько делается. Остальное тип 0 из банка или пол с флагом.

### 1.6. Бюджеты вечеров и составы с А2

День даёт только потолок. Ни один день не запрещает тип; перерасход прогоняется через §1.8.

| Вечер | Создаёт уроки на | Стена / внимание / очки |
|---|---|---|
| ВС-П | Понедельник | 60-120 (по варианту) / ≤60 / ≤5 |
| Понедельник | Вторник | ≤150 / ≤90 / ≤4 |
| Вторник | Среда | ≤165 / ≤100 / ≤5 |
| Среда | Четверг | ≤150 / ≤90 / ≤4 |
| Четверг | Пятница | ≤150 / ≤90 / ≤4 |
| Пятница | Суббота | Нет работы |

Квоты по урокам (сколько штук реально входит): 4 / 5 / 4 / 4 — **только при составе без А2**.

Составы с А2 (счёт по очкам, не по числу уроков):

| Вечер | Допустимый состав с А2 | Очки | Стена | Вердикт |
|---|---|---|---|---|
| ≤4 очка (ВС-П, пн, ср, чт) | **Полный А2 — только соло** | 4 | 102-128 | работает |
| ≤4 очка | Полный А2 + любой урок | 4,5-5 | 117-158 | не проходит кап |
| ≤4 очка | **А2-экспресс (3) + В/Б (1)** | 4 | 105-140 | работает |
| ≤4 очка | **А2-экспресс + 2 П** | 4 | 115-140 | работает |
| ≤5 очков (вторник) | Полный А2 + П | 4,5 | 117-143 | работает |
| ≤5 очков | Полный А2 + В | 5 | 122-158 | работает |
| ≤5 очков | Полный А2 + Б | 5 | 137-173 | риск: верх стены за 165 |
| ≤5 очков | А2-экспресс + Б + П | 4,5 | 152-188 | не проходит стену |

Ключевое различие, которое надо помнить: **полный А2 вытесняет весь остальной вечер, А2-экспресс оставляет одно очко.** Экспресс дешевле не потому, что хуже, а потому что его методическая часть отнесена в долг.

Дополнительный потолок на вечер: **не более одного А2 (любого)**, потому что они не суммируются по очкам линейно, а вытесняют очередь.

Типовые составы без А2 (стена): 4×В = 80 · 2×Б+2×П = 100 · 5×П = 75 · 3×В+2×П = 90 · 1×А1 лёгкий+2×П = 105 · 1×А1 тяжёлый+1×П = 117-143.

### 1.7. Что делать с остатком ёмкости вечера

Разрешено: догон проваленного за неделю, карта идей модуля сверх плана, типовое мини-приложение, **типовой печатный лист модуля**, изображения в `assets`, банк заданий, пересборка скелета, погашение долга `неполный`.
Запрещено: готовый урок дня, следующего за следующим.

### 1.8. Порядок жертвоприношения

Визуал → мини-приложение (fallback из канвы) → презентация (тезисный текст) → понижение до П → перевод полного А2 в А2-экспресс с записью долга → лишний урок целиком в банк/аварийный.
Провал утреннего ретелла = +1 очко; нет очка = fallback без правок. Шаг 7 не жертвуется, шаг 9 не сокращается молча. Коридор последнее средство после всего списка.

## 2. Контекст использования

Информатика, ИИ, ИБ (5-10), труд (5-7), начальная школа (1-4), практические задачи (10). ~52 урока в неделю, через алгоритм до 20. Ядро: 10 профиль (заточка под детей), 11 профиль (ЕГЭ), незнакомые предметы (труд, ИБ, ИИ).

Сон 2-4 ч при целевых 6-7: отбой 0:30, жёлтая 0:30-2:00, красная 2:00-4:30, обрыв 4:30. Нормативная неделя при ≤2 жёлтых и ≤1 красной даёт ~40 ч сна против ~21 в старом режиме; коридор платит сам: жёлтая снимает очко следующего вечера, красная снимает весь следующий вечер и включает ТБ-ограничение.

Персональная особенность: чужих уроков не бывает; банк только своё; шаги 7 и 9 обязательны; ИИ полуфабрикаты.
Формат: HTML-презентации, печатные (`@media print`), мини-приложения (vanilla JS), техкарты ФГОС. Доставка: код в чат → копирование. Исполнение на чужих машинах. ПДн детей вне ИИ. Россия, ~2000 ₽/мес.

## 3. Суть

Учитель автор, ИИ исполнители полуфабрикатов. Алиса сверяет этапы с промтом в диалоге: факт и структура, не методика. Методику оценивает только GLM (свежий чат, полный контекст). «Своим» урок становится на 7 и 9.

## 4. Уровень 0 (разово) manufacture буфера

Запрет впрок делает сырьевой банк единственным буфером. Он не «полезен», он несущий.

КТП по ФРП (edsoo.ru) · паспорта классов · библиотека промптов-ролей · шапка-контекст (8-10 строк первым сообщением в каждый чат) · HTML-шаблоны презентации и печатных · обёртка мини-приложения один самодостаточный файл (base64, без `assets`, без внешних запросов) · требования: vanilla JS, ES2018-совместимо (без `?.`, `??`, `import/export`), без CDN, ≤300 строк · шаблон техкарты с образцом · префикс стиля генерации изображений · песочница со старым браузером + «первый экземпляр класса артефакта прогоняется вне окна раздачи» · разведка источников (РЭШ, «Урок цифры», edsoo.ru факты, не уроки) · чек-лист §16 · скелет курса ИИ первый ВС сентября, приоритет над первым модулем · **квартальный пересмотр статуса предмета (§5.1, поле A) — 30 секунд в У0** · пересмотр У0 30 мин/четверть · ретроспектива 5 мин в последний ВС-1 · У0-минимум: паспорт, обёртка, чек-лист, промпты 1/5/6/9.

**Приоритет наполнения банка (по влиянию на вечер):**
1. типы мини-приложений,
2. банк заданий по модулю,
3. **типовые печатные листы модуля** — до изображений: они условие легальности контура П, а П нужен именно в первые недели и именно когда нечего переиспользовать. Qwen, один лист на модуль, дёшев;
4. скелеты канвы,
5. изображения `assets`.

## 5. Триаж: тип определяется состоянием, не решением

### 5.1. Вывод типа (тест 2 минуты, перед шагом 2)

Четыре сырых факта:

| Факт | Значения |
|---|---|
| **A. Статус предмета для меня** | в зоне экспертизы (≥3 пройденных модуля) / идущий (1-2) / новый (0). Пересмотр квартальный, в У0 |
| **B. Что нашёл поиск банка** | готовый урок по теме (флаг какой) / только скелет модуля / пусто |
| **C. Мышление по этому модулю в ВС-2 пройдено** (0.5+2, ТЗ-рамка, скелет канвы) | да / нет |
| **D. Какой это урок в модуле** | первый / середина / завершающий |

Вывод:

| Условие | Тип |
|---|---|
| Предмет из перечня типа 0 (инф. 7-9, повторы нач. школы) или урок субботы/воскресенья | **0** |
| B = готовый урок с флагом `готово` | **Б** или **В**, дельта-приёмка |
| B = готовый урок с флагом `понижено`/`аварийный`/`неполный` | **Б/В с обязательной пересборкой** перед переиспользованием |
| B = только скелет модуля, C = да | **А1** (лёгкий/тяжёлый по артефактам), шаг 5 укорочен: канва из скелета |
| A = в зоне экспертизы, B = пусто, C = да | **А1** |
| Модуль не обдуман (C = нет) — при любой A | **А2-экспресс** + долг в §7.5 |
| A ≠ «в зоне экспертизы», B = пусто, C = да | **А2 полный** |

Правила вывода:
- **Скелет модуля не делает урок типом Б.** Скелет экономит часть шага 5, урок остаётся А и проходит 7 и 9 полностью. Попадание в `_скелеты` не есть попадание в банк уроков.
- **П не вводится никогда и никем.** Его присваивает только аукцион 22:00.
- **Аудит не входит в цикл текущего урока:** в ВС-2 проверяются материалы уже прошедших уроков модуля. Первый урока модуля по определению идёт без аудита; при экспрессе это не исключение, а конструкция, поэтому печатный fallback обязателен.
- Техкарта (10) реактивная, в поурочные циклы не входит.
- «Два А2 в один вечер невозможно» следствие арифметики, не правило.

Опция Мозга на первые модули **труда и ИБ** (где цена ошибки выше): +10 мин GLM-чека контента первого урока модуля. 112-138 ≤ 150, в вечер влезает. Не требование, выбор.

## 7. Банк, метрики, долг

### 7.1. Структура
`/Банк/Модуль/Тема` (готовые уроки) + `assets` + `_скелеты` + `_типовые_приложения` + **`_типовые_печатные`** + `_задания`. Ключ по модулю.

### 7.2. Флаги
`готово` / `понижено` / `аварийный` / `неполный` / `сорвался`. Обязательны в выдаче поиска; `понижено`, `аварийный`, `неполный` → предупреждение «пересобрать перед переиспользованием».

### 7.3. Заметка
Юридический артефакт, единственный источник правды для техкарты. Формат: 3 строки + служебные (зона коридора, «вечер занял ~N мин»).

### 7.4. Счётчики (5 мин в ВС-1; зоны и очередь видны одной цифрой вечером перед блоком)
доля уроков с папкой в банке (ловит отказ от системы) · число `понижено`/`аварийный`/`сорвался` · **число `неполный` и список непогашенных долгов** · жёлтые и красные отдельно, красные с причиной · «урок начат не в канун» (нарушение правила 1).

### 7.5. Реестр долгов
Каждый А2-экспресс записывает: модуль, что не сделано (0.5/2, 3, 4, аудит), срок ближайший ВС-2. **Долг гасится до взятия нового модуля.** Два непогашенных одновременно → новый модуль на эту неделю не стартует. Так экспресс остаётся исключением с ценой, а не новым способом работы.

### 7.6. Пороги
≥3 флага · неделя без заметок · ≥3 жёлтые · ≥2 красные → следующий ВС в режиме восстановления банка.

## 8. Роли

Ансамбль будней ≤4: **Алиса** (поиск, дифф факт/структура, фактчек ИИ+труд, промты правок, простые приложения, визуал; не канва и не контент) · **DeepSeek** (канва и скелеты, резерв) · **Qwen** (контент, печатные, презентации по шаблону, массовость, техкарты; тезисность слайдов в промпте) · **GLM** (экспертиза, аудит, средние приложения без рассуждений; свежий чат, один вызов). **Claude** сложные приложения сразу, через API-агрегатор (рубли, без VPN); лестница fallback. **Gemini** нестабильный резерв. GigaChat и Cherry Studio удалены (триггер возврата Cherry копипаст >30-40 мин/день по замеру).

## 10. Присвоение операционал

Личный вклад и 3-5 якорей (определение, объяснение, вопрос классу) задаются в поле ТЗ и вплетаются вечером накануне через промт Qwen. Утром текущего дня ретелл их проверяет: 2 минуты рассказать канву без листа. Сможешь твоё; нет провал: +1 очко вечеру на правку канвы либо fallback без правок. Провал диагностика, не вина.
Пассивная форма в тяжёлый день и после жёлтой зоны; после красной отменён, урок по fallback. Вечерние дельт-правки идут в канву и в скелет модуля. Б/В присвоение легально = сверка дельт. П ретелл пассивно + строка в заметку. А2-экспресс: присвоение полное, ретелл обязательный неполнота касается методической обвязки, не авторства. Право объявить урок `аварийный` вместо фальшивого присвоения. На шаге 7 fallback открывается руками: жив, печатается.

Хвост миграции (5 полей): РЕШЕНИЯ / ОГРАНИЧЕНИЯ ГРУППЫ / НЕ ДЕЛАТЬ / ТЕРМИНЫ / ДАЛЬШЕ.
Логика группы: усп.5 углубление; усп.2 упрощение + визуал; упр.5 самостоятельность; упр.2 короткие блоки, интерактив из банка.
Аудит бессрочно по каждому новому модулю незнакомого предмета, проверяет прошедшие материалы. Аудитор ≠ автор.
Ручное: ФГОС, ТБ труда, ПДн.
Последняя инстанция: лимит исчерпан → упростить / вердикт «П» на аукционе / полный А2 в экспресс с долгом / fallback / вручную. Шаг 7 не сокращается, шаг 9 не сокращается молча.

## 15. Пол, потолок, восстановление, сон

Потолок бюджет, не запрет. Всё сверх отказ по правилу в гарантированный пол, не решение уставшего человека в 21:45.
Пол: канва из банка → ретелл → заметка. Остальное не делается по определению.
Аварийный «20 минут»: канва + лист раздатки; флаг; техкарта потом из заметки.
Восстановление без вины: ВС-3 догоняет; `сорвался` не ночи.
Якоря: пятничная ночь и субботный сон ≤1:00 не продаются, в том числе коридором.
После жёлтой надзор на инструменте; после красной бюджет 0 и труд с лабораторными без самостоятельной работы.
Признание: ~52 урока при 2-4 часах сна, готовке исключительно накануне и красной зоне до 4:30 нагрузка вне пределов личной эффективности. Размен принят на этот год осознанно; алгоритм считает цену, но не вправе её не замечать. Вся арифметика опирается на текущий уровень внимания: если сон падает, бюджет сжимается сам (4→3→2), флагов для этого нет, есть пункт «как я засыпаю».

## 17. Диагностический контур (приложение Б)

Источник ТЗ шага 1, не второй цикл. Входная диагностика раз в полугодие. Карта пробелов офлайн; в чаты только проценты, не количества (количество учеников из паспорта вход правила). Карта = вход ТЗ; КТП нормативка. Пересборка ВС-1 по заметкам.

## 19. Изменения v8.3 → v8.4

1. **Составы с А2 сведены таблицей очков** (п. 2.1 GLM): полный А2 = кап вечера целиком, экспресс оставляет одно очко. Снято обещание «А2 + П», которое не проходило потолок.
2. **Полный А2 отвязан от дня и привязан к состоянию модуля** (поле C): обдуман полный, не обдуман экспресс с долгом. Дневной запрет А2, предложенный экспертизой, отвергнут как возврат к планированию тяжести по дням.
3. **Аукцион исполняет только вердикты**; понижение уходит в жёлтую зону (корзины 1 и 3 слиты). Осуществимость корзины «П» проверяется в течение вечера.
4. **`_типовые_печатные` введены как отдельная папка и подняты в приоритете наполнения** над изображениями: без них П нелегален, а нужен именно в первые недели.
5. **Разрыв ≥1,5 ч ВС-2 → ВС-П** для всех вариантов воскресенья.
6. **ТБ-надзор распространён на жёлтую зону.**
7. **Поле A стало статусом предмета с динамическим переходом** («в зоне экспертизы» после ≥3 модулей, пересмотр в квартальном У0). Без него математика выхода (§15) недостижима принципиально.
8. Опция Мозга: +10 мин GLM-чека первого урока труда/ИБ.

**Позиция в очереди** (сколько уроков уже в этом вечере и сколько они стоили) берётся не из заявки, а из факта: счётчик вечера.
