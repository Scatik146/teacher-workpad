Совместная работа через сетевую папку — подготовка сегодня

  1. Положите delo_6-II.html в сетевую папку, куда у учеников есть право записи.
  2. Откройте файл в Chrome или Edge (Firefox не умеет писать в папку — там работает только запасной режим со скачиванием файлов).
  3. На одном ученическом компьютере: роль «Отдел 1» → «Папка дела» → выбрать ту же сетевую папку → разрешить изменения → «Материалы дела» → «Проверка связи». Должно быть «Связь в порядке».
  4. На своём компьютере: роль «Руководитель следствия» → та же папка → «Материалы дела» → «Проверить, какие файлы есть». Должен быть виден файл проверки.
  5. Приложение само создаёт подпапку delo-6-II_ДАТА: на каждый день — своё дело, старые файлы не мешают.

Как это работает на уроке

  • Каждый компьютер отдела пишет только свой файл otdel-N.json — кнопками «Внести в дело». Руководитель пишет rukovoditel.json.
  • Ваш экран и ваши «вскрытия» (ответы опознания, строки, журнал механизма) раз в 4 секунды подхватываются компьютерами отделов. На компьютерах отделов кнопок вскрытия нет — подсмотреть ответ заранее нельзя.
  • Кнопка «Собрать материалы» на вашем экране: голоса опознания, заключения отделов (сразу в доску улик), сверка допроса, позиции для среднего режима вердикта, тайные бюллетени для аварийного режима, решения рефлексии.
  • Если в заключении отдела встречаются «понимает / думает / придумывает», приложение подсказывает переформулировать по словарю.
  • Если папка не заработала: отделы нажимают «Внести в дело» — файл скачивается; его сохраняют в общую папку, вы загружаете все файлы в «Материалах дела».
