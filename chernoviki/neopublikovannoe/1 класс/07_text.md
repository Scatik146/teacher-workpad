# Канва урока «Раскрась как хочешь»: где живёт каждая буква

**Предмет:** информатика · **Класс:** 1 (7 лет) · **Тип:** комбинированный · **Группа:** 5 детей · **Успешность:** 4/5 · **Управляемость:** 4/5  
**Длительность:** 35 минут  
**Среда:** одно локальное HTML-приложение «Раскрась как хочешь», ноутбук + мышь на каждого ребёнка  
**Смысл урока:** это игра-раскраска. Ребёнок ищет буквы, потому что ему нужен результат игры — картинка, золото. Не тренажёр клавиатуры.  
**Дидактическая цель:** ребёнок знает, где на клавиатуре находится буква русского алфавита. Ничего более: не ввод текста, не пробел, не Enter, не слепой набор.  
**Сквозной навык:** Ctrl+Z(Я) — на каждом этапе. Только русские буквы; приложение работает по `event.code`.

## Опорные элементы

### Карта цветов (финальная, менять нельзя)

| Блок (мнемоническое слово) | Буквы | Базовый цвет | Ряд |
|---|---|---|---|
| ЙЦУКЕН | Й Ц У К Е Н | красный | верхний |
| ГШЩЗХЪ | Г Ш Щ З Х Ъ | зелёный | верхний |
| ФЫВА | Ф Ы В А | жёлтый | средний |
| ПРОЛ | П Р О Л | голубой | средний |
| ДЖЭ | Д Ж Э | чёрный | средний |
| ЯМИТЬ | Я М И Т Ь | фиолетовый | нижний |
| ЧС | Ч С | оранжевый | нижний |
| БЮ | Б Ю (Ё — в карте, в заданиях не используется) | белый | нижний |

- 8 базовых цветов: 7 основных (синий заменён чёрным как самый путаемый с голубым) + белый.
- Синего в буквенной палитре нет; **синий — служебный цвет интерфейса**, **оранжевый — цвет сундуков и золота** (отличие от букв ЧС — по форме и контексту).
- У каждой буквы — свой оттенок её базового цвета (33 оттенка на 8 базовых). Оттенки **не являются предметом различения**: ребёнок всегда работает с конкретной буквой, а не «угадывает оттенок».
- Буква **Ё в заданиях не используется нигде**: ни в уровнях, ни в вратах, ни в лабиринте.
- Мнемонику проговаривает учитель; приложение слова не показывает.
- В игре — статичная нарисованная клавиатура, кнопки раскрашены цветами своих мнемонических слов. Это постоянная зрительная опора «где какая буква». Интерактивная подсветка — только в профиле помощи слабых: подсвечивается целевая кнопка на том же изображении. У сильных подсветки нет.

### Ctrl+Z(Я)

Физический якорь: клавиша Z в русской раскладке — это «Я», блок ЯМИТЬ = **фиолетовый**. Правило урока: **«Я — отмена»**. Учитель никогда не говорит «исправь ошибку» — только «отмени», «верни», «нажми Я».

### Врата (механика подбора цвета)

- Перед каждой игрой — серия клеток-образцов (по одной на каждый ключевой цвет этой игры). Всего 6–7 образцов.
- Ребёнок **мышкой** кликает по RGB-переключателям: три канала, счётные позиции (ориентир 3–4 позиции на канал, суммарно до ~40 комбинаций). Точные ступени — на этапе разработки контента; требование канвы: **подбор всей серии занимает не более 60–90 секунд**.
- Попал в цвет очередного образца — в клетке появляется **буква**. Её оттенок = оттенок этой буквы. Оттенки меняются от врат к вратам: заучить значения RGB нельзя, нужно каждый раз сверяться с образцом.
- Врата дают **набор букв-ключей**: по одной букве из 6–7 мнемонических слов (набор слов меняется от игры к игре; Ё не используется; для ДЖЭ проверяется читаемость чёрного оттенка на образце — при проблеме образец заменяется соседним оттенком того же слова).
- **Гарантия покрытия рядов:** случайный набор букв-ключей **всегда** содержит минимум по одной букве из каждого **ряда** клавиатуры — верхний (ЙЦУКЕН / ГШЩЗХЪ), средний (ФЫВА / ПРОЛ / ДЖЭ), нижний (ЯМИТЬ / ЧС / БЮ). Без этой гарантии требование «все три ряда в каждом уровне» не выполняется: случайность может выбросить весь верхний ряд. Генератор набора проверяет покрытие рядов до выдачи.
- Каждая буква набора — **ключ текущей игры**: у неё свои области в рисунке, которые никакой другой буквой не закрыть. Остальные области закрашиваются обычной механикой «клик по области + буква» теми же буквами-ключами (несколько цветов в работе — ребёнок раскрашивает разноцветно, а не одним ключом).
- Врата — «тормозилка» для торопыг и передышка между клавиатурными этапами; тон игровой, это врата, не наказание.

### Антисоревновательность

Очки лабиринта — только на личном экране; на доске — общее золото. Рисунки в галерее — все вместе и равноценно. Реплики на «а у кого больше» и на «мимо сундука» — ниже.

### Тон учителя

Игровой. Врата — игра, не наказание. Ошибка — дрожь и мягкий звук, никогда красный крест.

## Этапы

### Этап 1. Орг. момент + правило «Я — отмена» (0–2 мин)

| Параметр | Содержание |
|---|---|
| **Цель** | Ребёнок знает, где находится буква «Я», и что Ctrl+Z — это отмена; посадка и СанПиН-условия |
| **Действия учителя** | Приветствие, проверка посадки и расстояния до экрана (≥ 50 см), яркость минимальная. Показывает Ctrl+Z на доске: «зажал Ctrl — не отпускаю — один раз нажал Я — отпустил обе». Одна фраза про звук: «звук появится после первого клика — так и должно быть» |
| **Действия ученика** | Слушают, находят «Я» пальцем, пробуют Ctrl+Z на заставке |
| **На доске** | Крупная схема: Ctrl (левая рука) + Я (правая). Я — фиолетовая (блок ЯМИТЬ). Надпись «Я — отмена» |
| **На ноутбуках** | Заставка; изображение клавиатуры с цветными кнопками по карте; «Я» в фиолетовом блоке |
| **Ctrl+Z(Я)** | Первый опыт: одна отмена на заставке — «проверили, что отмена работает» |
| **Дифференциация** | Сильные — находят «Я» сами; средние — с подсказкой на доске; слабые — учитель кладёт палец ребёнка на «Я», проговаривает вслух |
| **Реплика** | «Смотри: если что-то нажал не так — есть волшебная отмена. Зажал Ctrl — не отпускаю! — один раз нажал вот эту клавишу. На ней написано „Я“. Ctrl+Z — это „Я“, это отмена.» |
| **Критерий перехода** | Все показали «Я» пальцем и хотя бы раз нажали Ctrl+Z |

### Этап 2. Врата №1: подбор цвета → набор ключей игры 1 (2–4 мин)

| Параметр | Содержание |
|---|---|
| **Цель** | Ребёнок подобрал серию образцов и получил набор букв-ключей игры 1; видит, что у буквы есть свой оттенок |
| **Действия учителя** | Показ на доске (1 мин): образец → RGB-переключатели → попал → в клетке появилась буква. Затем индивидуально: подходит к каждому |
| **Действия ученика** | Кликают RGB-переключатели, совпадают с очередным образцом; в клетке появляется буква с её оттенком |
| **На доске** | 6–7 клеток-образцов, скриншот RGB-переключателей, «попал — появилась буква» |
| **На ноутбуках** | Серия образцов (6–7); RGB-переключатели (3 канала, 3–4 позиции на канал, до ~40 комбинаций); подбор серии ≤ 60–90 сек; набор ключей гарантированно покрывает три ряда |
| **Ctrl+Z(Я)** | Ритуал перед вратами: «Проверим отмену: нажми Ctrl+Z — видишь, „Я“ загорелась фиолетовым, это её блок. Теперь подбираем цвет.» После подбора — ещё раз Ctrl+Z: «вернули, посмотрели ещё раз» |
| **Дифференциация** | Врата одинаковы для всех; слабым учитель помогает голосом и пальцем на экране; сильные проходят быстрее и ждут остальных |
| **Реплика** | «Перед каждой игрой — врата. Вот клетки-образцы. Подбираю цвет переключателями — раз! Попал — в клетке появилась буква, вот её оттенок. Оттенки меняются от врат к вратам, поэтому каждый раз сверяемся с образцом. Это не ошибка, это врата. И не забываем: Я — отмена.» |
| **Критерий перехода** | Серия подобрана у всех (или у всех, кроме одного — с ним учитель доберёт на этапе 3; врата не барьер) |

### Этап 3. Игра 1 «По образцу», уровень А — крупные области (4–7 мин)

| Параметр | Содержание |
|---|---|
| **Цель** | Ребёнок находит буквы-ключи текущей игры на изображении клавиатуры и закрашивает крупные области |
| **Действия учителя** | Запускает уровень А у всех; стоит в центре, видит все экраны; комментирует одну-две области как пример |
| **Действия ученика** | Находит букву-ключ на изображении клавиатуры, нажимает физическую клавишу, видит закраску; области, закреплённые за конкретной буквой, закрываются только ею; свободные области — любой буквой-ключом; ребёнок раскрашивает разноцветно |
| **На доске** | Образец уровня А с буквами-ключами; напоминание «Я — отмена» в углу |
| **На ноутбуках** | Уровень А, крупные области; изображение клавиатуры с цветными кнопками по карте; у слабых подсвечивается целевая кнопка, у сильных — нет; подсказка при простое 5 сек; один звук на событие; debounce auto-repeat |
| **Ctrl+Z(Я)** | Нажал не ту букву → Ctrl+Z убирает последнюю закраску. Учитель **заранее**: «Если область дрогнула — не страшно, нажми Ctrl+Z, Я вернёт» — до того, как ребёнок ошибётся |
| **Дифференциация** | Слабые: подсветка целевой клавиши, подсказка при простое 5 сек. Средние: подсветки целевой нет. Сильные: без подсветки. Задание одно для всех |
| **Реплика** | «На области написана буква. Нажимаем эту букву — область закрашивается её оттенком. Дрогнула — Ctrl+Z, „Я“, и продолжаем. Зажал Ctrl — не отпускаю — нажал Я — отпустил.» |
| **Критерий перехода** | ≥ 3 областей закрашено у каждого; хотя бы один Ctrl+Z попробовал каждый (у кого не было ошибки — учитель просит «проверим отмену» на пустой области) |

| **Действия учителя** | Запускает уровень Б; напоминает «уровни равноправны»; **основной финиш** — конец этого этапа, не дальше |

| **Дифференциация** | Слабые: подсветка целевой клавиши, подсказка при простое. Средние: без подсветки целевой. Сильные: без подсветки, темп выше |
| **Реплика** | «Второй уровень. Он не сложнее — просто другой. Кто закончил — поднимите руку, я подойду. Кто не закончил — тоже нормально: основной финиш здесь, дальше — лабиринт для тех, кто готов, или дописать картинку.» |
| **Критерий перехода** | Каждый ребёнок либо закончил уровень Б, либо осознанно переходит в лабиринт / дописывать картинку — учитель фиксирует маршрут **до** запуска этапа 11 |

### Этап 11. Лабиринт / дописать картинку игры 2 (21–27 мин)

| Параметр | Содержание |
|---|---|
| **Цель** | В лабиринте — ребёнок находит буквы-ключи на клетках и нажимает их на физической клавиатуре, проверяя позиционную память; на маршруте «дописать» — завершает свою картинку уровня Б |
| **Действия учителя** | Стоит в центре; следит за звуком и за тем, чтобы не было рейтингов; **не комментирует очки**; при промахе — ровно и коротко: «сундук подождёт до следующего раза»; при «а у кого больше» — «очки у тебя личные, на доске — общее золото» |
| **Действия ученика** | В лабиринте: находят буквы на клетках, шагают, выбирают маршрут (скорость или сундуки), на развилках выбирают направление буквами-указателями; на обычной клетке неверная буква = персонаж не идёт, отменять нечего; на развилке передумал — Ctrl+Z возвращает. На маршруте «дописать»: закрашивают оставшиеся клетки уровня Б |
| **На доске** | Коллективное золото — общая сумма, без имён; надпись «оба маршрута равны по очкам» |
| **На ноутбуках** | Лабиринт: буквы на клетках (слабым — горят постоянно, сильным — мелькают коротко), сундуки, 2–3 развилки, персонаж. Маршрут «дописать»: картинка уровня Б |
| **Ctrl+Z(Я)** | **Главное место:** на развилке передумал направление — Ctrl+Z возвращает персонажа. Учитель **заранее**: «Если на развилке передумал — Ctrl+Z, „Я“, вернулся. На обычной клетке неверная буква — персонаж не идёт, отменять нечего» |
| **Дифференциация** | Слабые: подсветка целевой клавиши, буквы на клетках горят постоянно, подсказка при простое. Средние: без подсветки целевой, буквы горят постоянно. Сильные: без подсветки, буквы мелькают коротко. Задание одно для всех; маршрут — по готовности, не по «уровню» |
| **Реплика** | «На клетке буква. Нашёл — шагнул, клетка закрасилась. Можно к выходу, можно за сундуками — очков будет одинаково. Передумал на развилке — Ctrl+Z, „Я“, вернулся. Промахнулся — чуть подождал, и всё. Мимо сундука — он подождёт до следующего раза. Кто дописывает картинку — твоя картинка ждёт.» |
| **Критерий перехода** | Каждый сделал хотя бы один шаг в лабиринте или закрасил хотя бы одну клетку на маршруте «дописать». **Ctrl+Z отработан в играх 1 и 2 (у каждого по плану); в лабиринте отмена применима только на развилках — если в маршруте ребёнка развилки не было, отмену не требуем** (на обычной клетке неверная буква = персонаж не идёт, отменять нечего). Звук — один на событие |

**Проверка: влезает ли лабиринт (6 мин на 5 детей).**  
Средний маршрут ≈ 15–20 нажатий, 1 нажатие = 1–2 сек → 20–40 сек чистой работы; с обдумыванием, промахами и одним-двумя Ctrl+Z — 2–4 мин на ребёнка. Дети играют параллельно — 6 минут хватает на 1 полный проход каждому и на второй проход у 2–3 быстрых.

**Если лабиринт не влезает — что ужимать (в порядке приоритета):**  
1. **Размер** лабиринта: 8×8 → 6×6 → 5×5, убрать длинные коридоры и декоративные клетки.  
2. **Число сундуков**: 4 → 3 → 2 (минимум 1 сундук вне прямого пути — иначе нет второй стратегии).  
3. **Число развилок**: 3 → 2 → 1 (минимум 1 настоящая развилка с выбором).  
4. **В последнюю очередь** жертвуем: равноправием очков (полный и скоростной маршруты дают одинаковое число очков — калибровка на тестовом прогоне до урока) и наличием хотя бы одного сундука вне прямого пути.  
**Чем жертвовать нельзя:** антисоревновательностью (очки только на личном экране), нейтральной ошибкой, Ctrl+Z как отменой шага на развилке.

## Антисоревновательный сценарий (реплики готовы)

| Ситуация | Что говорит учитель |
|---|---|
| «А у кого больше очков?» | «Очки у тебя личные — они только на твоём экране. На доске мы вешаем общее золото — его собрали все вместе.» |
| «Я не дошёл до лабиринта» | «У тебя другой маршрут — ты дописываешь свою картинку. Это тоже маршрут урока, а не отставание.» |
| Ребёнок огорчился из-за пройденного мимо сундука | Ровным, игровым тоном, без жалости: «Сундук подождёт до следующего раза. Смотри, вот следующая буква — найдёшь?» — и сразу вернуть в игру |
| «У меня рисунок хуже» | «Все рисунки в галерее рядом, и все настоящие. Ни один не лучше другого.» |
| «Я всё стёр / я испортил» | «Ничего не испортил: Ctrl+Z, „Я“ — вернули. Чёрный и белый — такие же цвета, как все.» |
| «А можно ещё раз лабиринт?» | «Можно — проложи второй маршрут другой стратегией. Сравни очки: они равны, видишь?» |
| «А почему у него больше сундуков?» | «Он выбрал другой маршрут. Очков у вас одинаково — так устроена игра.» |

## Проверка требований

- **Поминутная развёрстка 35 минут** — есть, с буфером 3,5 минуты на организационные паузы (запуск, три перехода, закрытие).
- **Цель в терминах «находит буквы-ключи текущей игры на изображении клавиатуры»** — в каждом этапе.
- **Действия учителя и ученика, доска, ноутбуки** — в каждом этапе.
- **Дифференциация по каждому этапу** — сильные / средние / слабые, только через профили помощи, без ярлыков «лёгкий/сложный», без разных заданий.
- **Ctrl+Z(Я) на каждом этапе** — в этапах 1, 2, 3, 5, 6, 7, 9, 10, 11, 13; в этапах 4, 8, 12 — паузы/просмотр (обоснованно). В лабиринте — только на развилках; если развилки в маршруте не было, отмену не требуем.
- **Антисоревновательность** — сценарий с репликами.
- **Точки риска и план Б** — таблица.
- **Лабиринт — влезает** — проверка и приоритет ужимания.
- **Ограничения психолога** — в тайминге (смена каждые 3–6 минут), в репликах (тон, «сундук подождёт», «другой маршрут», «твоя картинка ждёт»), в дифференциации (профили), в архитектуре (очки только на личном экране).
- **Карта цветов** — финальная, 8 базовых, Ё не используется, синий — служебный, оранжевый — сундуки/золото.
- **Врата** — RGB-переключатели, 6–7 образцов, ≤ 60–90 сек, буква появляется в клетке, набор букв-ключей с **гарантией покрытия всех трёх рядов клавиатуры**.
- **Клавиатура в игре** — статичная, цветные кнопки; подсветка целевой — только у слабых.
- **Состав букв** — только буквы-ключи текущей игры; генератор набора врат **гарантирует минимум по одной букве из каждого ряда** (верхний / средний / нижний), поэтому «все три ряда в каждом уровне» выполняется всегда, а не по случайности.
- **Свободной раскраски нет** — маршрут «дописать картинку».
- **А/Б — уровни одной игры**, оба проходят все.
- **Лабиринт** — Ctrl+Z только на развилках; на обычной клетке неверная буква = персонаж не идёт.
- **Мелочи** — нет обещания «рисунки вернутся»; галерея 1,5 мин за счёт буфера; в рефлексии «покажи пальцем Я, М, Б».
- **Язык дрилла убран** — нет «повторов», «тренировки», «закрепления через повторы».
