### Задание 4. Условие Фано, код Хаффмана.
**Задание 1**
Для кодирования некоторой последовательности, состоящей из букв А, Б, В, Г, Д, Е, Ж, З, И, Й, К, Л, решили использовать неравномерный двоичный код, удовлетворяющий одному из условий Фано. Для букв А, Б, В, Г, Д, Е, Ж, З, И, Й, К использовали соответственно кодовые слова 01, 111100, 10, 111101, 11000, 00, 1110, 11011, 11001, 111110, 11010. Укажите кратчайшее возможное кодовое слово для буквы Л, при котором код будет допускать однозначное декодирование. Если таких кодов несколько, укажите код с наименьшим числовым значением.<br>
**Задание 2**
Для кодирования некоторой последовательности, состоящей из букв А, Б, В, Г, Д, Е, Ж, З, И, Й, К, Л, М, решили использовать неравномерный двоичный код, удовлетворяющий одному из условий Фано. Укажите кратчайшее возможное кодовое слово для буквы М, при котором код будет допускать однозначное декодирование. Если таких кодов несколько, укажите код с наименьшим числовым значением.<br>
**Задание 3**
Для кодирования некоторой последовательности, которая может содержать любые заглавные букв русского алфавита, решили использовать неравномерный двоичный код, удовлетворяющий одному из условий Фано. Для букв А, Б, В, Г, Д, Е, Ж, З, И, К, Л, М, О, П, Р, С, Т, У, Ф, Х, Ц, Ч, Ш, Щ, Э, Ю использовали соответственно кодовые слова 0110, 11100, 1001, 1111110, 11101, 1010, 0000, 111100, 1101, 0001, 01110, 1100, 1000, 1111101, 1111111, 0010, 1011, 00110, 011110, 111101, 001110, 1111100, 0111111, 0011110, 0011111, 0111110. **Задание 4**
Для кодирования некоторой последовательности, состоящей из произвольных заглавных букв русского алфавита, решили использовать неравномерный двоичный код, удовлетворяющий одному из условий Фано. Для букв А, Б, В, Г, Д, Е, Ж, З, И, К, Л, М, Н, О, П использовали соответственно кодовые слова 00, 110001, 110010, 110011, 110100, 110101, 110110, 110111, 01, 10, 111000, 11101, 111100, 110000, 111001. **Задание 5**
Для кодирования некоторой последовательности, состоящей из заглавных букв русского алфавита, решили использовать неравномерный двоичный код, удовлетворяющий одному из условий Фано. **Задание 6**
Для кодирования последовательности, состоящей из букв П, А, Е, И, К, Л, М, Н, О, Р, С, Т, Ч, Ы, З (всего 15 букв), решили использовать неравномерный двоичный код, удовлетворяющий условию Фано. В сообщении встречается только слово МАТЕМАТИЧЕСКИИАНАЛИЗ. Укажите минимально возможную длину кода для этого сообщения.<br>
**Задание 7**
Для кодирования некоторой последовательности, которая может состоять из всех заглавных букв русского алфавита и десяти цифр, решили использовать неравномерный двоичный код, удовлетворяющий условию Фано. В сообщении есть только слово ВЫЧИСЛЕНИЕ5И5МАТЕМАТИКА. Укажите коды для букв А и И, при которых длина кода слова будет минимально возможной, код буквы И имеет наименьшую возможную длину, а среди кодов такой длины — наименьшее числовое значение, а код буквы А — наибольшее числовое значение. В ответе запишите полученные коды слитно в порядке А, затем И.
