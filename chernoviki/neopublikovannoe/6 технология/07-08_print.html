Памятка по Paint

  • Вставка: «Буфер обмена» → «Вставить» (стрелка) → «Вставить из файла»
  • Размер: кнопка «Изменить размер» (или «Растянуть/Наклонить») → Проценты < 100, галочка «Сохранять пропорции»
  • Инструменты: Фигуры (Shift — квадрат, круг, звезда, линия), Заливка (замкнутый контур), Текст, Выделение
⚠ «Изменить размер» уменьшает всю картинку, не выделенный кусок!

Алгоритм практики

  1. Вставить сгенерированную картинку из файла
  2. Уменьшить через «Изменить размер», оставить место для рамки
  3. Нарисовать рамку (прямоугольник) и звёздочки (фигура «Звезда», Shift)
  4. Залить фигуры цветом, следя за замкнутостью контура
  5. Написать поздравление инструментом «Текст»
6. Сохранить: Файл → Сохранить как → PNG, имя «Otkrytka_01» (латиницей, номер выдаёт учитель)
