Оригиналы, убранные при разборе, остаются в истории git: `git show 368fc0c:<путь>`.

## Решения по структуре
- Поурочное планирование — `plan/` в корне сайта: файл на курс, внутри разделы по классам (`plan/README.md` — оглавление).
- Папка урока — по `CLAUDE.md`: `<класс>-klass/<имя>/`; для уроков из черновиков имя `<предмет>-<NN>-<тема-латиницей>`,
  предмет — `iiib`, `inf`, `trud`, `prog`, `rpz` (Решение практических задач, 10 кл.) (NN — номер строки в `plan/`). Паспорт урока — `README.md` в папке.
- Флаги: ✅ готово, ✏️ требует правки, 📝 черновик.
