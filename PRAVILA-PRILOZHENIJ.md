# Правила приложений уроков

Читать один раз за сессию — перед созданием или правкой приложения урока. Единственное место этих правил (решение учителя 25.11, экономия лимита): `CLAUDE.md`, навык `teacher-workpad-sajt` и `ii-komanda/komanda/VHOD-UROKI.md` только ссылаются сюда.

## Устройство

- Папка урока: `<класс>-klass/<имя>/` (урок для нескольких предметов — `obshchie/<имя>/`); приложение — `index.html`, рядом можно класть другие файлы (тексты, картинки). Один большой файл не обязателен.
- Каждое приложение — со скрытым меню перехода по экранам **Ctrl+Alt+M** (с заполнением данных по умолчанию для пропущенных экранов). На сайте и в материалах для учеников это меню не упоминать.
  Общий модуль меню — `lib/menu-ekranov/` (подключение — в шапке `menu-ekranov.js`); ставить при переводе урока в каталог.
- Шрифты — только из `lib/fonts/` (шрифт + файл лицензии, относительный путь; см. её README) или `lib/drakon-graf/fonts/`; Google Fonts и другие CDN не подключать.
- **Резерв для быстрых (решение учителя 23.11):** в приложениях 1–4 кл. — дополнительные задания не меньше чем на 25 % времени урока (★-задания, запасные задания, бонус), и в канве — план Б «что резать», если времени не хватает. Образцы — каталог приёмов ii-komanda `komanda/chernoviki/teacher-workpad/razbor-vse-uroki/README.md`, П-11 и П-12. Причина: «Цвет» 23.11 — дети прошли приложение на ~10 минут раньше.
- Прогресс — в `localStorage` (обёрнуто в try/catch), на заставке — кнопка «Новая смена / начать заново» для следующей пары.
- Работает без интернета (сетевая папка): никаких CDN, всё по относительным путям внутри сайта.
- Материалы учителя (канва, слайды, раздатки) — HTML-страницы в папке урока, в стиле `*/kanva.html`; .pptx и .docx переводим в HTML. Тексты, общие для игры и канвы, держать в одном файле (пример: `5-klass/ekho-uzel/tekst.js`).

## Задания и роли

- Варианты ответов перемешивать: верный — не всегда первый.
- В парах — роли «за пультом» и «штурман».

## Связанные правила

- Код приложения — по навыку `tri-stilya-koda` («по-фортовски», ДРАКОН-лист); готовые слова — `lib/slova/SLOVA.md`.
- Графические конспекты и дракон-схемы — навыки `graficheskij-konspekt` и `drakon-shema`.
- Материалы учителя — только HTML: Claude Docs у учителя не открывается.
