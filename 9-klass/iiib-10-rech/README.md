## Что есть

- `index.html` — приложение ученика: заставка с сюжетом, экран 1 «Ремонт» (6 примеров распознавания: станция ошибки, ветка помощника, ловушки), экран 2 «Голос» (синтез в браузере: прогноз → прослушивание, «Казнить нельзя помиловать», своя фраза, вывод), экран 3 «Итог» (помощник целиком, правило «перезвони сам», самооценка 3 × 0–2 → отметка). Меню учителя — Ctrl+Alt+M.
- `slajdy.html` — слайды на доску (18), по этапам урока; элементы — по щелчку. ДРАКОН-ГРАФ — по слайду на каждую схему (сцена, шеренга, очная ставка, батарея): как называется, из чего, зачем.
- `drakon-list.html` — ДРАКОН-лист А4 книжный, цвет: силуэт «Голосовой помощник» (станции 2–4 пустые), «Слова ДРАКОНа» — батарея запоминателей, ДРАКОН-ГРАФ урока. Схема — картинка `skhema-pomoshnik-list.png`, снятая с виджета по `TEKST.drakonPomoshnikList`; поменяли схему — переснять.
- `shpargalka.html` — стр. 1 — шпаргалка по минутам; стр. 2–3 — конспект учителя (что говорю про граф и ДРАКОН), ключи, «если…».
- `tehkarta.html` (+ `tehkarta.css`, `tehkarta.js`) — техкарта по форме 9070 словаря команды (А4 альбомный, 9 этапов).
- `tekst.js` — все тексты урока: примеры, заготовки синтеза, схема, конспект ДРАКОН-ГРАФ, шкала. Их читают все страницы.
