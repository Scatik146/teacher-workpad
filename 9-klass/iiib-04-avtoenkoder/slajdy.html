Алгоритм работы

функция восстановить(картинка):
    μ, σ = энкодер(картинка)          # параметры распределения
    z = μ + σ · случайный_вектор        # из стандартного нормального
    вернуть декодер(z)                  # μ и σ нужны для штрафа KL
функция создать_новую():
    z = случайный_вектор                # входной картинки нет
    вернуть декодер(z)
«Восстановить»: есть картинка
«Создать»: входа нет
Случайный вектор даёт новизну

Зона рисования (офлайн-режим)
  1. Вариационный автоэнкодер (VAE) — нейросеть, сжимающая данные в вероятностное латентное представление и восстанавливающая их обратно.
  2. Энкодер — часть сети, которая по входным данным выдаёт параметры распределения сжатого представления: центр и разброс.
  3. Декодер — часть сети, восстанавливающая данные из сжатого представления.
  4. Латентное пространство — многомерное пространство сжатых признаков, в котором закодированы данные.
  5. Промпт — текстовый запрос, описывающий желаемое изображение.
  6. Генеративная модель — модель, создающая новые данные на основе обученного распределения.
  7. Реконструкция — восстановление исходных данных из латентного представления.
  8. KL-дивергенция — мера различия между двумя распределениями вероятностей.
  9. Эмбеддинг — числовое представление текста или объекта.
  10. Функция потерь — мера ошибки, которую обучение уменьшает.
  11. Генерация — создание нового изображения моделью, а не восстановление уже показанного.
Размытым бывает код-описание, а не обязательно картинка; размытость результата — отдельное свойство модели.
