# Текстовая запись дракон-схем в md (блок `дракон`)

Версия 1.0 от 14.11.2026. Запись утверждена учителем 13.11. Разбор книг и обоснование — `docs/research/08` (§ 4–9) и `09` (§ 1–2).

**Принцип.** Текст нужен, чтобы ввести схему, а читают картинку. Язык ДРАКОН не меняется: программа строит по тексту каноническую схему (виджет Митькина, обёртка `drakon-shema`). Служебные слова на картинку не попадают.

## 1. Лексика (общая с блоками `конспект` и `мат`)
- Блок: ```` ```дракон ```` или ```` ```drakon ````. Одна строка — одна икона.
- Вложение задаётся сдвигом на 2 пробела (Tab = 2 пробела).
- Строка без ключевого слова — это **Действие**.
- Ключевое слово стоит в начале строки и заканчивается двоеточием. Пишется строчными буквами, «ё» = «е». У каждого слова есть английский синоним.
- `# …` — пояснение автора, на схему оно не попадает. `\` в начале строки отменяет ключевое слово: `\вопрос: это действие`.
- `…` или пустая икона — место, которое ученик заполнит сам (заготовка для сборки).

## 2. Словарь

| Запись (рус. / англ.) | Икона на схеме | Короткий формат обёртки | Есть |
|---|---|---|---|
| `название:` / `title:` | Заголовок | `nazvanie` | ✓ |
| *обычная строка* | Действие | `'текст'` | ✓ |
| `вопрос:` или `если:` / `question:`, `if:`, под ним `да:` / `yes:` и `нет:` / `no:` | Вопрос (Да — вниз, Нет — вправо) | `vopros, da, net` | ✓ |
| `выбор:` / `select:`, под ним `вариант:` / `case:` | Выбор и Варианты | `vybor, varianty` | ✓ |
| `пока:` / `while:` + тело со сдвигом | цикл ПОКА (продолжаем при Да) | `poka, shagi` | ✓ |
| `пока нет:` / `while not:` | цикл ПОКА (продолжаем при Нет) | — | — |
| `делать:` / `do:` + тело, затем `пока:` или `до:` / `until:` | цикл ДО (вопрос внизу) | `delat, poka` | ✓ (`до:` — нет) |
| `для:` / `for:` + тело | цикл ДЛЯ: всё в верхней крышке; нижнюю «Конец цикла k» программа пишет сама; свой текст — `низ:` / `end:` | `dlya, niz` | ✓ |
| `ввод:` / `input:`, `вывод:` / `output:`; двухэтажный: `ввод: Получи \| данные` | Ввод, Вывод | `vvod`, `vyvod` | ✓ (простой) |
| `комментарий:` / `comment:` | Комментарий | `kommentarij` | ✓ |
| `выход из цикла` / `break` | линия в точку сразу после цикла | `vyhod` | ✓ |
| `к следующему шагу` / `continue` | линия к нижней крышке цикла | `dalshe` | ✓ |
| `конец` / `end` | линия к Концу (только в примитиве) | `konec` | ✓ |
| `ветка:` / `branch:` | Имя ветки (силуэт) | `vetki[].imya` | ✓ |
| `→ Имя ветки` / `-> Branch` | Адрес; если адрес ведёт на свою ветку, получается веточный цикл | — | — |
| `@имя` и `→ @имя` | слияние в точку **ниже** по той же ветке (схемы «И», «ИЛИ», вертикальное объединение) | — | — |
| `одновременно:` / `parallel:`, дорожки `- …` | параллельные действия | — | — |
| `время:` / `time:` (строка со сдвигом под иконой) | Время или Синхронизатор сбоку | — | — |
| `пауза:` / `pause:` | Пауза | — | — |
| `таймер:` / `timer:` | Таймер | — | — |
| `вставка:` / `insert:` | Вставка | — | — |
| `полка: верх \| низ` / `shelf:` | Полка | — | — |

«Есть» — уже работает в коротком формате обёртки (JS-объект). Разборщик строк ✓: `lib/drakon-shema/zapis.js` (`DrakonZapis.razobrat(текст)` → `{shema, oshibki}`), проверка — `node tools/drakon-zapis-test.mjs`. Принято при проверке: `→`/`->` — адрес только в начале строки; `#` не после пробела — часть текста; после `да:`/`нет:` в той же строке — один шаг любой иконы, кроме вопроса, выбора и цикла.

Правила проверки (подсказки ученику, как в ГРАФе): у вопроса есть и `да:`, и `нет:` (пустая ветка разрешена); у выбора не меньше двух вариантов; переходы `выход из цикла`, `к следующему шагу`, `конец` стоят последней строкой в ветке ответа; `→ @имя` ведёт только вниз; слова «и», «или», «не» в вопросе — подсказка «разбей на цепочку вопросов».

## 3. Примеры

```дракон
название: Сумма цифр
ввод: n
s = 0
пока: n > 0
  s = s + n % 10
  n = n // 10
вывод: s
```

```дракон
название: Приручаем попугая
ветка: Учимся брать корм с ладони
  Положи на ладонь зёрна
    время: Утром
  вопрос: Попугай ест с ладони?
    да: → Учимся сидеть на руке
    нет: → Учимся брать корм с ладони    # веточный цикл
ветка: Учимся сидеть на руке
  одновременно:
    - Подставь руку
    - Говори с попугаем
  пауза: 2 мин
  → Конец
```

```дракон
название: Можно забить гвоздь?
вопрос: Есть молоток?
  нет: → @дальше
вопрос: Есть гвоздь?
  нет: → @дальше
Забей гвоздь
@дальше
Убери инструменты
```

## 4. Ступени
- **5–6 класс:** действие, вопрос, выбор, ввод и вывод, комментарий, циклы ПОКА и ДО, ветки и адреса, веточный цикл, пауза, время сбоку, параллельные действия.
- **7–9 класс (программирование):** цикл ДЛЯ, `выход из цикла`, `к следующему шагу`, `конец`, слияние `@имя` (логика «И»/«ИЛИ»), двухэтажные ввод и вывод.
- **Старшие:** таймер, синхронизатор, вставка, полка.

## 5. Не поддерживаем
Метки и переходы вверх (goto), `return` (в Python значит другое), параллельные процессы (Пуск, Останов), цикл ЖДАТЬ и переключающий цикл (пока нет), несколько входов в схему.

## 6. Решения учителя 13.11
1. `если:` — синоним `вопрос:` (`if:`); двоеточие после ключевого слова обязательно.
2. Знак «?» в конце условия вопроса и цикла дописывает программа (ученик может не ставить). Так проще переводить код в текстовую запись.
3. Конец: в силуэте — адрес `→ Конец`, в примитиве — слово `конец`.
4. Пустое `низ:` (или из одних пробелов) — как будто строки нет: нижняя крышка получает «Конец цикла k»; написанное дважды `низ:` — ошибка, даже если первое пустое.
