# Брифинг — старт по одной фразе

Учитель пишет «начинаем брифинг» и ничего не ищет. Всё находит Claude.

## Старт (без вопросов учителю)
1. `add_repo` Scatik146/drakon-graf (push), `git clone --depth 1` в `/home/claude/drakon-graf`.
2. Найти стартовое сообщение: самый свежий файл `docs/komanda/brifing/*-start.md` (по дате в имени). Нет за сегодня — взять из `docs/komanda/SOSTOYANIE.md` верхний блок «ОБНОВЛЕНО …» и раздел повестки `docs/komanda/BRIFING.md` под сегодняшней датой (только его, через grep/sed).
3. Прочитать **только** это: стартовое сообщение, верхний блок SOSTOYANIE.md, незачёркнутые пункты «В повестку» в BRIFING.md под сегодняшней датой. Журнал README.md — только § 5 (открытые вопросы), через sed.
4. Ответить учителю одним сообщением:
   - «Мы здесь» — 2–3 строки;
   - повестка — нумерованный список (зачёркнутое и «решено» — не включать);
   - первый пункт: суть, варианты, рекомендация Claude, вопрос учителю.

## Ход
- По одному пункту. Порядок обсуждения команды: ответы всех → общий разбор → голосование → решает учитель. GLM — «Зануда» (проверка фактов), Алиса — генеративный взгляд, DeepSeek — «молчаливый Джо» (только голос). Для GLM и Алисы — самодостаточный промпт с полным контекстом; все видят ответы всех.
- Решение учителя → строкой в журнал README.md § 4; открытый вопрос → § 5; ход → BRIFING.md под датой. SOSTOYANIE.md не писать — его составляет Алиса (вставить блок можно по просьбе учителя, «как руки»).
- Параллельные чаты не меняют статусы пунктов брифинга — только исполнитель темы или координатор.
- Большая тема → отдельный чат: дать учителю готовое стартовое сообщение для него.

## Конец
- Итог одной строкой в BRIFING.md, коммит, push.
- Последней строкой ответа — «Для Алисы: …».
- Дальше — навык `ekonomnaya-sessiya` (резерв навыков и памяти, если менялись).
