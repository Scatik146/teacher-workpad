# Графические конспекты ДРАКОН-ГРАФ

Конспект пишется текстом, картинку рисует библиотека drakon-graf (язык ГРАФ — В. Д. Паронджанов; инициатор — Г. А. Гуленков; расширенная версия и библиотека — С. Н. Веснин). Нужен для главных мыслей урока в тетрадь: понятия, правила, цепочки, сравнения. Для алгоритмов и ветвлений — навык `drakon-shema`.

Сайт и порядок публикации — навык `teacher-workpad-sajt` (клон `Scatik146/teacher-workpad`, правила в его `CLAUDE.md`).

## Где лежит
- `lib/drakon-graf/drakon-graf.min.js` — библиотека (0.9.1), `konspekt.js` — обвязка сайта, `fonts/` — PT Serif, PT Mono.
- `lib/drakon-graf/drakon-graf.mjs` — для Node; `tools/konspekt.mjs` — проверка без браузера.
- `lib/drakon-graf/index.html` — «Проба конспекта»; онлайн-генератор (печать, PNG, SVG, ссылка) — https://scatik146.github.io/drakon-graf/generator/.
- Справочник языка — репозиторий `Scatik146/drakon-graf`: `docs/graf/шпаргалка_ученика.md`, `справочник_учителя.md`.
- Обновить библиотеку: в репо drakon-graf `node tools/bundle.mjs` (esbuild есть в `/opt/npm-tools`), скопировать `dist/drakon-graf.min.js` и `.mjs` в `lib/drakon-graf/`.

## Язык по ступеням
- **5–6 класс:** `тема: …` (овал); `- пункт`; `1. шаг`; `вопрос -> ответ` (запомни); `опр: Слово -> Это …`; `пример: [часть]{подпись} → [часть]{подпись}` (белая рамка — разберись, кружки с выносками); `# заметка` не рисуется.
- **7–9:** `одно >< другое` (не путать); `связка: А | Б`; `стрелка: Значит, …`; `правило → часть: …`; выкладка `  => шаг  {почему}`; `---` — новая схема.
- **10–11:** таблица-сравнение (Шеренга): `связка: А | Б | В` + строки `признак -> а | б | в`; `контрпример:`, `выноска:`, `код:`, `$$формула$$`.
- Ключевые слова — маленькими буквами в начале строки. Правило для детей: жёлтое — запомни, белое — разберись.
- Проверенные образцы: цепочка `пример: [звук]{микрофон} → [кадры]{шумодав} → …` + `Что мешает? -> …`; сравнение `связка: Распознавание | Синтез` + `Что на входе? -> звук | текст`.

## Встроить в приложение урока
```html
<script src="../../lib/drakon-graf/drakon-graf.min.js"></script>
<script src="../../lib/drakon-graf/konspekt.js"></script>
<script>Konspekt.draw(el, текст, { class: 5, width: 760 });</script>
```
- `Konspekt.draw` возвращает `{hints, scheme, height}`; `Konspekt.svg`, `Konspekt.hints(text)` — проверить ввод ученика; `theme:'bw'` — для печати.
- SVG светлый: на тёмном приложении ставить на «лист бумаги» (`background:#fffdf7`).
- Текст конспекта в коде помечать `/*конспект*/` перед строкой-шаблоном; тексты держать в общем `tekst.js` урока, чтобы игра и канва совпадали.
- Детская механика, проверенная на уроке «Эхо-Узел» (5 кл.): на тетрадных точках показать **готовый образец** + легенду фигур (овал, белая рамка, кружок, жёлтая выноска, флажок), в финале — таблица из выпадающих списков, программа сразу рисует схему ученика.

## Страница учителя, документ, лист для печати
- Страница учителя: `<pre><code class="language-конспект">…</code></pre>` + `Konspekt.run({class:N})`, либо `Konspekt.draw` в нужные блоки.
- Лист для вклейки в тетрадь: `theme:'bw'`, `width:640` (≈170 мм), пунктир «✂» между схемами, `@page{size:A4}` (образец — `5-klass/ekho-uzel/vkleyka.html`). Ссылку на него можно прятать в служебное меню Ctrl+Alt+M.
- Картинка для документа: `node tools/konspekt.mjs файл.txt -o рисунок.svg` (шрифты ссылкой на `lib/drakon-graf/fonts`); для PNG — снять скриншот страницы headless Chrome.

## Проверка — обязательно
- `node tools/konspekt.mjs --scan путь/к/файлу --class N` — ноль подсказок «важно»; `-e "текст"` — одна строка.
- Посмотреть рисунок в браузере (headless Chrome `/usr/bin/google-chrome` + Python playwright): нет наложений, подписи читаются.

## Авторство
Не удалять: `lib/drakon-graf/NOTICE`, шапка `konspekt.js`; на страницах-пробах — строка с тремя авторами.
