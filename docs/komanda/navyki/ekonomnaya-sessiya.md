# Экономная сессия

Учитель платит лимитом. Дорого стоят: чтение больших файлов и книг, скриншоты, повторные запуски браузера, длинная история разговора.

## Начало
0. День начинается с чата «Брифинг» (`drakon-graf/docs/komanda/BRIFING.md`: стартовое сообщение, журнал, повестка). Рабочие чаты — по одной задаче, их итог одной строкой — в `BRIFING.md` под датой.
1. Склонировать только нужный репозиторий (`--depth 1`).
2. Прочитать **только** `Scatik146/drakon-graf/docs/komanda/SOSTOYANIE.md` (страница). Журнал решений `README.md` и разборы `docs/research` — только нужный раздел, через grep.
3. Спросить или сформулировать **одну задачу сессии** и критерий «готово». Новая большая тема — в следующую сессию, предложить записать её в «Следующие шаги».

## Во время работы
- Читать файлы кусками (grep, sed -n), не целиком. Не выводить большие файлы и логи в разговор.
- Скриншот: один на проверку, масштаб 0.5, обрезать нужную область. Сначала проверки командами и тестами (`tools/*.mjs`), скриншот — последним.
- Чтение книг, статей, чужих репозиториев, рутинный код по готовому описанию, тексты для детей — **делегировать**: написать задание по шаблону `teacher-workpad/docs/komanda/zadaniya/SHABLON.md` (файл `zadaniya/NNN-имя.md`) и отдать учителю для помощника. Claude оставляет себе архитектуру, решения, проверку чужих PR.
- Распределение по помощникам — в `drakon-graf/docs/komanda/README.md`.
- Короткие ответы учителю: итог и вопросы, без пересказа шагов.

## Конец (обязательно)
1. Обновить `SOSTOYANIE.md` (не длиннее страницы): что сделано, следующие шаги.
2. Решения учителя — строкой в журнал `README.md`, раздел 4; открытые вопросы — раздел 5.
3. Если менялись навыки — копии в teacher-workpad `docs/komanda/navyki/` и предложение обновить навык.
4. Всё отправить в GitHub; в ответе — что сделано и что ждёт решения.
