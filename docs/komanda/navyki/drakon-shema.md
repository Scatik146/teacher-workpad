# Дракон-схемы

Когда брать: алгоритм, порядок действий, ветвления, «что делать, если…», циклы, программы. Для главных мыслей урока в тетрадь — навык `graficheskij-konspekt`. Сайт и публикация — навык `teacher-workpad-sajt`.

## Где лежит
- `lib/drakonwidget/drakonwidget.js` — виджет Степана Митькина 1.5.7, Unlicense. **Не менять.**
- `lib/drakon-shema/drakon-shema.js` — обёртка `DrakonShema` (работает и в Node: `vNative`, `iz`, `proverit`, `loopParts`).
- `lib/drakon-shema/index.html` — проба; `tools/drakon-shema.mjs` — проверка.
- Шрифты и вид как у ДРАКОН-ГРАФ (PT Serif / PT Mono из `lib/drakon-graf/fonts`, обводка `#993300`, жёлтое `#FFFF99` — заголовок, конец, ветки, комментарии, текст по центру). Папка `lib/drakon-graf` должна быть рядом.

## Встроить
```html
<script src="../../lib/drakonwidget/drakonwidget.js"></script>
<script src="../../lib/drakon-shema/drakon-shema.js"></script>
<script>
  DrakonShema.pokazat(el, shema);                                  // просмотр
  const d = DrakonShema.pokazat(el, zagotovka, { rezhim:'sborka', klyuch:'урок-схема-1',
    razreshit:['dejstvie','vopros','vybor','vvod','vyvod','cikl','vetka','kommentarij'], izmenenie: sh => … });
</script>
```
- Объект: `poluchit()` — короткий формат, `json()` — родной, `ochistit()`, `ready` — промис.
- Настройки: `kod:true` — блоки шрифтом PT Mono (программирование); `vysota` (px или `'auto'`); `vpisat:false` — не ужимать.
- Высота: в просмотре рамка сама по высоте схемы, если у элемента нет `style="height:…"`; в сборке без высоты — 480 px.
- Сборка: двойной щелчок — текст (Enter — сохранить, Esc — отмена), правая кнопка — меню по-русски, кнопки сверху вставляют блок через жёлтые кружки; после вставки окно ввода открывается само.

## Короткий формат
```js
/*схема*/{ nazvanie:'Проверка пароля', shagi:[
  { vvod:'Пароль' },                                   // ввод: вырез-стрелка слева
  'Действие',
  { vopros:'Пароль верный?', da:[…], net:[…] },         // Да — вниз, Нет — вправо
  { vybor:'Время суток?', varianty:{ 'Утро':[…], 'Вечер':[…] } },
  { dlya:'Для k от 1 до 10', shagi:[…] },               // ДЛЯ по канону: всё в верхней крышке, нижняя «Конец цикла k» — сама
  { poka:'Есть грязная посуда?', shagi:[…] },           // while: Да — тело справа и назад, Нет — выход вниз
  { delat:[…], poka:'Пароль неверный?' },               // do-while: тело, вопрос внизу
  { vyvod:'Сообщение' },                                // вывод: треугольник справа
  { kommentarij:'…' } ] }
```
- Силуэт: `{ nazvanie, vetki:[ {imya, shagi:[…]}, … ] }`.
- Верхняя крышка ДЛЯ: `'Для каждого ученика в списке класса'`, `'for x in range(n)'`, `'i = 0; i < n; i++'`. Нижнюю программа пишет сама («Конец цикла k», без имени — «Конец цикла»); свой текст — `niz:'…'`. Старое `po` приклеивается к верхней крышке; сохранённые у учеников схемы со старой нижней крышкой читаются так же.
- Переходы — последним шагом в ветке вопроса или варианта: `{vyhod:true}` — «выход из цикла» (break, линия в точку сразу после цикла), `{dalshe:true}` — «к следующему шагу» (continue), `{konec:true}` — «конец» (только в примитиве). return не вводим. Ветка с переходом в цикле ДЛЯ уходит вправо сама (иначе виджет падает); в циклах «пока» — как записана.
- Заготовка для сборки: пустой блок — `''` или `'…'`, помечать `/*заготовка*/`. Кнопка `cikl` вставляет только for; циклы «пока» давать готовыми в заготовке.
- Тело цикла «пока» в ДРАКОНе всегда справа — по главной линии вниз не рисуется. Вложенные for — две крышки подряд: это правильно.

## Родной формат (если нужно руками)
`items`: id → `{type, content, one, two, branchId, flag1}`. Первая `branch` (branchId 0, content '' для одной ветки), в конце `end`. `question`: `one` — вниз, `two` — вправо, `flag1:1` — вниз «Да». `select.one` → первый `case`, `case.two` → следующий. Силуэт: хвост ветки указывает на id следующей `branch`. for: `loopbegin` → тело → `loopend` (у обоих `content`; ранний выход — ветка `two` вопроса ведёт в блок после `loopend`, `flag1:0`). while/do-while: узел `arrow-loop`, к нему возвращается ветка `two` вопроса, `flag1:0`. Ввод/вывод — `simpleinput` / `simpleoutput`.

## Проверка — обязательно
- `node tools/drakon-shema.mjs --scan путь/к/файлу` — у вопросов обе ветки, у выбора ≥2 вариантов, нет пустых блоков в просмотре, перевод туда-обратно совпадает.
- Открыть в браузере (headless Chrome + playwright, файл по file://): Да/Нет на местах, консоль чистая; для сборки — правка текста, вставка блока, перезагрузка сохраняет, «Начать заново».
- Координаты блоков для тестов: `d.widget.visuals.nodes[id]` (x, y — центр; минус `visuals.scrollX/Y`, умножить на `zoomFactor`); элемент прокрутить в видимую область перед кликами.

## Ограничения виджета (обёртка уже обходит)
Служебный журнал в `console.log` — глушится; кружок «параметры» у «Действия» — скрыт; после вставки нет окна ввода — открывается обёрткой. Вставка через кружки ~15 px — на интерактивной доске пальцем может быть мелко.
