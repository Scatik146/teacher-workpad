# Задание 011 (блок 6, простое): наши языки — пароль

**Блок тестов навыка:** 6 из 6, простой уровень (студенту 10–15 минут) · **Исполнители:** Claude, Алиса и DeepSeek (скрипт `ii-komanda/tools/test_koda.py`), GLM (вручную) · **Проверяет:** команды — скрипт, «руками» — учитель, «чтением» — Марьям

## Цель
Проверить, что модель пишет на наших языках так же уверенно, как на чужих: готовую мысль — заданной схемой блока `конспект`, алгоритм с одним циклом и одним вопросом — блоком `дракон`, из которого получается работающая программа.

## Прочитать
- `docs/komanda/TRI-STILYA-ODNIM-TEKSTOM.md` — навык и шпаргалки блоков `дракон` и `конспект` (Приложение 2). Больше ничего не нужно.

## Что сделать
Один файл `parol-list.md` — ДРАКОН-лист. В нём по порядку:

1. Блок `дракон`: алгоритм «Есть ли цифра в пароле». Ввод — пароль строкой (`ввод: parol = input()`); один цикл по символам пароля (`для:` с записью `for … in …`) и в нём один вопрос «символ — цифра?»; вывод — `True`, если в пароле есть хотя бы одна цифра, иначе `False`. Текст в иконах — на Python: из блока получается программа.
2. Блок `конспект`: готовая мысль «Надёжный пароль — это всё сразу: хотя бы одна цифра, хотя бы одна заглавная буква, хотя бы один спецсимвол». Схема — **батарея**: один запоминатель «Надёжный пароль -> …», под ним три пункта `- …` со сдвигом.
3. Тест: строка `пример:` (пароль, где программа печатает `True`) и строка `контрпример:` (пароль и неверный для него вывод).

## Нельзя
- Ключевые слова, которых нет в шпаргалках; `вставка:`, адреса веток, параллельные действия.
- Писать программу на Python отдельно — программа получается только из листа.
- Не знаешь — пиши «не знаю, надо проверить».

## Сдать файлы
`parol-list.md`

Перед сдачей проверь: каждый файл из «Сдать файлы» есть в ответе, у каждого — свой блок кода. Файл целиком, строкой выше — имя файла; файл в ограде из четырёх обратных кавычек (внутри него блоки с тремя). После файла — «пополнение словаря» в формате навыка: новые слова, если они есть (имена переменных — не слова). Весь ответ — не длиннее 50 строк.
