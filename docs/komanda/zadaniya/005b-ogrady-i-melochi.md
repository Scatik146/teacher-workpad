## Сделать

### 1. Ограда `~~~` — поддержать (решение учителя 14.11)
`--scan` находит блок по строке ограды ```` ``` ```` **или** `~~~`, затем `дракон`/`drakon`, после них можно пробел и слова. Закрывает блок строка из **тех же трёх знаков**, что открыли его (с пробелами по краям). Строка ```` ``` ```` внутри `~~~`-блока — обычный текст блока, и наоборот.

### 2. Незакрытая ограда — ошибка, код 1
Если до конца файла закрывающей строки нет, блок попадает в вывод с одной ошибкой: `строка F: ограда блока «дракон» не закрыта`, где F — строка ограды. Текст такого блока не разбирается (где он кончается, неизвестно), название — `«»`. Блоки выше проверяются как обычно.

**Таблица (вывод сравнивается целиком; ⏎ — перевод строки, файл кончается ⏎):**

| файл | stdout | код |
|---|---|---|
| ```` ```дракон⏎шаг⏎ ```` | `— #1 «» · просмотр (строка 1)`⏎`   строка 1: ограда блока «дракон» не закрыта` | 1 |
| ```` ```дракон⏎шаг⏎```⏎⏎```дракон⏎вопрос: А⏎ ```` | `— #1 «» · просмотр (строка 1) · ошибок нет`⏎`— #2 «» · просмотр (строка 5)`⏎`   строка 5: ограда блока «дракон» не закрыта` | 1 |
| `~~~дракон⏎вопрос: А⏎~~~⏎` | `— #1 «» · просмотр (строка 1)`⏎`   строка 2: в вопросе «А» нет ветки «да:»`⏎`   строка 2: в вопросе «А» нет ветки «нет:»` | 1 |
| `~~~дракон⏎название: Б⏎```⏎шаг⏎~~~⏎` | `— #1 «Б» · просмотр (строка 1) · ошибок нет` | 0 |
| ```` ```drakon сборка⏎…⏎```⏎ ```` | как сейчас: «пустой блок», код 1 (сборки в блоке нет — так и задумано) | 1 |

Тест «Находка: незакрытая ограда — блок не добавляется, код 0» замени проверкой первой строки таблицы.

### 3. Позиции блоков при CRLF
Порядок блоков в выводе — по месту в файле. Сейчас смещение строки считается как `длина + 1`, и при переводах строк `\r\n` позиция ограды уезжает. Считай позицию ограды по исходному тексту (с учётом `\r`). Тест: файл с `\r\n`, сначала блок ```` ```дракон ````, потом `/*схема*/ {shagi:['a']}` → в выводе `#1` — блок, `#2` — схема.

### 4. `podgotovit`: `shema` — всегда объект
Если `zapis.js` не подключён или `razobrat` бросил исключение — `shema: {}`, а не `null` (как и сказано в 005: «`shema` возвращается всегда»). Остальное без изменений.

### 5. Подсказка `drakon-shema.mjs` без аргументов
Верни подробности, которые пропали в 005, и добавь новое. Начало файла:
```
#!/usr/bin/env node
// Проверка дракон-схем в коротком формате (lib/drakon-shema) без браузера.
//
//   node tools/drakon-shema.mjs схема.json [--sborka]
//   node tools/drakon-shema.mjs --zapis файл [--sborka]   весь файл — текстовая запись
//   node tools/drakon-shema.mjs --scan путь/к/файлу   схемы с меткой /*схема*/ (просмотр) и /*заготовка*/ (сборка),
