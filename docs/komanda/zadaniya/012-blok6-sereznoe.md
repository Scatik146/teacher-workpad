# Задание 012 (блок 6, серьёзное): наши языки — число R по числу N

Проверить наши языки на настоящей задаче: модель сама выбирает схемы конспекта, строит силуэт с циклом и выбором, пишет знания с рекурсивным правилом — и всё это одним ДРАКОН-листом, из которого получается работающая программа.

## Задача
На вход алгоритма подаётся натуральное число N. Алгоритм строит по нему новое число R следующим образом: 1. Строится шестнадцатеричная запись числа. 2. Далее, эта запись обрабатывается по следующему правилу: а) Если цифр B в ней чётное количество, то к этой записи слева дописывается 1. б) Если цифр B в ней нечётное количество, то к этой записи справа дописывается 1. Полученная таким образом запись является шестнадцатеричной записью искомого числа R. Например, возьмём число 91. Строим шестнадцатеричную запись числа: 5B. Цифра B в нём одна – нечётное количество, значит, единицу дописываем справа. Итоговое число 5B1 переводим в десятичную систему – 1457. Число 1457 и является результатом работы алгоритма. Определите количество натуральных чисел N, для которых результатом выполнения алгоритма может стать двухзначное число.

## Что сделать
Файл `r-list.md` — ДРАКОН-лист. В нём по порядку:

1. **Блок `дракон` — силуэт** «Число R по числу N»: ветки (`ветка:`) — ввод, шестнадцатеричная запись, подсчёт цифр B, дописать единицу. В силуэте — хотя бы один цикл и один `выбор:` (по `k % 2`, варианты `0` и `1`). Ввод — `ввод: n = int(input())`, вывод — число R (`вывод: int(h, 16)`). Текст в иконах — на Python. Подсказки: цикл по символам — `для: for c in h`; цикл «пока» — `пока: m > 0`; цифру по остатку можно взять так: `'0123456789ABCDEF'[m % 16]`.
2. **Три блока `конспект`** — три куска содержания; схему каждого выбери сам (схема — по шпаргалке, у трёх кусков схемы разные):
   - что такое шестнадцатеричная запись (основание, цифры, чему равна цифра B);
   - пример из условия по шагам: 91 → 5B → 5B1 → 1457;
   - два случая правила рядом: чётное и нечётное количество B — куда дописывается единица.
3. **Блок `конспект` в режиме знаний** — порядок цифр: факты `связь 9 -> A: перед`, `связь A -> B: перед`, `связь B -> C: перед`; два правила отношения `младше` — простое и рекурсивное («Х младше У, если Х перед У» и через промежуточную цифру); `пример: 9 младше C`, `контрпример: C младше 9`, `запрос: кто младше C`. Цифры пиши как есть (`9`, `A`, `B`, `C` — латиница); переменные — русскими буквами **Х, У, З** (не А, Б, В: их не отличить от латинских цифр).
4. **Тест** листа — не меньше двух строк `пример:` (ввод N → вывод R) и одна `контрпример:`.

И отдельно файл `otvet.txt` — одно число: ответ задачи.

## Нельзя
- Ключевые слова и схемы, которых нет в шпаргалках; `вставка:`, адреса веток, параллельные действия; «или» и «не» в правилах.
- Писать программу на Python отдельно — программа получается только из листа.
- Не знаешь — пиши «не знаю, надо проверить».
