# Задание 017 (блок 3, простое): Forth — номер пропуска

**Блок тестов навыка:** 3 из 6, простой уровень (студенту 10–15 минут) · **Исполнители:** Claude, Алиса и DeepSeek (скрипт `ii-komanda/tools/test_koda.py`), GLM (вручную) · **Проверяет:** команды — скрипт, «чтением» — Марьям

## Цель
Проверить стиль «по-фортовски» на настоящем Forth: дописать словарь маленьких слов на готовые нижние слова, слои снизу вверх, у каждого слова — строка «слово: что делает» и стековый комментарий; приложить ДРАКОН-лист.

## Прочитать
- `docs/komanda/TRI-STILYA-ODNIM-TEKSTOM.md` — навык, правила дословно, шпаргалки блоков. Больше ничего не нужно.

## Задача
Номер пропуска (до 9 цифр) верен, если сходится контрольная цифра по алгоритму Луна. Идём по цифрам справа налево: первую цифру берём как есть, вторую удваиваем (если вышло больше 9 — вычитаем 9), третью как есть, четвёртую удваиваем и так далее. Номер верен, если сумма делится на 10. Пример: 18 — верный (8 + 2 = 10), 19 — неверный.

## Готовые слова (менять нельзя, переписать в начало файла как есть)
```forth
\ ВДВОЕ: удвоить цифру по правилу Луна
: ВДВОЕ ( цифра -- цифра' ) 2* DUP 9 > IF 9 - THEN ;
\ ЦИФРА: отделить последнюю цифру числа
: ЦИФРА ( n -- n' цифра ) 10 /MOD SWAP ;
```

## Что сделать
1. Файл `propusk.fs` — готовые слова и ещё четыре:
   - `ПАРА ( сумма n -- сумма' n' )` — прибавить к сумме две последние цифры (первую как есть, вторую — через `ВДВОЕ`) и отбросить их;
   - `СУММА-ЛУНА ( n -- сумма )` — сумма по Луну для всего номера;
   - `ВЕРНЫЙ? ( n -- флаг )` — флаг истины (`-1`), если сумма делится на 10, иначе `0`;
   - `ПРОВЕРИТЬ ( n -- )` — печатает `верный` или `неверный`.
2. Файл `propusk-list.md` — ДРАКОН-лист к `СУММА-ЛУНА` и `ВЕРНЫЙ?`: блок `дракон` по порядку действий (цикл «пока номер не 0», внутри — две цифры, вторая через вопрос «больше 9?»; потом вопрос «делится на 10?»); ниже — тест: строки `пример:` и `контрпример:` вида `- пример: 18 ПРОВЕРИТЬ → верный`.

## Правила стиля (кратко, полностью — в навыке)
Над каждым словом — строка `\ ИМЯ: что делает` (имя — то же, что у слова); у каждого слова — стековый комментарий `( до -- после )`; одно слово — одно действие, одна строка определения (до 15 строк — потолок); вложенность `IF`/`BEGIN` — не глубже 2. Стандартные слова — заглавными (`DUP`, не `dup`); имена своих слов — русские. Верхнее слово читается как фраза и не лезет в цифры.

## Нельзя
- Менять готовые слова; подключать что-либо (`INCLUDE`, `REQUIRE`); переменные (`VARIABLE`, `VALUE`) — хватит стека.
- Выдумывать слова Forth. Не знаешь, есть ли слово, — пиши «не знаю, надо проверить».

## Сдать файлы
`propusk.fs`, `propusk-list.md`

В первой строке ответа — какая ты модель. Каждый файл целиком, в своём блоке кода, строкой выше — имя файла. `propusk-list.md` — в ограде из четырёх обратных кавычек. После файлов — «пополнение словаря» (новые слова Forth) в формате навыка. Весь ответ — не длиннее 60 строк.
