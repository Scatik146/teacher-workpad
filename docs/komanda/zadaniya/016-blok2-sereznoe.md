# Задание 016 (блок 2, серьёзное): Prolog — куда дошёл файл

**Блок тестов навыка:** 2 из 6, серьёзный уровень (студенту полчаса-час) · **Исполнители:** Claude, Алиса и DeepSeek (скрипт `ii-komanda/tools/test_koda.py`), GLM (вручную) · **Проверяет:** команды — скрипт, «чтением» — Марьям

## Цель
Проверить стиль «по-прологовски» на трудном: рекурсивное правило, сбор ответа `findall`, отрицание `\+` на связанных переменных; и «по-графовски»: ДРАКОН-схема «как проверяется правило».

## Прочитать
- `docs/komanda/TRI-STILYA-ODNIM-TEKSTOM.md` — навык, правила дословно, шпаргалки блоков. Больше ничего не нужно.

## Данные (менять нельзя, имена выдуманные)
Тимур передал файл Глебу, Глеб — Вере, Вера — Дине. Тимур передал файл ещё и Ире, Ира — Олегу. Других передач нет, по кругу файл не ходил.

Отношение-факт: `передал(кто, кому)`. Правила (слова даны, придумывать другие отношения нельзя):
- `дошёл(А, Б)`: файл от А дошёл до Б — А передал Б сам или передал тому, от кого файл дошёл до Б;
- `получатели(А, Список)`: Список — все, до кого дошёл файл от А (порядок любой);
- `дошёл_через_других(А, Б)`: файл от А дошёл до Б, но сам А Б не передавал;
- `общий_источник(А, Б)`: есть человек, от которого файл дошёл и до А, и до Б, и А с Б — разные люди («разные» — `А \= Б`).

## Что сделать
1. Файл `peredacha.pl` — чистый Prolog: ровно пять фактов; `дошёл` — двумя предложениями, `получатели`, `дошёл_через_других` и `общий_источник` — по одному. Имена отношений — русские, атомы — строчными (`тимур`), переменные — заглавными русскими буквами. Для `дошёл`, `дошёл_через_других` и `общий_источник` — по две строки-комментария: `% пример: цель.` (должна выполняться) и `% контрпример: цель.` (не должна).
2. Файл `peredacha-list.md` — ДРАКОН-лист: блок `дракон` — схема «как проверяется `дошёл(А, Б)`»: что движок пробует первым, что вторым и когда ответ «нет» (текст в иконах — по-русски); ниже — тест (строки `пример:` и `контрпример:`, те же, что в `.pl`).

## Нельзя
- Менять данные; `!`, `->`, `;`, `assert`, `retract`, `setof`, `bagof`; больше трёх условий в правиле.
- Рекурсивный вызов крайним слева; `\+` и `\=` на переменной, которая к этому месту ещё не связана.
- Ключевые слова блоков, которых нет в шпаргалках. Не знаешь — пиши «не знаю, надо проверить».

## Сдать файлы
`peredacha.pl`, `peredacha-list.md`

В первой строке ответа — какая ты модель. Перед сдачей проверь: каждый файл из «Сдать файлы» есть в ответе, у каждого — свой блок кода. Каждый файл целиком, в своём блоке кода, строкой выше — имя файла. `peredacha-list.md` — в ограде из четырёх обратных кавычек. После файлов: по строке на каждое правило — почему оно написано именно так (что верно, а не как вычислить; почему такой порядок условий); «пополнение словаря отношений» в формате навыка. Весь ответ — не длиннее 100 строк.
