# Задание 009: тест навыка «три стиля кода» — «Кружки: кто кого учит»

**Исполнители:** Claude, DeepSeek, GLM, Алиса — каждый отдельно, одно и то же задание · **Проверяет:** Марьям (Claude) по листу проверки, смотрит учитель

## Цель
Проверить, что любая ИИ по навыку «три стиля кода» пишет код в трёх стилях и сдаёт к нему ДРАКОН-лист. Задание маленькое: важен стиль, а не объём.

## Прочитать
- `docs/komanda/TRI-STILYA-ODNIM-TEKSTOM.md` — навык, три правила дословно, шпаргалки блоков и образец ДРАКОН-листа. Больше ничего читать не нужно.

## Данные (менять нельзя)
- Мария ведёт кружок «Роботы». Олег ведёт кружок «Шахматы».
- Тимур и Вера входят в «Роботы». Глеб входит в «Шахматы».
- Имена выдуманные.

## Сделать
1. **Знания (по-прологовски, по-графовски).** Блок `конспект` в режиме знаний: факты `ведёт` и `входит` и правило «У учит Ш». Запись — как в образце:
   ```
   режим: знания
   У -> ?
   связь Мария -> Роботы: ведёт
   правило: У учит Ш, если …
   пример: …
   контрпример: …
   запрос: кто учит Веру
   ```
   Сейчас режим знаний умеет только отношения двух участников, без «или» и «не».
2. **Вопрос на честность.** Можно ли в нынешнем режиме знаний записать отношение «А одногруппник Б» (два **разных** ученика одного кружка)? Если да — запиши. Если нет — так и напиши и объясни в 1–2 строках, чего не хватает. Запись не выдумывай.
3. **Действия (по-фортовски, JavaScript).** Файл `kruzhki.js`: данные отдельно, слово `ucheniki(uchitel, dannye)` возвращает имена всех учеников учителя по алфавиту. Проверка: `ucheniki('Мария', …)` → `['Вера', 'Тимур']`; для учителя, которого нет в данных, — пустой список.
4. **Разметка и вид (HTML и CSS).** Файлы `kruzhki.html` и `kruzhki.css`: карточка учителя «Мария» — имя, кружок, список учеников. Без JavaScript.
5. **ДРАКОН-лист.** Файл `kruzhki-list.md`: блок `дракон` для слова `ucheniki`, блок `конспект` из п. 1, тест (`пример:` и `контрпример:`).
6. **Пополнение словаря** (слова JS) и **пополнение словаря отношений** — в формате из навыка.

## Нельзя
- Менять данные; подключать библиотеки и CDN; писать не по-русски (имена в коде — латиницей, комментарии — по-русски).
- Выдумывать ключевые слова блоков, которых нет в шпаргалках. Не знаешь — пиши «не знаю, надо проверить».

## Формат ответа
Один ответ, не длиннее 150 строк: четыре файла целиком, каждый в своём блоке кода с именем файла над ним (`kruzhki.js`, `kruzhki.html`, `kruzhki.css`, `kruzhki-list.md`), затем ответ на п. 2, затем два списка «пополнение словаря». Без пересказа задания. В первой строке — какая ты модель и в каком режиме работаешь.
