# Задание 006: решения 12 задач ЕГЭ на Python

**Исполнитель:** Qwen · **Проверяет:** Claude (чат 12: Python против Skulpt), ответы сверяет учитель

## Цель
Дать эталонные решения 12 реальных задач ЕГЭ по информатике — 17, 24, 26, 27, по 3 каждого номера. По ним Claude проверяет форк Skulpt (чат 12): запускает каждое решение в настоящем Python и в Skulpt и сравнивает ответы.

## Прочитать
- Условия и файлы данных — учитель вставляет в чат сам; в открытый репозиторий **их не класть**, в ответе условия **не пересказывать и не цитировать**.

## Можно менять
- Только твои файлы `ege17-1.py … ege27-3.py` (12 штук); учитель переносит их в закрытое место сам.

## Сделать
1. На каждую задачу — один `.py`, первой строкой служебный комментарий `# данные: 17.txt` (имя файла данных из условия), далее решение. Чтение — только `open(имя)`.
2. Только то, что работает в учебном Python: без внешних модулей; стандартные — `math`, `itertools`, `functools`, `fnmatch`; решения 24 и 26 — без регулярных выражений.
3. Вывод — **только ответ**: `print(ответ)` одним числом (два числа — через пробел, как в условии) **последней строкой**; никаких промежуточных print, пояснений в вывод.
4. Над ответом комментарий-подсказка: какие функции и приёмы использованы (`sorted`, `zip`, `list slicing`, `str.split` …) — для проверки Skulpt.

## Нельзя
- Класть условия, файлы или решения в репозиторий; считывать данные не через `open`; писать вывод, отличный от ответа.

## Готово, когда
- 12 файлов в ответе, у каждого `# данные:` первой строкой и `print(ответ)` последней;
- учитель запустил в обычном Python, ответ совпал с его ответом (у несовпавших — перерешать по замечанию);
- в конце ответа — таблица «файл → какие функции/модули использованы»; что в условии читалось двояко.
