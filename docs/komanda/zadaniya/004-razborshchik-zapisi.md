# Задание 004: разборщик текстовой записи дракон-схем (текст → короткий формат)

**Исполнитель:** DeepSeek (`deepseek-flash`); пока нет баланса — DeepSeek в чате, ответ — файлами целиком · **Проверяет:** Claude, сливает учитель

## Цель
Учитель и ученик пишут дракон-схему текстом (блок `дракон` в md). Нужна функция, которая превращает этот текст в короткий формат обёртки `DrakonShema`. Обёртка уже умеет рисовать короткий формат. В этом задании делаем только ту половину словаря, которая уже есть в обёртке.

- `docs/komanda/navyki/drakon-shema.md`, раздел «Короткий формат».

## Сделать
1. `lib/drakon-shema/zapis.js` — без зависимостей, работает в браузере (`window.DrakonZapis`) и в Node (`module.exports`), как сама обёртка. Функция `razobrat(tekst)` возвращает `{ shema, oshibki }`. Здесь `oshibki` — список `{ stroka, tekst }` (номер строки с 1, текст по-русски).
2. Лексика:
   - сдвиг на 2 пробела — вложение; Tab = 2 пробела; нечётный сдвиг — ошибка;
   - ключевое слово стоит в начале строки и кончается двоеточием, регистр не важен, «ё» = «е»;
   - работают английские синонимы из таблицы;
   - `#` после пробела или в начале строки — пояснение, его отбросить;
   - `\` в начале строки — строка считается Действием, `\` убрать;
   - пустые строки пропускать.
3. Правила разбора:
   - `название:` → `nazvanie`.
   - Если есть хоть одна `ветка:` → `vetki:[{imya, shagi}]`, иначе `shagi`.
   - Строка без ключевого слова → строка-Действие (`…` — тоже Действие, заготовка).
   - `вопрос:` / `если:` / `question:` / `if:` → `{vopros, da, net}`. Под ним строки `да:` / `yes:` и `нет:` / `no:` со сдвигом. Шаги ответа пишутся либо после двоеточия (один шаг в той же строке), либо строками со сдвигом ниже. Нет `да:` или `нет:` — ошибка. Пустой ответ разрешён (`[]`).
   - `выбор:` → `{vybor, varianty}`. Под ним `вариант: Имя` и шаги со сдвигом. Меньше двух вариантов — ошибка.
   - `пока:` → `{poka, shagi}` с телом со сдвигом.
   - `делать:` с телом, а сразу за ним на том же сдвиге `пока:` без тела → `{delat, poka}`.
   - `для:` → `{dlya, shagi}`. Строка `низ:` / `end:` внутри тела → `niz` (в `shagi` не попадает).
   - `ввод:` → `{vvod}`, `вывод:` → `{vyvod}`, `комментарий:` → `{kommentarij}`.
   - Строки `выход из цикла` / `break`, `к следующему шагу` / `continue`, `конец` / `end` (целиком, без двоеточия) → `{vyhod:true}`, `{dalshe:true}`, `{konec:true}`.
4. Знак «?» в конце: к тексту `vopros` и `poka` (в том числе в `{delat, poka}`) программа дописывает «?», если его нет. К `vybor`, `dlya` и Действию — не дописывать.
5. Ещё не сделанные конструкции (`→`, `->`, `@`, `пока нет:`, `до:`, `одновременно:`, `время:`, `пауза:`, `таймер:`, `вставка:`, `полка:`, `|` в `ввод:`/`вывод:`) не угадывать. Дать ошибку «пока не поддерживается: <слово>» и строку пропустить.
6. `tools/drakon-zapis-test.mjs` — вывод `✓` / `✗` по образцу `tools/drakon-kod-test.mjs`, код выхода 1 при ошибке. Проверки:
   - пример «Сумма цифр» из § 3 описания даёт **ровно** `{ nazvanie:'Сумма цифр', shagi:[{vvod:'n'}, 's = 0', {poka:'n > 0?', shagi:['s = s + n % 10', 'n = n // 10']}, {vyvod:'s'}] }`;
   - по одной проверке на каждую строку ✓ таблицы (русское слово и английский синоним);
   - для каждой схемы без ошибок: `DrakonShema.proverit(shema)` не находит ошибок и `DrakonShema.vNative(shema)` не бросает исключение;
   - ошибки с верным номером строки: вопрос без `нет:`, выбор с одним вариантом, нечётный сдвиг, `пауза: 2 мин` («пока не поддерживается»).
