# Задание 009 (блок 1): навык в целом — верно выбрать стиль

**Блок тестов навыка:** 1 из 6 · **Исполнители:** Claude, Алиса и DeepSeek (скрипт `ii-komanda/tools/test_koda.py`), GLM (комната) · **Проверяет:** команды — скрипт, «руками» — учитель, «чтением» — Марьям

## Цель
Проверить главное в навыке «три стиля кода»: модель сама понимает, какой стиль нужен для какой работы, и сдаёт к коду ДРАКОН-лист. Объём маленький. Глубину языков проверяют блоки 2–6.

## Прочитать
- `docs/komanda/TRI-STILYA-ODNIM-TEKSTOM.md` — навык, три правила дословно, шпаргалки блоков, образец ДРАКОН-листа. Больше ничего не нужно.

## Часть 1. Выбор стиля

Для каждой работы выбери один стиль: `fort` (по-фортовски — как разложить), `prolog` (по-прологовски — как описать), `graf` (по-графовски — как нарисовать).

1. Функция на JavaScript считает, сколько дней дежурит ученик.
2. Факты «кто в какой день дежурит» и правило «А сменяет Б».
3. Показать на листе, как проверяется правило «А сменяет Б».
4. Разметка страницы «График дежурств» (HTML).
5. Оформление этой страницы (CSS).
6. Слово на Forth: по номеру дня даёт номер следующего дня.
7. Скрипт на Python читает график из файла и печатает дежурного.
8. Служебный код, который передаёт запрос из JavaScript в движок Prolog и принимает ответ.
9. Нарисовать связь «Тимур дежурит в понедельник».
10. Переделать старую длинную функцию JavaScript, не меняя её поведения.
11. Файл JSON с графиком дежурств: какие в нём поля и как записи связаны между собой.
12. Файл README в Markdown с описанием программы.

Ответ — файл `vybor.json`: объект, ключи — номера пунктов строками, значения — `"fort"`, `"prolog"` или `"graf"`. Пример формы: `{"1": "fort", "2": "graf"}` (это только форма, не ответ).

В тексте ответа, вне файлов, — по одной строке на пункт: почему этот стиль.

## Часть 2. Маленькая программа «Дежурство»

Данные (менять нельзя, имена выдуманные): Тимур дежурит в понедельник, Глеб — во вторник, Вера — в среду. Вторник идёт после понедельника, среда — после вторника.

1. Файл `dezhurstvo.js`: данные `GRAFIK` отдельно от действий; слово `dezhurnyj(den, grafik)` возвращает имя дежурного в этот день или пустую строку, если в этот день никто не дежурит. Последняя строка файла — ровно такая:
   `if (typeof module !== 'undefined') module.exports = { GRAFIK, dezhurnyj };`
2. Файл `dezhurstvo-list.md` — ДРАКОН-лист:
   - блок `дракон` для слова `dezhurnyj`;
   - блок `конспект` в режиме знаний: факты `дежурит` и `после`, правило «А сменяет Б» (тот, кто дежурит на следующий день, сменяет того, кто дежурил накануне), `пример: Глеб сменяет Тимура`, `контрпример: Тимур сменяет Глеба`, `запрос: кто сменяет Глеба`;
   - тест для слова `dezhurnyj`: строки `пример:` и `контрпример:`.
3. В тексте ответа — «пополнение словаря» (слова JS) и «пополнение словаря отношений» в формате из навыка.

## Нельзя

- Выдумывать ключевые слова блоков, которых нет в шпаргалках. Не знаешь — пиши «не знаю, надо проверить».
