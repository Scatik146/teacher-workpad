# Задание 018 (блок 3, серьёзное): Forth — журнал входов без повторов

**Блок тестов навыка:** 3 из 6, серьёзный уровень (студенту полчаса-час) · **Исполнители:** Claude, Алиса и DeepSeek (скрипт `ii-komanda/tools/test_koda.py`), GLM (вручную) · **Проверяет:** команды — скрипт, «чтением» — Марьям

## Цель
Проверить стиль «по-фортовски» там, где он даёт больше всего: перенести функцию JavaScript в словарь Forth так, чтобы **кода стало меньше и не осталось повторов** — повтор выносится в слово, различие между повторами — в данные. Поведение не меняется. К верхнему слову — ДРАКОН-лист.

## Прочитать
- `docs/komanda/TRI-STILYA-ODNIM-TEKSTOM.md` — навык, правила дословно, шпаргалки блоков. Больше ничего не нужно.

## Данные (всё выдумано)
Журнал входов в учётную запись — список чисел, по числу на событие: `0` — удачный вход, `1` — неверный пароль, `2` — неверный код из SMS, `3` — неверный ответ на секретный вопрос. Пример: `1 1 1 0 2 2 3 3`.

## Старая функция (длинная, с повторами)
```js
function f(zhurnal) {
  var blokov = 0;
  var parol = 0, kod = 0, vopros = 0;
  for (var i = 0; i < zhurnal.length; i++) {
    var s = zhurnal[i];
    if (s == 0) {
      parol = 0;
      kod = 0;
      vopros = 0;
    }
    if (s == 1) {
      parol = parol + 1;
      if (parol == 3) {
        blokov = blokov + 1;
        parol = 0;
      }
    }
    if (s == 2) {
      kod = kod + 1;
      if (kod == 3) {
        blokov = blokov + 1;
        kod = 0;
      }
    }
    if (s == 3) {
      vopros = vopros + 1;
      if (vopros == 2) {
        blokov = blokov + 1;
        vopros = 0;
      }
    }
  }
  return blokov;
}
```
Она считает блокировки: три неверных пароля подряд, три неверных кода или два неверных ответа на вопрос — блокировка, и счёт этой ошибки начинается заново; удачный вход обнуляет все счета.

## Что сделать
1. **Сначала запиши в ответе «вход → результат»** — три примера работы старой функции (один — на журнале из примера). Это нужно до переделки.
2. **Найди повторы** в старой функции и запиши в ответе: какой кусок повторяется, чем повторы отличаются, какое слово или какие данные его заменят.
3. Файл `zhurnal.fs`: словарь слов Forth; верхнее слово `БЛОКИРОВКИ ( адрес длина -- число )` — число блокировок для журнала из `длина` ячеек, начиная с `адрес`; на любом журнале — то же, что старая функция. Каждый вызов начинает счёт с нуля. Пороги (3, 3, 2) — данными, отдельно от действий. Проверка сама создаёт журналы так: `CREATE Ж1 1 , 1 , 1 , 0 , 2 , 2 , 3 , 3 ,` и зовёт `Ж1 8 БЛОКИРОВКИ .`
4. Файл `zhurnal-list.md` — ДРАКОН-лист к `БЛОКИРОВКИ`: блок `дракон` по порядку действий (цикл по журналу, вопрос «удачный вход?», вопрос «дошло до порога?»); блок `конспект` с данными (журнал, коды событий, пороги, счета); тест — строки `пример:` и `контрпример:` вида `- пример: 1 1 1 0 2 2 3 3 → 2`. Что на листе — то и в коде.

## Правила стиля (кратко, полностью — в навыке)
Над каждым словом — строка `\ ИМЯ: что делает` (имя — то же, что у слова); у каждого слова — стековый комментарий `( до -- после )`; у каждого `CREATE`, `VARIABLE`, `CONSTANT` — строка `\ ИМЯ: что хранит`. Одно слово — одно действие, до 15 строк; вложенность `IF`/`BEGIN`/`DO` — не глубже 2. Стандартные слова — заглавными; имена своих слов — русские. Верхнее слово читается как фраза.
**Без повторов:** одна и та же цепочка из 4 и больше слов подряд не встречается в коде дважды (комментарии не считаются).
