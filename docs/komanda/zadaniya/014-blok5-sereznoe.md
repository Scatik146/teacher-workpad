## Старая функция (длинная, плохая)
```js
function f(d) {
  var r = [];
  for (var i = 0; i < d.chitateli.length; i++) {
    var c = d.chitateli[i];
    var t = [];
    for (var j = 0; j < d.vydachi.length; j++) {
      if (d.vydachi[j].chitatel == c.id) {
        for (var k = 0; k < d.knigi.length; k++) {
          if (d.knigi[k].id == d.vydachi[j].kniga) {
            t.push(d.knigi[k].nazvanie);
          }
        }
      }
    }
    t.sort();
    var s;
    if (t.length == 0) {
      s = c.imya + ': ничего не взял';
    } else {
      s = c.imya + ': ' + t.join(', ');
      if (t.length >= 2) s += ' (много)';
    }
    r.push(s);
  }
  return r;
}
```
Она строит отчёт: по строке на читателя, в порядке списка читателей.

## Правила стиля (кратко, полностью — в навыке)
Слово — до 15 строк, вложенность блоков не глубже 2, один выход (`return`); над каждым словом — строка «имя: что делает» (в JavaScript `// имя: …`, в Python `# имя: …`; имя в строке — то же, что у слова); имена в коде — латиницей, комментарии — по-русски. Слова JavaScript — только `function имя(…)` в начале строки (так их находит проверка; условие этого теста, не общее правило).
