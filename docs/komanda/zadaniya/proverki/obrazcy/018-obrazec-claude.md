Модель: Claude (Марьям).

Вход → результат старой функции (записано до переделки):
- `1 1 1 0 2 2 3 3` → 2 (три пароля — блокировка; вход обнулил; два вопроса — блокировка)
- `3 3 3 3` → 2 (порог вопроса — 2: блокировка после второго и после четвёртого)
- `1 1 0 1 1 0 1` → 0 (удачный вход каждый раз обнуляет счёт пароля до порога)

Повторы в старой функции:
- Три блока `if (s == 1)`, `if (s == 2)`, `if (s == 3)` — один кусок: «счёт ошибки + 1; если счёт == порог — блокировок + 1, счёт = 0». Отличаются только счётом (`parol`, `kod`, `vopros`) и порогом (3, 3, 2). Заменяет: слово `ОШИБКА ( код -- )` и две таблицы по коду события — `СЧЕТА` и `ПОРОГИ`.
- В `if (s == 0)` три одинаковых обнуления — заменяет `ОБНУЛИТЬ`: вся таблица `СЧЕТА` в ноль одним `ERASE`.

```forth
\ Журнал входов: число блокировок. Коды: 0 — вход, 1 — пароль, 2 — код из SMS, 3 — вопрос.
\ ПОРОГИ: порог блокировки по коду события (ячейка 0 — удачный вход, не нужна)
CREATE ПОРОГИ 0 , 3 , 3 , 2 ,
\ СЧЕТА: ошибки подряд по коду события
CREATE СЧЕТА 0 , 0 , 0 , 0 ,
\ БЛОКОВ: число блокировок
VARIABLE БЛОКОВ
\ СЧЁТ: адрес счёта события
: СЧЁТ ( код -- адрес ) CELLS СЧЕТА + ;
\ ПОРОГ: порог события
: ПОРОГ ( код -- порог ) CELLS ПОРОГИ + @ ;
\ ОБНУЛИТЬ: все счета — в ноль
: ОБНУЛИТЬ ( -- ) СЧЕТА 4 CELLS ERASE ;
\ ДОШЛО?: счёт события дошёл до порога
: ДОШЛО? ( код -- флаг ) DUP СЧЁТ @ SWAP ПОРОГ = ;
\ БЛОКИРОВАТЬ: ещё одна блокировка, счёт события — заново
: БЛОКИРОВАТЬ ( код -- ) 0 SWAP СЧЁТ ! 1 БЛОКОВ +! ;
\ ОШИБКА: счёт события +1, на пороге — блокировка
: ОШИБКА ( код -- ) 1 OVER СЧЁТ +! DUP ДОШЛО? IF БЛОКИРОВАТЬ ELSE DROP THEN ;
\ СОБЫТИЕ: удачный вход обнуляет счета, ошибка считается
: СОБЫТИЕ ( код -- ) ?DUP IF ОШИБКА ELSE ОБНУЛИТЬ THEN ;
\ НАЧАТЬ: счета и блокировки — с нуля
: НАЧАТЬ ( -- ) ОБНУЛИТЬ 0 БЛОКОВ ! ;
\ БЛОКИРОВКИ: число блокировок для журнала из длина ячеек
: БЛОКИРОВКИ ( адрес длина -- число ) НАЧАТЬ CELLS OVER + SWAP ?DO I @ СОБЫТИЕ 1 CELLS +LOOP БЛОКОВ @ ;
```

zhurnal-list.md
````markdown
# ДРАКОН-лист: журнал входов (БЛОКИРОВКИ)

## Действия

```дракон
название: БЛОКИРОВКИ
ввод: журнал
блоков = 0, все счета = 0
для: каждого события s в журнале
  вопрос: удачный вход (s == 0)?
    да:
      все счета = 0
    нет:
      счёт[s] = счёт[s] + 1
      вопрос: дошло до порога (счёт[s] == порог[s])?
        да:
          блоков = блоков + 1
          счёт[s] = 0
        нет:
вывод: блоков
```

## Данные

```конспект
тема: Журнал входов: коды событий, пороги, счета
связка: событие | порог
0 -> удачный вход | все счета в ноль
1 -> неверный пароль | 3
2 -> неверный код из SMS | 3
3 -> неверный ответ на вопрос | 2
стрелка: Счёт дошёл до порога — блокировка, счёт события заново
```

## Тест

- пример: 1 1 1 0 2 2 3 3 → 2
- пример: 3 3 3 3 → 2
- контрпример: 1 1 0 1 1 0 1 → 1
````

Пополнение словаря (Forth):
- `ПОРОГИ` (данные) — порог блокировки по коду события: 0, 3, 3, 2.
- `СЧЕТА` (данные) — ошибки подряд по коду события; `БЛОКОВ` (данные) — число блокировок.
- `СЧЁТ ( код -- адрес )` — адрес счёта события — из `СЧЕТА`.
- `ПОРОГ ( код -- порог )` — порог события — из `ПОРОГИ`.
- `ОБНУЛИТЬ ( -- )` — все счета в ноль — из `СЧЕТА`, `ERASE`.
- `ДОШЛО? ( код -- флаг )` — счёт дошёл до порога — из `СЧЁТ`, `ПОРОГ`.
- `БЛОКИРОВАТЬ ( код -- )` — блокировка, счёт заново — из `СЧЁТ`, `БЛОКОВ`.
- `ОШИБКА ( код -- )` — счёт +1, на пороге блокировка — из `СЧЁТ`, `ДОШЛО?`, `БЛОКИРОВАТЬ`.
- `СОБЫТИЕ ( код -- )` — одно событие журнала — из `ОШИБКА`, `ОБНУЛИТЬ`.
- `НАЧАТЬ ( -- )` — счёт с нуля для нового вызова — из `ОБНУЛИТЬ`, `БЛОКОВ`.
- `БЛОКИРОВКИ ( адрес длина -- число )` — число блокировок журнала — из `НАЧАТЬ`, `СОБЫТИЕ`.
