propusk.fs
```forth
\ Пропуск: проверка номера контрольной цифрой (алгоритм Луна). Номер — до 9 цифр.
\ ВДВОЕ: удвоить цифру по правилу Луна
: ВДВОЕ ( цифра -- цифра' ) 2* DUP 9 > IF 9 - THEN ;
\ ЦИФРА: отделить последнюю цифру числа
: ЦИФРА ( n -- n' цифра ) 10 /MOD SWAP ;
\ ПАРА: прибавить к сумме две последние цифры — первую как есть, вторую вдвое
: ПАРА ( сумма n -- сумма' n' ) ЦИФРА ROT + SWAP ЦИФРА ВДВОЕ ROT + SWAP ;
\ СУММА-ЛУНА: сумма по Луну для всего номера
: СУММА-ЛУНА ( n -- сумма ) 0 SWAP BEGIN DUP WHILE ПАРА REPEAT DROP ;
\ ВЕРНЫЙ?: сумма по Луну делится на 10
: ВЕРНЫЙ? ( n -- флаг ) СУММА-ЛУНА 10 MOD 0= ;
\ ПРОВЕРИТЬ: напечатать, верен ли номер
: ПРОВЕРИТЬ ( n -- ) ВЕРНЫЙ? IF ." верный" ELSE ." неверный" THEN ;
```

propusk-list.md
````markdown
# ДРАКОН-лист: номер пропуска (СУММА-ЛУНА, ВЕРНЫЙ?, ПРОВЕРИТЬ)

```дракон
название: Проверка номера пропуска
ввод: n
summa = 0
пока: n > 0
  summa = summa + n % 10
  n = n // 10
  d = n % 10 * 2
  вопрос: d > 9
    да:
      d = d - 9
    нет:
  summa = summa + d
  n = n // 10
вопрос: summa % 10 == 0
  да:
    вывод: "верный"
  нет:
    вывод: "неверный"
```

## Тест
- пример: 18 ПРОВЕРИТЬ → верный
- пример: 12345674 ПРОВЕРИТЬ → верный
- контрпример: 19 ПРОВЕРИТЬ → верный
````

Пополнение словаря (Forth):
- `ПАРА ( сумма n -- сумма' n' )` — две последние цифры в сумму — из `ЦИФРА`, `ВДВОЕ`.
- `СУММА-ЛУНА ( n -- сумма )` — сумма по Луну — из `ПАРА`.
- `ВЕРНЫЙ? ( n -- флаг )` — номер верен — из `СУММА-ЛУНА`.
- `ПРОВЕРИТЬ ( n -- )` — печать «верный» / «неверный» — из `ВЕРНЫЙ?`.
