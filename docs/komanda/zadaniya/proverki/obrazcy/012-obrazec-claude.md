# ДРАКОН-лист: число R по числу N

## Действия

```дракон
название: Число R по числу N
ветка: Ввод
  ввод: n = int(input())
  m = n
  h = ''
ветка: Шестнадцатеричная запись
  пока: m > 0
    h = '0123456789ABCDEF'[m % 16] + h
    m = m // 16
ветка: Подсчёт цифр B
  k = 0
  для: for c in h
    вопрос: c == 'B'
      да:
        k = k + 1
      нет:
        # не B
ветка: Дописать единицу
  выбор: k % 2
    вариант: 0
      h = '1' + h
    вариант: 1
      h = h + '1'
  вывод: int(h, 16)
```

## Данные

```конспект
тема: Шестнадцатеричная запись
Основание -> 16
Цифры -> 0–9 и A–F
Цифра B -> одиннадцать
```

```конспект
тема: Пример: N = 91
1. Запись числа 91 — 5B
2. Цифра B одна — нечётное количество
3. Единицу дописываем справа — 5B1
4. Число 5B1 — это 1457
```

```конспект
тема: Куда дописать единицу
связка: чётное число B | нечётное число B
Где единица -> слева | справа
Из 5 получится -> 15 | 51
```

```конспект
тема: Порядок цифр
режим: знания
Х -> ?
У -> ?
З -> ?
связь 9 -> A: перед
связь A -> B: перед
связь B -> C: перед
правило: Х младше У, если Х перед У
правило: Х младше У, если Х перед З и З младше У
пример: 9 младше C
контрпример: C младше 9
запрос: кто младше C
```

## Тест
- пример: ввод 91 → вывод 1457
- пример: ввод 5 → вывод 21
- контрпример: ввод 11 → вывод 27

Почему эти схемы: определение из трёх пар «что → чему равно» — батарея; пример по шагам с номерами — лестница; два случая рядом по одним признакам — шеренга.

Как получен ответ: программа по листу запущена для N от 1 до 99 (при больших N R только больше). Двузначные R дают N от 1 до 15, кроме 11: запись N — одна цифра, B нет (кроме 11 = B), единица слева — R = 16 + N, от 17 до 31. Таких N 14.

Пополнение словаря отношений:
- перед — две цифры — первая идёт сразу перед второй — факт
- младше — две цифры — первая стоит раньше второй в ряду цифр — из «перед» и «младше» (рекурсивное)
