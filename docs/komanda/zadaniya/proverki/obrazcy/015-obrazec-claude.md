kruzhok.pl
```prolog
% Данные: кто записан в кружок и кто кому передал файл.
записан(тимур, робототехника).
записан(глеб, робототехника).
записан(вера, шахматы).
передал(тимур, глеб).
передал(глеб, вера).

% Правило: двое — однокружники, если записаны в один кружок.
однокружник(А, Б) :- записан(А, К), записан(Б, К).
% пример: однокружник(тимур, глеб).
% контрпример: однокружник(тимур, вера).

% Правило: передал своему — передал файл тому, кто в том же кружке.
передал_своему(А, Б) :- передал(А, Б), однокружник(А, Б).
% пример: передал_своему(тимур, глеб).
% контрпример: передал_своему(глеб, вера).
```

````markdown
# ДРАКОН-лист: кружок

```конспект
тема: Кружок и передача файлов
режим: знания
Х -> ?
У -> ?
З -> ?
связь Тимур -> Робототехника: записан
связь Глеб -> Робототехника: записан
связь Вера -> Шахматы: записан
связь Тимур -> Глеб: передал
связь Глеб -> Вера: передал
правило: Х однокружник У, если Х записан З и У записан З
правило: Х передал_своему У, если Х передал У и Х однокружник У
пример: Тимур передал_своему Глеб
контрпример: Глеб передал_своему Вера
запрос: кто однокружник Глеб
```

## Тест
- пример: Тимур передал_своему Глеб
- контрпример: Глеб передал_своему Вера
````

- однокружник: описано, что значит «одного кружка» (оба записаны в один и тот же кружок), без порядка действий.
- передал_своему: через промежуточное отношение — два условия вместо трёх.

Пополнение словаря отношений:
- записан — человек, кружок — человек записан в кружок — факт
- передал — человек, человек — первый передал файл второму — факт
- однокружник — человек, человек — записаны в один кружок — из записан
- передал_своему — человек, человек — передал файл однокружнику — из передал, однокружник
