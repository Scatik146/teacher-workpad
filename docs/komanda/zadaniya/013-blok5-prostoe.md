# Задание 013 (блок 5, простое): стиль «по-прологовски» — школьная библиотека

**Блок тестов навыка:** 5 из 6, простой уровень (студенту 10–15 минут) · **Исполнители:** Claude, Алиса и DeepSeek (скрипт `ii-komanda/tools/test_koda.py`), GLM (вручную) · **Проверяет:** команды — скрипт, «чтением» — Марьям

## Цель
Проверить стиль «по-прологовски» (как описать, а не как вычислить) на четырёх языках описания: JSON, HTML, CSS, Markdown. Действий в этом задании нет.

## Прочитать
- `docs/komanda/TRI-STILYA-ODNIM-TEKSTOM.md` — навык и правила дословно. Больше ничего не нужно.

## Данные (менять нельзя, всё выдумано)
- Книги: «Тайна пароля» (А. Ветров), «Робот и ветер» (Н. Лесной), «Карта сети» (И. Морозова).
- Читатели: Тимур, Вера.
- Выдано: Тимур взял «Тайну пароля» и «Карту сети», Вера взяла «Робота и ветер».

## Что сделать
Четыре файла:

1. `knigi.json` — данные: три таблицы (книги, читатели, выдачи). У каждой записи поле `id`; во всём файле `id` разные. Выдача ссылается на книгу и читателя полем-ссылкой на `id`, названия и имена не копируются. Имена полей — латиницей, из словаря предмета.
2. `knigi.html` — страница «Школьная библиотека»: заголовок `<h1>`, список из трёх книг. Вид подключён через `<link rel="stylesheet" href="knigi.css">`. Классы — по смыслу (что это), не по виду.
3. `knigi.css` — вид: переменные цвета и отступа в `:root`, правила «селектор → свойства» для классов из `knigi.html`.
4. `README.md` — описание: заголовок `#`, раздел `##`, список из трёх файлов (с их именами), и блок, показывающий в Markdown пример записи выдачи: блок `markdown` в ограде из **четырёх** обратных кавычек, внутри него блок `json` в трёх.

## Нельзя
- Менять данные; подключать библиотеки и шрифты из сети; писать в разметке `style="…"`, `onclick="…"`, теги `<style>` и `<script>`; писать `!important`.
- Выдумывать то, чего нет в правилах. Не знаешь — пиши «не знаю, надо проверить».

## Сдать файлы
`knigi.json`, `knigi.html`, `knigi.css`, `README.md`

В первой строке ответа — какая ты модель. Каждый файл целиком, в своём блоке кода, строкой выше — имя файла. `README.md` стоит в ограде **длиннее** любой ограды внутри него (внутри четыре — значит пять и больше). После файлов: по одной строке на файл — «что он говорит» (не «как выглядит»); «пополнение словаря отношений» для `knigi.json` в формате навыка: `имя — участники — что значит`. Весь ответ — не длиннее 90 строк.
