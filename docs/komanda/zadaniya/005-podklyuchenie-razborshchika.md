## Сделать

### 1. Пустое `низ:` = нет `низ:` (находка 004б)
Если значение после `низ:` пустое (или из одних пробелов), в шаг **не** пишется `niz`. Тогда нижняя крышка получит «Конец цикла i», как будто строки `низ:` не было. Проверка повтора (««низ:» уже есть») остаётся как есть: если `низ:` написано дважды, это ошибка, даже когда первое пустое.

| вход | `shema` | `oshibki` |
|---|---|---|
| `для: i от 1 до 3⏎  шаг⏎  низ:` | `{"shagi":[{"dlya":"i от 1 до 3","shagi":["шаг"]}]}` | `[]` |
| `для: i от 1 до 3⏎  шаг⏎  низ:   ` | то же | `[]` |
| `для: i от 1 до 3⏎  шаг⏎  низ:⏎  низ: b` | то же (без `niz`) | `[{"stroka":4,"tekst":"«низ:» уже есть"}]` |
| `для: i от 1 до 3⏎  шаг⏎  низ: Свой` | `…"niz":"Свой"…` — как сейчас | `[]` |

### 2. `lib/drakon-shema/blok.js` — версия 1.0
Подключается так же, как `zapis.js`: в браузере `window.DrakonBlok`, в Node `module.exports`. Берёт `DrakonZapis` и `DrakonShema`: в браузере — из `window`, в Node — через `require('./zapis.js')` и `require('./drakon-shema.js')`. В начале файла — комментарий с описанием подключения, как в `konspekt.js`:
```html
<script src="../../lib/drakonwidget/drakonwidget.js"></script>
<script src="../../lib/drakon-shema/drakon-shema.js"></script>
<script src="../../lib/drakon-shema/zapis.js"></script>
<script src="../../lib/drakon-shema/blok.js"></script>
<script>DrakonBlok.run();</script>
```

**2.1. `podgotovit(tekst, rezhim = 'pokaz')` → `{ shema, oshibki, gotova }`.** Чистая функция, без DOM. Она **никогда не бросает исключение**: на `null`, `undefined`, `123`, `'\t\t'`, `` '```' ``, `'вопрос:'` возвращает объект с массивом `oshibki`.
- `oshibki` = ошибки `razobrat` + ошибки `DrakonShema.proverit(shema, rezhim)` (они без строки: `stroka: 0`) + исключение `vNative` (`{stroka:0, tekst:'схема не строится: ' + сообщение}`).
- Нет ни одного шага (и нет веток) → `{stroka:0, tekst:'блок пуст: нет ни одного шага'}`.
- `oshibki` сортируются по `stroka` **устойчиво**: при равных номерах порядок сохраняется; `stroka: 0` идут последними.
- `gotova` = `oshibki.length === 0`. `shema` возвращается всегда, даже с ошибками.

| вход | режим | `oshibki` (сравнение целиком) |
|---|---|---|
| `название: Чай⏎вскипятить воду⏎вопрос: Есть сахар?⏎  да: положить сахар⏎  нет: без сахара` | pokaz | `[]`, `gotova: true` |
| `…` | pokaz | `[{"stroka":0,"tekst":"схема, шаг 1: пустой блок"}]` |
| `…` | sborka | `[]` — в заготовке «…» законно |
| `` (пусто) и `название: Чай` | pokaz | `[{"stroka":0,"tekst":"блок пуст: нет ни одного шага"}]` |
| `вопрос: x?⏎  да: a` | pokaz | `[{"stroka":1,"tekst":"в вопросе «x?» нет ветки «нет:»"}]` |
| `шаг⏎    лишний` | pokaz | `[{"stroka":2,"tekst":"лишний сдвиг: у Действия не бывает вложенных строк"}]` |
| третий пример из `drakon-zapis.md` («Можно забить гвоздь?», строки 76–83) | pokaz | 7 ошибок, номера по порядку: `2, 2, 3, 4, 4, 5, 7`; на строке 2 — сначала «нет ветки «да:»», потом «нет ветки «нет:»» |

**2.2. `podskazka(oshibki)` → строка.** Каждая ошибка с новой строки: `строка N: текст`, а при `stroka: 0` — просто `текст`. Для `[]` — пустая строка `''`.

**2.3. `run(nastrojki)` — все блоки на странице. Только просмотр.**
- Ищет `pre > code.language-дракон` и `pre > code.language-drakon` (так их выдают marked и markdown-it). Каждый `<pre>` заменяет на `<div class="drakon-blok">`.
- `gotova` → `DrakonShema.pokazat(div, shema, { rezhim:'pokaz', knopki: nastrojki.knopki, kod: nastrojki.kod })`.
- Есть ошибки → в `div`: `<div class="drakon-podskazka">` с текстом `podskazka(...)`, под ним `<pre>` с исходным текстом блока. Схему не рисует.
- `pokazat` бросил исключение → то же, с текстом `схема не построилась: ` + сообщение. Не подключён `drakon-shema.js` → та же подсказка с текстом `не подключён drakon-shema.js`. Исключения наружу не выходят: один сломанный блок не ломает остальные.
- **Сборки в блоке нет.** Слова после имени языка (```` ```дракон сборка ````) ничего не включают: блок только показывает схему.
- Возвращает `[{ el, gotova, oshibki }]`. Повторный вызов `run()` уже обработанные блоки не трогает.

**2.4. `sborka(el, tekst, nastrojki)` — заготовка для ученика, только из кода задания.**
- `nastrojki.klyuch` нет, пустой или не строка → `el.textContent = 'Для сборки нужен ключ задания (nastrojki.klyuch): без него работа ученика не сохранится.'`, возврат `null`, `DrakonShema` не вызывается.
- Ошибки `podgotovit(tekst, 'sborka')` → `el.textContent = podskazka(...)`, возврат `null`.
- Иначе — `DrakonShema.pokazat(el, shema, { ...nastrojki, rezhim:'sborka' })` в `try/catch` (исключение → подсказка, как в 2.3); возврат — то, что вернул `pokazat`.

**2.5. Только `textContent`.** Текст ученика и подсказки попадают на страницу только через `textContent` или `createTextNode`, без `innerHTML`: в тексте блока может стоять `<script>`.

### 3. `tools/drakon-shema.mjs`
- Новый ключ: `node tools/drakon-shema.mjs --zapis файл [--sborka]` — весь файл считается текстовой записью; ошибки печатаются как `   строка N: …`.
- `--scan` дополнительно находит в файле блоки ```` ```дракон ```` и ```` ```drakon ```` (строка ограды, после неё можно пробел и слова) до закрывающей ```` ``` ````. Это всегда просмотр. Номер строки в выводе — **номер в файле**: строка ограды + `stroka`. Заголовок блока: `— #k «название» · просмотр (строка F)`, где F — строка ограды. Ошибки со `stroka: 0` печатаются без номера.
- Блоки проверяются через `DrakonBlok.podgotovit`, а не отдельной копией правил.
- Старые режимы (JSON, `/*схема*/`, `/*заготовка*/`) работают и печатают как раньше.
- Подсказка без аргументов печатает строки 2–9 файла (`slice(1, 9)`). Если дописываешь описание в начало файла, сдвинь эту границу, чтобы подсказка печатала всё описание целиком.
- Ожидаемо: `--scan docs/komanda/drakon-zapis.md` → 3 блока; #1 «Сумма цифр» без ошибок; у #2 первая ошибка — `строка 63: лишний сдвиг: у Действия не бывает вложенных строк`; код выхода 1 (примеры 2–3 используют запись следующих версий — так и должно быть).
