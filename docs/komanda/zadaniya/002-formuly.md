## Сделать
1. Образец (взять как первый конспект файла, один в один):
   ```
   тема: Нагревание тела
   пример: Q = [c]{удельная теплоёмкость} · [m]{масса} · [$(t_2 − t_1)$]{изменение температуры}
   ```
2. Ещё **24 конспекта**, каждый — `тема:` + `пример:` (с разбором букв `[…]{…}`) + при необходимости строка `Формула -> $…$ | $…$`. Конспекты разделять пустой строкой и строкой `---`.
3. Состав: математика — 12 (дроби, степени и корни, квадратное уравнение и дискриминант, формулы сокращённого умножения, арифметическая и геометрическая прогрессии, тригонометрия, логарифмы, производная, площадь и объём, вероятность и $C_n^k$, модуль, система); физика — 12 (скорость и ускорение, $F = ma$, давление, работа и мощность, закон Ома, КПД, $E = mc^2$-подобные формулы с индексами, векторы $\vec F$, формулы с греческими буквами, единицы через `\text{…}`, дроби в степенях).
4. Охват записи: верхние и нижние индексы, дроби, корни, суммы и пределы, греческие буквы, векторы, `\text{…}` с русскими единицами, знак `−` и `·`, выключная формула `$$…$$`.
5. Файл — чистый текст, UTF-8; каждый конспект проходит просмотр: формулы только в `$…$` или `$$…$$`, символы `[ ] { } | $` вне формул — через `\`.

## Нельзя
- Придумывать операторы вне справочника; ссылаться на формулы, которых нет в школьной программе; писать не по-русски.

- 3–5 формул, которые, по-твоему, генератор может сломать (длинные дроби, вложенные индексы, `\text` внутри индекса), — отдельным разделом «Находки, ждут решения» (без починки).
