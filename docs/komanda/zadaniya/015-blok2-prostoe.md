# Задание 015 (блок 2, простое): Prolog — кружок и передача файлов

**Блок тестов навыка:** 2 из 6, простой уровень (студенту 10–15 минут) · **Исполнители:** Claude, Алиса и DeepSeek (скрипт `ii-komanda/tools/test_koda.py`), GLM (вручную) · **Проверяет:** команды — скрипт, «чтением» — Марьям

## Цель
Проверить стиль «по-прологовски» (как описать): факты и правила чистым Prolog, а тот же вывод — на нашем языке, в блоке `конспект` в режиме знаний.

## Прочитать
- `docs/komanda/TRI-STILYA-ODNIM-TEKSTOM.md` — навык, правила дословно, шпаргалки блоков (в том числе режим знаний). Больше ничего не нужно.

## Данные (менять нельзя, имена выдуманные)
Тимур и Глеб записаны в кружок «робототехника», Вера — в «шахматы». Тимур передал файл Глебу, Глеб передал файл Вере.

Два отношения-факта: `записан(кто, кружок)` и `передал(кто, кому)`. Два правила (слова даны, придумывать другие нельзя):
- `однокружник(А, Б)`: А и Б записаны в один кружок;
- `передал_своему(А, Б)`: А передал файл Б, и А с Б — однокружники.

Что человек сам себе однокружник — нормально, исключать это не нужно.

## Что сделать
1. Файл `kruzhok.pl` — чистый Prolog: ровно пять фактов и ровно два правила. Имена отношений — русские, атомы — строчными (`тимур`, `робототехника`), переменные — заглавными русскими буквами. Для каждого правила — две строки-комментария: `% пример: цель.` (должна выполняться) и `% контрпример: цель.` (не должна).
2. Файл `kruzhok-list.md` — ДРАКОН-лист: блок `конспект` в режиме знаний с теми же фактами и правилами (имена людей и кружков — с заглавной: `Тимур`, `Робототехника`; переменные — **Х, У, З**), строки `пример:` и `контрпример:` для `передал_своему`, строка `запрос: кто однокружник Глеб`; ниже — тест (строки `пример:` и `контрпример:`).

## Нельзя
- Менять данные; `!`, `->`, `assert`, `retract`; больше трёх условий в правиле.
- Ключевые слова блоков, которых нет в шпаргалках. Не знаешь — пиши «не знаю, надо проверить».

## Сдать файлы
`kruzhok.pl`, `kruzhok-list.md`

В первой строке ответа — какая ты модель. Перед сдачей проверь: каждый файл из «Сдать файлы» есть в ответе, у каждого — свой блок кода. Каждый файл целиком, в своём блоке кода, строкой выше — имя файла. `kruzhok-list.md` — в ограде из четырёх обратных кавычек. После файлов: по строке — почему правило написано именно так (по-прологовски: что верно, а не как вычислить); «пополнение словаря отношений» в формате навыка. Весь ответ — не длиннее 80 строк.
