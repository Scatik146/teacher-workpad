# Команда ИИ: вход для помощников

Общая память сайта уроков для всех ИИ, которые над ним работают: Claude, Qwen, GLM, DeepSeek, Алиса, YandexGPT. Перед работой прочитайте этот файл, затем `CLAUDE.md` в корне. `CLAUDE.md` — действующие правила, он главнее.

Обновлено: 13.11.2026.

## 1. Учитель и уроки

- Учитель ведёт курс «ИИ и информационная безопасность» (ИИИБ) и другие предметы. Группы курса:
  - 4 класс — около 6 человек, 10 лет; школьные ноутбуки, Word, бумажные листы заданий;
  - 6 класс — около 8 человек, 12 лет;
  - 7 класс — около 8 человек, 13 лет; у каждого свой ноутбук.

  Есть и другие классы, от 2-го до 9-го.
- Любимые форматы — игры и детективы в виде HTML-приложений. Работают на парах: роли «за пультом» и «штурман», выводы — индивидуальные, в тетрадь.
- Сайт открывается с GitHub Pages; GitHub на школьных ноутбуках работает. Запасной вариант — школьная сетевая папка без интернета, поэтому никаких CDN.
- Claude Docs у учителя не открывается: материалы учителя делаем HTML-страницами в папке урока.
- У учителя накоплено много материалов на SourceCraft (sourcecraft.dev). Он думает постепенно переработать их и перенести сюда.

Копии навыков Claude — подробные инструкции, годятся любому помощнику:

## 4. Как работать помощнику

- Изменения — в отдельной ветке через Pull Request; учитель смотрит и сливает.
- Перед PR пройти приложение в браузере: экраны, консоль без ошибок, все ветки игры. Конспекты и схемы проверить скриптами из `tools/`.
- Не трогать `lib/drakonwidget/drakonwidget.js` и строки авторства в `lib/drakon-graf`.
- Всё по-русски: тексты, интерфейсы, коммиты.
