# Правило: «по-графовски» — как нарисовать

Решение учителя 15.11.2026. Действует для кода на Prolog во всех проектах (drakon-graf, «Живой конспект», teacher-workpad и связанные). Один из трёх стилей кода (журнал drakon-graf `docs/komanda/README.md` § 4): «по-фортовски» — как разложить (`KOD-PO-FORTOVSKI.md`), «по-прологовски» — как описать (`KOD-PO-PROLOGOVSKI.md`), **«по-графовски» — как нарисовать (этот файл)**. Разбор и проба «Родословная» — drakon-graf `docs/research/12_ГРАФ_и_Prolog.md` § 6.

15.11 файл разведён на два без изменения смысла: пункты 1–3 остались здесь, прежние пункты 4–8, ловушки и раздел «Движок» — в `KOD-PO-PROLOGOVSKI.md`.

```
ПРАВИЛО: «ПО-ГРАФОВСКИ»

Каждое отношение рисуется в ДРАКОН-ГРАФ.

1. Факт — связь с подписью; подпись — имя отношения.
   родитель(иван, петр).  =  связь Иван -> Пётр: родитель

2. Правило — строка «…, если … и …» и ДРАКОН-схема «как проверяется»:
   условия — иконы «Вопрос» подряд по шампуру; несколько правил
   одного имени — ветки силуэта; поиск («найти такого Б») — цикл
   «Для каждого»; ответ — конец схемы.
   ГРАФ — что верно, ДРАКОН — как проверяется.

3. Запрос — запоминатель с пустым ответом (кто -> ?); ответ Prolog —
   те же запоминатели с ответом (кто -> Иван).
```

Как отношения описывать (сколько условий, имена, пример и контрпример, запреты, «пополнение словаря отношений») — `KOD-PO-PROLOGOVSKI.md`.

Мерило: картинку одинаково читают 2–4, 5–6, 7–9, 10–11 классы и учителя всех предметов.

П. 2 (схема правила) — на проверке у GLM (Зануда), см. журнал § 4, строка «Prolog „по-графовски“».

## Ловушки рисования: «если … то будет …» (брифинг 15.11 ночью)

- **Если** рисовать рекурсию петлёй → **то** шампур ломается. Рекурсия на ДРАКОН-схеме — икона «Вставка» той же схемы.
- **Если** факта нет в базе → **то** Prolog ответит «нет» (закрытый мир). В подписи к картинке — «не нашли = нет».

Остальные ловушки (порядок правил, `findall`, `\+`, cut) — в `KOD-PO-PROLOGOVSKI.md`.
