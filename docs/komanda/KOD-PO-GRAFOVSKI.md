# Правило: Prolog «по-графовски»

Решение учителя 15.11.2026. Действует для кода на Prolog во всех проектах (drakon-graf, «Живой конспект», teacher-workpad и связанные). Пара к правилу «по-фортовски» (`KOD-PO-FORTOVSKI.md`): там — порядок действий, здесь — знания (факты и правила-отношения). Разбор и проба «Родословная» — drakon-graf `docs/research/12_ГРАФ_и_Prolog.md` § 6.

```
ПРАВИЛО: PROLOG «ПО-ГРАФОВСКИ»

Каждое отношение рисуется в ДРАКОН-ГРАФ.

1. Факт — связь с подписью; подпись — имя отношения.
   родитель(иван, петр).  =  связь Иван -> Пётр: родитель

2. Правило — строка «…, если … и …» и ДРАКОН-схема «как проверяется»:
   условия — иконы «Вопрос» подряд по шампуру; несколько правил
   одного имени — ветки силуэта; поиск («найти такого Б») — цикл
   «Для каждого»; ответ — конец схемы.
   ГРАФ — что верно, ДРАКОН — как проверяется.

3. Запрос — запоминатель с пустым ответом (кто -> ?); ответ Prolog —
   те же запоминатели с ответом (кто -> Иван).

4. В правиле не больше 3 условий. Больше — выдели промежуточное
   отношение (то же «маленькое слово», что в Forth).

5. Имена отношений — русские, из словаря предмета.

6. У каждого отношения — хотя бы один «пример:» (должно выводиться)
   и один «контрпример:» (не должно).

7. В знаниях — без cut (!), assert/retract и побочных эффектов.
   Служебный код (ввод-вывод, JSON) — отдельно и «по-фортовски».

8. В конце работы — «пополнение словаря отношений»:
   имя — участники — что значит — из каких отношений собрано.
```

Мерило: картинку одинаково читают 2–4, 5–6, 7–9, 10–11 классы и учителя всех предметов.

Пп. 2 и 7 — на проверке у GLM (Зануда): что теряется при рисовании правила схемой (откат, рекурсия, несколько ответов) и не ломает ли запрет cut/assert школьные задачи.
