# Рабочий стол учителя

Приложения к урокам: «ИИ и информационная безопасность», «Информатика», «Математика», «Труд (технология)». Каждое приложение лежит в своей папке (index.html, при необходимости — папка img/ рядом) и работает с GitHub Pages и из школьной сетевой папки без интернета.

## Как открыть

- **С GitHub Pages:** главная страница сайта — каталог уроков.
- **Из сетевой папки (запасной вариант):** скопируйте папку урока целиком и откройте в ней `index.html` в браузере.

## Как добавить урок

1. Создайте папку `<класс>-klass/<короткое-имя>/` (урок для нескольких предметов — `obshchie/<имя>/`) и положите в неё `index.html` (и `img/`, если нужны картинки).
2. В `lessons.js` добавьте объект в список `LESSONS`: `where` — где урок стоит в каталоге (`[{s:'iiib', g:7}]`, предметы: `iiib`, `inf`, `mat`, `trud`), название, тема, описание, путь к папке.
3. Материалы учителя (слайды, листы для печати, конспекты) — в поле `teacher`; они появятся на странице «Для учителя». Урок без приложения для учеников — `app: null`.
4. Плашки с `ready:false` на сайте не показываются: так можно заранее завести урок, пока файлы не загружены.

## Графические конспекты (ДРАКОН-ГРАФ)

Библиотека лежит в `lib/drakon-graf/` и подключается к любому приложению двумя строками — см. [lib/drakon-graf/README.md](lib/drakon-graf/README.md). Проба конспекта: `lib/drakon-graf/index.html`. Проверка без браузера: `node tools/konspekt.mjs`.
