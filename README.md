# Рабочий стол учителя

Приложения к урокам: «ИИ и информационная безопасность», «Информатика», «Труд (технология)». Каждое приложение лежит в своей папке (index.html, при необходимости — папка img/ рядом) и работает с GitHub Pages и из школьной сетевой папки без интернета.

## Как открыть

- **С GitHub Pages:** главная страница сайта — каталог уроков.
- **Из сетевой папки (запасной вариант):** скопируйте папку урока целиком и откройте в ней `index.html` в браузере.

## Уроки

| Предмет | Класс | Урок | Тема | Папка |
| --- | --- | --- | --- | --- |
| ИИИБ | 7 | Помощник сломался | Что такое данные. Датасет. Виды датасетов | `7-klass/dataset-pomoshnik/` |
| ИИИБ | 8 | Текст-Биржа: заказ «Архив» | Авторство, ИИ и ответственность исполнителя | `8-klass/tekst-birzha/` |
| ИИИБ | 9 | Следующая нота | Как нейросеть генерирует музыкальные последовательности | `9-klass/sleduyushchaya-nota/` |

## Как добавить урок

1. Создайте папку `<класс>-klass/<короткое-имя>/` и положите в неё `index.html` (и `img/`, если приложению нужны картинки).
2. В корневом `index.html` добавьте объект в список `LESSONS`: предмет (`iiib`, `inf`, `trud`), класс, название, тема, описание, путь к папке. Дополнительные кнопки (слайды, листы для печати) — в поле `extra`.
3. Плашки с `ready:false` на сайте не показываются: так можно заранее завести урок, пока файлы не загружены.

Служебные возможности приложений (ускоренный прогон, переход по экранам) на сайте не упоминаются — инструкция у учителя.
