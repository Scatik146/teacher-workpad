# Рабочий стол учителя

Приложения к урокам курса «ИИ и информационная безопасность». Каждое приложение — один HTML-файл без внешних ресурсов: работает с GitHub Pages и из школьной сетевой папки без интернета.

## Как открыть

- **С GitHub Pages:** главная страница сайта — каталог уроков.
- **Из сетевой папки (запасной вариант):** скопируйте папку урока целиком и откройте в ней `index.html` в браузере.

## Уроки

| Класс | Урок | Тема | Папка |
| --- | --- | --- | --- |
| 7 | Помощник сломался | Что такое данные. Датасет. Виды датасетов | `7-klass/dataset-pomoshnik/` |
| 9 | Следующая нота | Как нейросеть генерирует музыкальные последовательности | `9-klass/sleduyushchaya-nota/` |

## Как добавить урок

1. Создайте папку `<класс>-klass/<короткое-имя>/` и положите в неё `index.html`.
2. В корневом `index.html` добавьте объект в список `LESSONS` (класс, название, тема, описание, путь к папке).

Служебные возможности приложений (ускоренный прогон, переход по экранам) на сайте не упоминаются — инструкция у учителя.
