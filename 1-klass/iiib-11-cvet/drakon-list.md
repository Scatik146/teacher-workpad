# ДРАКОН-лист: тренажёр «Лаборатория света» (урок «Цвет», 1 класс)

Код — `trenazher.js` (слова `nazhatLampu`, `proveritSvet`, `kapnut`, `proveritPechat`), данные — `tekst.js`. Правило — ii-komanda `pravila/KOD-PO-GRAFOVSKI.md`, п. 4.

## Действия: ребёнок нажал на лампу

```дракон
название: Нажали на лампу
ввод: id лампы
вопрос: Говорун ещё хвалит?
  да:
  нет:
    уровень = (уровень + 1) % 3
    нажатий = нажатий + 1
    показать лампы и круг экрана
    вопрос: лампы как в задании?
      да:
        Говорун хвалит
        Говорун договорил — следующее задание
      нет:
        вопрос: нажатий >= 6 и делится на 3?
          да:
            мигает первая неверная лампа
            вывод: «Сделай ярче / тусклее / выключи»
          нет:
```

## Действия: капля краски в печатном цехе

```дракон
название: Капнули краску
ввод: id краски
вопрос: эта краска уже на бумаге?
  да:
  нет:
    капли = капли + краска
    цвет бумаги = белый × все краски
    вопрос: на бумаге ровно нужные краски?
      да:
        вывод: «Получилось!»
      нет:
        вопрос: красок столько же или больше, чем нужно?
          да:
            ошибок = ошибок + 1
            вывод: «Не то. Смой и попробуй другие»
          нет:
```

## Данные

```конспект
тема: Как считается цвет
связка: Экран | Бумага
начало -> чёрный: 0, 0, 0 | белый: 255, 255, 255
лампа или капля -> прибавляет свет | забирает свет
считаем -> уровень: 0, 128, 255 | умножаем на краску
красный и зелёный -> жёлтый | почти чёрный
```

## Тест

- пример: лампы красная ярко + зелёная ярко → круг rgb(255,255,0), задание «жёлтый» пройдено
- пример: краски голубая + жёлтая → rgb(20,184,20) — зелёный, задание «зелёный» пройдено
- контрпример: краски красная + зелёная → жёлтый (выходит тёмно-бурый rgb(40,29,11))
- контрпример: лампы все ярко → чёрный (выходит белый)
