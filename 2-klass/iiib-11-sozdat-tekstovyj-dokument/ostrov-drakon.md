# ДРАКОН-лист: «Система острова» (приложение ученика)

Урок «Как создать текстовый документ?», ИИИБ, 2 класс. Код — `ostrov.js` (действия), `tekst.js` (данные).
Правило листа — ii-komanda `pravila/KOD-PO-GRAFOVSKI.md`, п. 4.

## Действия: путь ученика (силуэт)

```дракон
название: Система острова
ветка: Рабочий стол
  ввод: Ученик выбирает свой лист: анбур или глаголица
ветка: Расшифровка
  для: каждого слова послания
    пока: Слово не собрано?
      ввод: Ученик нажимает русскую букву
      если: Буква нужная?
        да:
          Буква появляется русской и превращается в древний знак
        нет:
          если: Второй промах подряд?
            да:
              вывод: Говорун: мемослово, клавиши мерцают
            нет:
              вывод: Механизм увернулся — попробуй ещё хитрее
    вывод: Слово собрано — счётчик растёт
  вывод: Письмо друга по-русски
ветка: Микропауза
  вывод: Механизм думает — не подглядывайте
  Глаза отдыхают 90 секунд
ветка: Редактор
  ввод: Открыть редактор
  ввод: Файл → Создать
  пока: Выбран не свой древний шрифт?
    ввод: Ученик выбирает шрифт в списке
  ввод: Ученик выбирает фразу ответа
  Набор фразы, как при расшифровке
  вывод: Отправить через Говоруна
ветка: Квест
  вывод: ХА-ХА-ХА! Я разгадал ваш шифр!
  выбор: Точка 1 — что ответим механизму?
    вариант: а) Новый шифр
      вывод: Реакция «новый шифр» и буква назло
    вариант: б) Не скажем
      вывод: Реакция «молчите» и буква назло
    вариант: в) Не все языки
      вывод: Реакция «знаю все» и буква назло
  Расшифровать «ЖДУ» другим алфавитом
  выбор: Точка 2 — как отправим «ЛЕТИМ»?
    вариант: а) Всё сразу
      Набрать слово, нажать «Отправить»
    вариант: б) По одной букве
      Каждая буква улетает сразу
ветка: Финал
  вывод: Реплика своего пути из PATHS
  Терминал: зелёный → янтарный, 2 секунды
  вывод: ШЛМ справа налево
  вывод: ЯЗЫК… СОЗДАТЕЛЯ… ОТПУСКАЮ.
  вывод: Самолёт улетает
```

## Действия: слово `prinyat` (принять букву)

```дракон
название: prinyat(pole, b)
если: b — нужная буква?
  да:
    pole.nabrano = pole.nabrano + b
    Нарисовать букву: русская → древняя
    если: Слово набрано целиком?
      да:
        pole.gotovo()
      нет:
  нет:
    если: b — пробел?
      да:
        вывод: Механизм увернулся
      нет:
        вывод: Знак уворачивается и улетает
```

## Данные

```конспект
тема: Данные «Системы острова»
опр: S -> Состояние урока: экран, алфавит, шаги редактора и квеста, выбор в точках 1 и 2
опр: POLE -> Поле набора: цель, что набрано, алфавит, куда рисовать
пример: [алфавит]{anbur или glagolica} → [послание]{3–4 слова} → [фраза]{1 из 3} → [путь]{t1,t2}
---
тема: Точки выбора квеста
связка: Точка 1 | Точка 2
Сколько вариантов? -> 3 | 2
Что меняет? -> реакцию механизма | способ отправки
стрелка: 3 × 2 = 6 путей в PATHS, финал общий
```

## Тест

- пример: алфавит anbur, набор «С», «Т», «Р», «А», «Ж» → слово «СТРАЖ» собрано, счёт «Собрано 1 из 3»
- пример: путь `c,b` → реплика «НЕ ВСЕ ЯЗЫКИ… БУКВА ЗА БУКВОЙ… Я ВСПОМИНАЮ…», затем 𐤔𐤋𐤌 и «ОТПУСКАЮ.»
- контрпример: при цели «СТРАЖ» нажата «Ю» → буква не попадает в поле, счёт не растёт
- пример: при цели «СТРАЖ» дважды нажата «Ю» → Говорун: «…в слове ЧЮБС — нижний ряд», мерцают Ч, Ю, Б, С
- контрпример: в редакторе выбран шрифт Arial → шаг «фраза» не открывается

## Пополнение словаря

Нижний слой: `el`, `sozdat`, `pokazat`, `novoeSostoyanie`, `sohranit`, `zagruzit`, `zhdat` — элементы, хранение, таймеры; `znak`, `zapisat`, `drugoj`, `bukvaNazhatiya` — буквы.
Средний слой:
- `skazat`, `schet`, `vzmah` — Говорун (из `el`);
- `pechatat`, `pechatatStroki`, `pechatatSnomera` — терминал (из `zhdat`);
- `klavisha`, `klaviatura`, `podsvetit`, `zazhech` — экранная клавиатура, только показывает нажатое (из `sozdat`, `znak`);
- `novoePole`, `narisovatBukvu`, `uvernulsya`, `prinyat`, `nazhatie` — поле набора (из `znak`, `skazat`, `podsvetit`);
- `memoslovo`, `mercat`, `podskazka` — подсказка Говоруна мемословами ЙЦУКЕН, ФЫВА, МИТЬЯ… после двух промахов (из `skazat`, `vzmah`).

- `vojtiPauzu`, `tikPauzy`;
- `vojtiRedaktor`, `obnovitRedaktor`, `shagRedaktora`, `vybratShrift`, `spisokShriftov`, `knopkiFraz`, `nachatNabor`, `obrazecFrazy`, `frazaUchenika`, `otpravit`;
- `vojtiKvest`, `obnovitKvest`, `shagKvesta`, `strokiHahaha`, `strokaNazlo`, `knopkiVybora`, `tochka1`, `nachatPoslanieKvesta`, `gotovoePoslanieKvesta`, `prodolzhitKvest`, `tochka2`, `nachatOtvet`, `otvetNabran`, `uletet`, `otpravitOtvet`;
- `vojtiFinal`, `finalYantar`, `finalShlm`, `finalOtpuskayu`, `pechatatFinikijskoe`, `drugUletaet`, `klyuchPuti`.
Верхний слой: `perejti`, `menyuEkranov` (из `spisokEkranov`, `tekushchijEkran`, `ekranProjden`), `knopki`, `zapusk`.
