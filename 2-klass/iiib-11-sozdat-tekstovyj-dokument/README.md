## Решения автора

- Каждый ребёнок идёт своим маршрутом, ноутбуки не связаны; учитель раздаёт листы: анбур или глаголица.
- Расшифровка — набором на клавиатуре: русская буква превращается в древний знак; экранная клавиатура только показывает нажатое.
- По 3 слова на алфавит (анбур — «СТРАЖ ДЕРЖИТ МЕНЯ», глаголица — «ПИШИ ОТВЕТ ШИФРОМ»).
- Подсказка после двух промахов подряд: Говорун называет мемослово (ЙЦУКЕН, ГШЩЗХЪ, ФЫВА, ПРОЛ, ДЖЭ, МИТЬЯ, ЧЮБС), его клавиши мерцают.
- Анбур — таблица календаря Scatik146/komi-perm-game-calendar (Лыткин, 1952), русский режим: о — омегой.
- Глаголица — Unicode и таблица azbyka.ru; Э, Й, Я — условно (Ⰵ, Ⰻ, Ⱑ).
- Конец квеста: механизм читает «ЛЕТИМ» → друг просит написать «Я ДРУГ» финикийскими буквами → механизм узнаёт язык создателя и просит главное слово → Говорун подсказывает ШЛМ («шалом», мир и привет) → ребёнок набирает ШЛМ. Набор — слева направо; финикийское соответствие русских букв — условное, по названиям букв.
- Финал — механизм перечитывает 𐤔𐤋𐤌 справа налево, как его создатель (только на финальном экране): «ШЛМ — МИР. И ТЕБЕ МИР, ДРУГ МОЕГО СОЗДАТЕЛЯ. ОТПУСКАЮ.»
- Раздатка — по всему русскому алфавиту (33 буквы), соответствие — из приложения; два варианта листа (22.11, сессия 2).
- Шрифты — `lib/fonts/noto-sans-old-permic`, `noto-sans-glagolitic`, `noto-sans-phoenician` (OFL).
