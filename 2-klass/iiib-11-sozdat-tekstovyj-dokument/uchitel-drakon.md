# ДРАКОН-лист: приложение учителя и печатные листы

Урок «Как создать текстовый документ?», ИИИБ, 2 класс. Код — `uchitel.js` (доска), `listy.js` (печатные листы), данные — `tekst.js`.
Правило листа — ii-komanda `pravila/KOD-PO-GRAFOVSKI.md`, п. 4.

## Действия: доска (силуэт)

```дракон
название: Приложение учителя
ветка: Титул
  вывод: Тема, курс, сегодняшняя дата
  ввод: Учитель нажимает «Начать урок»
ветка: Сбой
  вывод: СБОЙ СИСТЕМЫ — дрожание и полосы
  Пауза 2 секунды
ветка: Терминал
  вывод: Чёрный экран, квадратный курсор
  ввод: Учитель нажимает «ПЕЧАТЬ»
  для: каждой строки: страж, друг, «подключайтесь»
    для: каждой буквы строки
      вывод: Буква и стук клавиши, если звук включён
    вывод: Звоночек каретки
  ввод: «СБРОС» — снова титул
```

## Действия: слово `pechatatBukvy` (печатать буквы)

```дракон
название: pechatatBukvy(stroka, tekst, i, pokolenie, gotovo)
если: pokolenie === S.pokolenie && i < tekst.length?
  да:
    вывод: Буква tekst[i] перед курсором
    если: tekst[i] !== ' '?
      да:
        stuk()
      нет:
    Через SKOROST.bukva — pechatatBukvy(i + 1)
  нет:
если: pokolenie === S.pokolenie && i >= tekst.length?
  да:
    zvonok()
    gotovo()
  нет:
```

## Действия: печатный лист (силуэт)

```дракон
название: Печатный лист
ветка: Какой лист
  ввод: body data-list
  выбор: Вид листа
    вариант: shpargalka
      вывод: Реплики терминала и правила клавиатуры из tekst.js
    вариант: razdatka
      для: каждого варианта: анбур, глаголица
        вывод: Лицо: свой алфавит, алфавит друга, финикийский
        вывод: Оборот: карта клавиатуры, мемослова, правила
    вариант: vkleyka
      для: двух копий
        вывод: Конспект «Как мы спасали друга» и «мой путь»
```

## Данные

```конспект
тема: Данные приложения учителя
опр: S -> Состояние доски: сцена, звук, поколение печати, звуковой движок
опр: SKOROST -> Скорость: буква, пауза между строками, длина сбоя
пример: [титул]{Начать урок} → [сбой]{2 секунды} → [терминал]{ПЕЧАТЬ}
опр: VARIANTY -> Порядок алфавитов на листе: свой, потом друга
опр: LATINICA -> Латинская буква на той же клавише
---
тема: Два варианта раздатки
связка: Анбур | Глаголица
Первая таблица -> анбур | глаголица
Вторая таблица -> глаголица | анбур
Третья таблица -> финикийский | финикийский
```

## Тест

- пример: «Начать урок» → через 2 с сцена `terminal`; «ПЕЧАТЬ» → в терминале три строки, последняя «ПОМОЩНИКИ, ПОДКЛЮЧАЙТЕСЬ К СИСТЕМЕ ОСТРОВА!»
- пример: «СБРОС» во время печати → сцена `titul`, печать остановлена
- контрпример: звук выключен → `stuk()` и `zvonok()` молчат, печать идёт
- пример: финикийский знак 𐤅 на листе → клавиши «В, У»
- контрпример: финикийский тет 𐤈 → клавиши нет, клетка серая
- пример: русская «а» на карте клавиатуры → латинская F, мемослово 3 ФЫВА
