# ДРАКОН-лист: испытания «Сосед» и «Середины» (raschet.js)

```дракон
название: Эталон клетки «Середины»
ввод: i, j
summa = 0, chislo = 0
для: Для каждой старой строки a из os(i)
  для: Для каждого старого столбца b из os(j)
    summa = summa + ishodnik[a][b]
    chislo = chislo + 1
вывод: summa / chislo
```

```конспект
тема: Что считает os(i)?
класс: 8
Чётное i? -> одна старая строка i / 2 — копия
Нечётное i? -> две старые строки — середина между ними
```

пример: etalonSerediny(0, 0) = 8; etalonSerediny(1, 1) = 7; etalonSerediny(2, 4) = 0; etalonSosed(5, 2) = 0
контрпример: etalonSerediny(1, 1) = 8 (это была бы копия, а клетка — среднее четырёх)
