2. Коммит

Снимок состояния файлов в момент времени
  • Автор — кто сделал
  • Дата — когда
  • Сообщение — пишет человек для человека и для себя-через-полгода

step-1: подготовка данных ✓ понятно

изменения ✗ не понятно

Конвенция: step-N: что сделал · fix: что исправил

3. Ветка

Параллельная линия разработки

Аналогия: альтернативная реальность — можно экспериментировать, не ломая основную версию.

В отличие от фантастики, реальности Git можно соединить обратно — это и есть merge.

  • main — основная ветка, проверенные работы
  • Личная ветка — твоё пространство (личное, но видимое другим)

Команды и сервисы

Pull Request — не команда Git

Pull Request (PR)

Механизм сервиса GitHub — не команда Git.

«Я закончил работу в своей ветке, посмотрите и примите.»

PR — интерфейс для ревью: учитель или одноклассник читает код, оставляет комментарии, одобряет или просит исправить.

Сервисы: GitHub · GitLab · GitFlic (российский)
