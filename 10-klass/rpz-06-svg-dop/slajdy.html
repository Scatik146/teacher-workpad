От одного отрезка к ломаным и фигурам

<line>

Только 1 отрезок (2 точки).

<line x1="10" y1="20"
      x2="100" y2="20" />

<polyline>

Ломаная из множества последовательных отрезков.

<polyline
  points="10,20 50,80 90,20"
  fill="none" />

<polygon>

Ломаная + автозамыкание + заливка.

<polygon
  points="10,20 50,80 90,20"
  fill="rgba(0,100,255,0.3)" />
💡 rgba(R, G, B, A) — цвет с прозрачностью. A от 0.0 (невидимый) до 1.0 (непрозрачный).
Лайфхак: открой Яндекс → «rgba конвертер» → выбери цвет → скопируй готовую строку.

Плавные графики: тег <path> и команда Q

Команды маршрута в атрибуте d

  • M x y — перенести перо (начало)
  • L x y — провести прямую
  • Q cx cy x y — квадратичная кривая Безье

Почему именно Q?
Парабола математически является квадратичной кривой. Это не аппроксимация — это идеальная точность.

Алгоритм контрольной точки

Для симметричной дуги параболы:

  1. Найди вершину (xᵥ, yᵥ). Твоя cx = xᵥ.
  2. Вычисли Δy = y_концевая − yᵥ.
  3. Контрольная точка cy = yᵥ − Δy (в противоположную сторону).
Блок 1 · Этап 2 · пример

Пример: y = x² − 4x + 3

1. Находим вершину

xᵥ = −b/(2a) = 4/2 = 2
yᵥ = 2² − 4·2 + 3 = −1

2. Концевые точки (симметричные)

x = 0 → y = 3 → точка A(0, 3)
x = 4 → y = 3 → точка Б(4, 3)

3. Контрольная точка

cx = 2
Δy = 3 − (−1) = 4
cy = −1 − 4 = −5

4. Перевод в экранные координаты

Параметры: S=30, CX=150, CY=200

A: sx = 150 + 0·30 = 150, sy = 200 − 3·30 = 110
Б: sx = 150 + 4·30 = 270, sy = 200 − 3·30 = 110
Q: cx = 150 + 2·30 = 210, cy = 200 − (−5)·30 = 350

5. Итоговый тег

<path
  d="M 150 110 Q 210 350 270 110"
  fill="none"
  stroke="red"
  stroke-width="3" />

Многоразовые стрелки: <defs> и <marker>

1. Описываем штамп один раз

<defs>
  <marker id="arrow"
    viewBox="0 0 10 10"
    refX="9" refY="5"
    markerWidth="6"
    markerHeight="6"
    orient="auto">
    <path d="M 0 0 L 10 5 L 0 10 z"
          fill="black"/>
  </marker>
</defs>

Расшифровка атрибутов

  • viewBox — внутренний холст стрелки
  • refX, refY — точка привязки («булавка»)
  • orient="auto" — автоповорот по углу линии

2. Применяем к любой линии

<line x1="..." y1="..."
      x2="..." y2="..."
      marker-end="url(#arrow)" />

Скрытые угрозы в чужом SVG

StackEdit вырезает <script>, но есть другие лазейки:

⚠️ Угроза 1: Утечка данных 
<use href="http://evil.com/track.svg"/>

Браузер тихо загружает файл с чужого сервера → владелец сайта получает ваш IP и факт просмотра.

⚠️ Угроза 2: DoS-атака 
<animate attributeName="opacity"
  dur="0.01s" repeatCount="indefinite"/>

Бесконечная перерисовка → 100% CPU → вкладка зависает (без JavaScript!).

✅ Правило: перед вставкой чужого SVG удаляй теги <use>, <image>, <animate>, <set>.

Практикум: расчёт перед кодом

📋 Алгоритм работы

  1. Выбери одну из трёх карточек (математика или физика).
  2. Реши задачу аналитически на бумаге.
  3. Заполни таблицу перевода в экранные координаты.
  4. Только после этого открывай StackEdit.
Формулы перевода:
sx = CX + x · S
sy = CY − y · S    (помни: Y в SVG направлен ВНИЗ!)
⏱️ Внимание: первые 10 минут вы не трогаете клавиатуру. Работа с бумагой и калькулятором. Если начнёте писать код без расчётов — увязнете в подборе чисел.

Чек-лист сборки SVG-модели

  • Оси координат на месте, серые, с подписями
  • Единичный отрезок с подписью «1»
  • Графики/векторы через рассчитанные sx, sy
  • polygon с fill="rgba(..., 0.3)" для площади
  • marker-end для стрелок (если есть векторы)
  • Код чистый: нет внешних ссылок, <animate>

🎨 Принцип минимализма

  • Оси — тонкие и серые (stroke="gray")
  • Графики — яркие и толстые (stroke-width="3")
  • Шрифт — читаемый, без лишних подписей
  • Заливка — полупрозрачная, не перекрывает текст

Peer-review: проверь соседа

🔄 Алгоритм взаимопроверки

  1. Поменяйтесь местами за компьютером.
  2. Откройте карточку с аналитическим решением соседа.
  3. Сверьте 2–3 ключевые точки на графике с его расчётами в таблице.
  4. Проверьте код по чек-листу на экране.
  5. Оставьте устный комментарий: «Что сделано круто» и «Что можно упростить».
💡 Совет: выберите любую точку (конец вектора, вершину параболы) и подставьте математические x и y в формулы sx и sy. Совпало с кодом? → плюс. Нет? → укажите на ошибку.
