# ДРАКОН-лист: когда следующее полнолуние (РПЗ-13, 10 кл.)

Код урока — первая программа на Python (одно слово, без функций: функции у класса позже). Порядок действий — блок `дракон`, данные — блок `конспект`, тест — `пример:` и `контрпример:`. Правило — ii-komanda `pravila/KOD-PO-GRAFOVSKI.md`, п. 4.

## Действия

```дракон
название: Следующее полнолуние
import math
ввод: chas
ввод: minuta
ввод: k
S = 29.530589
t = chas + minuta / 60 + k * S * 24
dni = math.floor(t / 24)
ostatok = t - dni * 24
chasy = math.floor(ostatok)
minuty = math.floor((ostatok - chasy) * 60)
вывод: dni, chasy, minuty
```

## Данные

```конспект
тема: Переменные программы «Полнолуние»
связка: Тип | Что хранит | Пример
chas -> int | час полнолуния 24.11 | 17
minuta -> int | минуты | 53
k -> int | через сколько месяцев | 1
S -> float | синодический месяц, сутки | 29.530589
t -> float | часы от 0:00 24 ноября | 726.6175
dni -> int | целых суток после 24.11 | 30
```

## Тест

- пример: ввод 17, 53, 1 → вывод 30, 6, 37 (24 декабря, 6:37 МСК по модели)
- контрпример: ввод 17, 53, 1 → вывод 30, 4, 28 (так в календаре; модель среднего месяца даёт ошибку ≈ 2 ч)
