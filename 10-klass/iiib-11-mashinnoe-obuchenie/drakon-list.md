# ДРАКОН-лист к приложению «Как нейрон учится»

Код — `prilozhenie.js` (слова по-фортовски), слова нейрона — `lib/nejron/nejron.js`, данные — `tekst.js`. Ниже — главное слово экрана 2: ход ученика при обучении.

```дракон
название: Ход ученика на экране 2
ввод: Ответ ученика
вопрос: Ждём S?
  да:
    вопрос: S равна сумме весов закрашенных клеток?
      да:
        Ждать выход
      нет:
        Подсказать, как считать S
  нет:
    вопрос: Ждём выход?
      да:
        вопрос: Выход совпал с выходом нейрона?
          да:
            Перемешать поправки и ждать выбор
          нет:
            Подсказать правило порога
      нет:
        вопрос: Поправка совпала с правилом Розенблатта?
          да:
            Поправить веса, дописать журнал, перейти к следующему примеру
          нет:
            Подсказать сравнить выход с нужным ответом
Сохранить и перерисовать экран
вывод: Экран «Обучение»
```

```конспект
тема: Как устроен экран «Обучение»?
класс: 10
Откуда пример? -> Из обучающей выборки tekst.js: C₁ → 1, T → 0.
Кто считает правильный ответ? -> Слова Nejron.summaS, Nejron.vyhod, Nejron.shag.
Когда обучение кончается? -> После круга без ошибок.
```

пример: C₁, веса 0, порог 0 → ученик вводит S = 0, выход 1, «ответ верный» — в журнале строка, следующий пример T
контрпример: ученик вводит S = 7 при весах 0 → шаг не меняется, подсказка про закрашенные клетки
