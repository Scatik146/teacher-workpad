# Правила работы с сайтом teacher-workpad

Сайт уроков учителя (GitHub Pages). Тексты, интерфейсы и коммиты — на русском.

## Команда ИИ

- Вход для помощников (Qwen, GLM, DeepSeek, Алиса и др.) — `docs/komanda/README.md`; копии навыков Claude — `docs/komanda/navyki/`. Если меняются правила или навык — обновить и копию.

## Приложения уроков

- Папка урока: `<класс>-klass/<имя>/` (урок для нескольких предметов — `obshchie/<имя>/`); приложение — `index.html`, рядом можно класть другие файлы (тексты, картинки). Один большой файл не обязателен.
- Каждое приложение — со скрытым меню перехода по экранам **Ctrl+Alt+M** (с заполнением данных по умолчанию для пропущенных экранов). На сайте и в материалах для учеников это меню не упоминать.
- Прогресс — в `localStorage` (обёрнуто в try/catch), на заставке — кнопка «Новая смена / начать заново» для следующей пары.
- Работает без интернета (сетевая папка): никаких CDN, всё по относительным путям внутри сайта.
- Материалы учителя (канва, слайды, раздатки) — HTML-страницы в папке урока, в стиле `*/kanva.html`; .pptx и .docx переводим в HTML. Тексты, общие для игры и канвы, держать в одном файле (пример: `5-klass/ekho-uzel/tekst.js`).

## Каталог

- Новый урок — объект в `LESSONS` в `lessons.js` (поля описаны в начале файла) и строка в таблице `README.md`.
- После изменений обновить `RAZRABOTANO.md` и `DORABOTKI.md`. Их копии ведутся в проекте Claude «Разработка уроков» (`claude/Разработано teacher-workpad.md`, `claude/Доработки teacher-workpad.md`) — держать одинаковыми.

## Графические конспекты (ДРАКОН-ГРАФ)

- Библиотека: `lib/drakon-graf/` (см. её README). Подключение из урока:
  `<script src="../../lib/drakon-graf/drakon-graf.min.js"></script><script src="../../lib/drakon-graf/konspekt.js"></script>`,
  затем `Konspekt.draw(el, текст, {class: N})`.
- Язык для 5–6 классов: `тема:`, `пример: [часть]{подпись} → …`, `вопрос -> ответ`, `- пункт`; для сравнения — `связка: А | Б` + строки `признак -> а | б`. Справочник — в репозитории Scatik146/drakon-graf (`docs/graf/шпаргалка_ученика.md`).
- Конспект в коде помечать `/*конспект*/` перед строкой-шаблоном и проверять: `node tools/konspekt.mjs --scan путь/к/файлу --class N` (без подсказок «важно»). Рисунок для просмотра: `node tools/konspekt.mjs файл.txt -o рисунок.svg`.
- Авторство (Паронджанов, Гуленков, Веснин) не удалять: оно в `lib/drakon-graf/NOTICE` и в шапке `konspekt.js`.

## Дракон-схемы (DrakonWidget)

- Виджет Степана Митькина: `lib/drakonwidget/drakonwidget.js` (1.5.7, Unlicense) — **не менять**. Обёртка: `lib/drakon-shema/drakon-shema.js`. Подключение из урока:
  `<script src="../../lib/drakonwidget/drakonwidget.js"></script><script src="../../lib/drakon-shema/drakon-shema.js"></script>`
- Вставка: `DrakonShema.pokazat(el, shema)` — просмотр (рамка сама по высоте схемы, широкая схема ужимается по ширине, не мельче 75 %);
  `DrakonShema.pokazat(el, zagotovka, {rezhim:'sborka', klyuch:'урок-схема-1', razreshit:[…], izmenenie: sh => …})` — ученик дописывает, схема сохраняется.
  Объект: `poluchit()` (короткий формат), `json()` (родной), `ochistit()`.
- Короткий формат: `{ nazvanie, shagi:[ 'Действие', {vopros, da:[…], net:[…]}, {vybor, varianty:{'А':[…],'Б':[…]}}, {vvod:'…'}, {vyvod:'…'}, {kommentarij:'…'} ] }`;
  силуэт — `{ nazvanie, vetki:[ {imya, shagi:[…]}, … ] }`. Пустой блок заготовки — `''` или `'…'`. Кнопки сборки (`razreshit`): `dejstvie, vopros, vybor, vvod, vyvod, cikl, vetka, kommentarij`.
- Циклы: ДЛЯ — по канону Паронджанова: всё о цикле в верхней крышке — `{dlya:'Для k от 1 до 10', shagi:[…]}` (также `'Для каждого ученика в списке класса'`, `'for x in range(n)'`, `'i = 0; i < n; i++'`); нижнюю крышку программа пишет сама — «Конец цикла k» (свой текст — `niz:'…'`; старое `po` приклеивается к верхней); while — `{poka:'Есть …?', shagi:[…]}` (Да — тело справа и назад к стрелке, Нет — выход вниз);
  do-while — `{delat:[…], poka:'… неверный?'}` (тело, потом вопрос: Да — снова, Нет — дальше). Кнопка сборки `cikl` вставляет только for (после верхней крышки нижняя заполняется сама);
  циклы «пока» давать в заготовке (виджет вставляет их перетаскиванием линий — школьнику неудобно). Тело цикла по главной линии вниз виджет не рисует — так и задумано в ДРАКОНе.
- Переходы — последним шагом ветки вопроса или варианта: `{vyhod:true}` — «выход из цикла» (break: линия в точку сразу после цикла), `{dalshe:true}` — «к следующему шагу» (continue: к концу тела цикла), `{konec:true}` — «конец» (только в примитиве). Слова return не вводим: в Python оно значит другое.
- Псевдокод и маршруты — библиотека Митькина `lib/drakongen/` (public domain, см. её README): подключить `drakongen.js` (и `ai-ast.js` для ИИ-формата) **до** `drakon-shema.js`; `DrakonShema.pokazat(el, shema, {knopki:true})` — кнопки «Псевдокод» и «Маршруты» под схемой; `DrakonShema.psevdokod(shema)`, `DrakonShema.marshruty(shema)`.
- Кнопка «Код» (входит в `knopki:true`; язык по умолчанию — `yazykKoda`): Python и КуМир — свои генераторы в стиле ОГЭ, C и 1С — `lib/drakongen/drakontechgen.js`. Текст в блоках пишется на целевом языке (схема — только порядок, развилки, циклы); заголовок цикла переводится сам («для i от 1 до n» ↔ `for i in range(1, n + 1)`), «использовать Робот» уходит в начало файла. Проверка: `node tools/drakon-kod-test.mjs`. Числовые варианты выбора ('4', '5') JavaScript сортирует по возрастанию — порядок задавайте так же. `pokazat` принимает и ИИ-формат DrakonHub (`{name, stages:[…]}`), и родной (`{items}`).
- Текст в иконах — по центру. Вид как у ДРАКОН-ГРАФ: шрифты PT Serif / PT Mono из `lib/drakon-graf/fonts` (обёртка ждёт их загрузки), обводка `#993300`, жёлтое `#FFFF99` — заголовок, конец, ветки, комментарии.
  Для уроков программирования — `{kod:true}`: блоки шрифтом PT Mono. Нужна папка `lib/drakon-graf` рядом (она уже на сайте).
- Ввод — блок со стрелкой-вырезом слева, вывод — с треугольником справа (`simpleinput` / `simpleoutput` виджета).
- В коде помечать `/*схема*/` (просмотр) или `/*заготовка*/` (сборка) перед объектом и проверять: `node tools/drakon-shema.mjs --scan путь/к/файлу`.
- Когда что брать: **дракон-схема** — алгоритм, порядок действий, ветвления, «что делать, если…»; **конспект ДРАКОН-ГРАФ** — главные мысли урока для тетради (понятия, правила, сравнения).
- Проба: `lib/drakon-shema/index.html`. Родной формат виджета (для справки): `items` — словарь id → `{type, content, one, two, branchId, flag1}`; у `question` `one` — «Да» (вниз), `two` — «Нет» (вправо), `flag1:1`; `select.one` → первый `case`, `case.two` → следующий `case`; в силуэте хвост ветки указывает на id следующей `branch`;
  for — `loopbegin` → тело → `loopend`; while/do-while — узел `arrow-loop`, к нему возвращается правая ветка вопроса (`two`), `flag1:0` — вниз «Нет».
