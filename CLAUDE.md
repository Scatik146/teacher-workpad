# Правила работы с сайтом teacher-workpad

Сайт уроков учителя (GitHub Pages). Тексты, интерфейсы и коммиты — на русском.

## Команда ИИ

- Вход для помощников (Qwen, GLM, DeepSeek, Алиса и др.) — `ii-komanda/komanda/VHOD-UROKI.md`; копии навыков Claude — `ii-komanda/rezerv/navyki/`. Если меняются правила или навык — обновить и копию.

## Код

- **Перед новым кодом урока — `lib/slova/SLOVA.md`:** готовое слово берём, а не пишем заново (ОЧ-10 «одно знание — одно место»); шаблон запуска — `Slova.zapustitPrilozhenie`, Говорун — `lib/slova/govorun.js`. Новое слово — только если готовое не подходит, с объяснением в отчёте.
- Весь новый и изменяемый код (JS, Python и другие языки, кроме Prolog) — «по-фортовски»: `ii-komanda/pravila/KOD-PO-FORTOVSKI.md`. В конце работы — «пополнение словаря».
- Prolog — «по-прологовски» (как описать): `ii-komanda/pravila/KOD-PO-PROLOGOVSKI.md`, и «по-графовски» (как нарисовать: каждое отношение — в ДРАКОН-ГРАФ): `ii-komanda/pravila/KOD-PO-GRAFOVSKI.md`. HTML и CSS — раздел в `KOD-PO-PROLOGOVSKI.md`.
- К коду сдаётся ДРАКОН-лист — Markdown с блоками ```` ```дракон ```` и ```` ```конспект ```` и тестом (`KOD-PO-GRAFOVSKI.md`, п. 4; образец — `ii-komanda/pravila/primery/drakon-list-evklid.md`); проверка: `node tools/drakon-list.mjs лист.md` (`--kod python` — код по блокам «дракон»). Всё вместе — навык `ii-komanda/rezerv/navyki/tri-stilya-koda/SKILL.md`.

## Приложения уроков

- **Перед созданием или правкой приложения урока — прочитать `PRAVILA-PRILOZHENIJ.md`** (один раз за сессию): папка, меню Ctrl+Alt+M, шрифты, резерв для быстрых, прогресс, офлайн, материалы учителя.
- Поурочное планирование — `plan/` (файл на курс, разделы по классам); строка плана ссылается на папку урока и несёт флаг ✅ / ✏️ / 📝. Уроки из черновиков называть `<предмет>-<NN>-<тема-латиницей>` (`iiib`, `inf`, `trud`, `prog`, `rpz` — «Решение практических задач»; NN — номер в плане), паспорт урока — `README.md` в папке. Разбор черновиков — `chernoviki/OPIS.md`. Рабочие программы курсов — `rabochie-programmy/`.

## Каталог

- Новый урок — объект в `LESSONS` в `lessons.js` (поля описаны в начале файла) и строка в таблице `README.md`. Предметы (`SUBJECTS`): `iiib`, `inf`, `mat`, `trud`, `rpz`. Черновые уроки (✏️, 📝) в каталог не заводить — они в `plan/`.
- После изменений обновить `RAZRABOTANO.md` и `DORABOTKI.md`. Их копии ведутся в проекте Claude «Разработка уроков» (`claude/Разработано teacher-workpad.md`, `claude/Доработки teacher-workpad.md`) — держать одинаковыми. **Копию в проект записывать один раз — в конце задачи**, а не после каждой правки (решение учителя 25.11: экономия лимита).

## Графические конспекты и дракон-схемы

Правила, встраивание и проверка — навыки `graficheskij-konspekt` (ДРАКОН-ГРАФ, `lib/drakon-graf/`) и `drakon-shema` (DrakonWidget, `lib/drakon-shema/`). Открывать навык, только когда урок их использует (решение учителя 25.11, экономия лимита: разделы здесь повторяли навыки).

## Проверка перед отправкой

- **Одна команда проверки** (учитель 25.11 02:55): `python3 -I tools/proverka-vsyo.py <папка урока> --kartinka svodka.png` — страницы (`proverka-uroka.py`), ДРАКОН-листы, схемы, конспекты, стиль кода, тесты библиотеки ДРАКОН при её правке, git; строка на проверку, подробности — в `/tmp/proverka-vsyo/`. Запускать **один раз после последней правки**, не после каждой; сводную картинку смотреть целиком один раз.
- **Что дешевле проверить человеком и человек доступен — проверяет человек** (учитель 25.11 02:55): экраны приложения дальше первого, все щелчки и проба путём пользователя — учитель при приёмке; ему — список экранов, действий и что должно получиться. Свой проход playwright (headless Chrome `/usr/bin/google-chrome`, 1366×768) — только если учителя нет.
- Большие файлы править `Edit` по частям, не переписывать целиком `Write`: каждая копия остаётся в разговоре и перечитывается на каждом следующем запросе.
- «Беды: нет» в отчёте проверки ещё не значит «готово»: пустые рамки, обрезанные схемы и лишние страницы программа не видит — сводную картинку смотрит учитель при приёмке; адреса с `#` программа берёт из таблицы `README.md` урока.
