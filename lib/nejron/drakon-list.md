# ДРАКОН-лист к lib/nejron/nejron.js

```дракон
название: Шаг нейрона (shag)
ввод: Пример с разметкой, веса, порог
Посчитать S — сумму весов закрашенных клеток
вопрос: S не меньше порога?
  да:
    Выход 1
  нет:
    Выход 0
вопрос: Выход совпал с разметкой?
  да:
    Веса не трогать
  нет:
    вопрос: Нужен был 1?
      да:
        Прибавить 1 к весам клеток с 1, порог уменьшить на 1
      нет:
        Вычесть 1 из весов клеток с 1, порог увеличить на 1
вывод: Строка журнала и новые веса
```

```конспект
тема: Формальный нейрон в lib/nejron
пример: [входы]{9 клеток} → [веса]{важность клетки} → [сумма S]{вход × вес} → [порог]{S ≥ порога?} → [выход]{1 или 0}
Нужен 1, вышел 0? -> +1 к весам клеток с 1, порог −1
Нужен 0, вышел 1? -> −1 к весам клеток с 1, порог +1
```
