# Меню экранов (Ctrl+Alt+M)

Общий модуль скрытого служебного меню учителя: переход на любой экран урока, данные по умолчанию для пропущенных экранов, служебные кнопки (часы, печать, сброс). Запасной вход — 3 быстрых клика в правый верхний угол. На сайте и в материалах для учеников меню не упоминать.

Подключение из урока и описание полей — в шапке `menu-ekranov.js`. Проба — `index.html` в этой папке.

Когда ставить: при переводе урока в каталог `lessons.js` (решение учителя 14.11). Уроки, где меню уже написано своё, переводить на модуль не обязательно — только при их доработке.

Проверка: открыть урок, Ctrl+Alt+M, перейти на последний экран, не проходя предыдущие, — экран должен открыться с данными по умолчанию, без ошибок в консоли.
