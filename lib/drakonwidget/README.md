# DrakonWidget

Виджет для рисования и правки дракон-схем в браузере.

- Автор: **Степан Митькин**, https://github.com/stepan-mitkin/drakonwidget
- Версия файла: **1.5.7** (`createDrakonWidget().getVersion()`)
- Лицензия: **Unlicense** — общественное достояние, можно использовать и распространять без ограничений.

Файл `drakonwidget.js` лежит здесь без изменений. Его не правим: обновление — заменить файл новой версией автора и пройти пробную страницу `lib/drakon-shema/index.html`.

В уроках виджет напрямую не используется — только через обёртку `lib/drakon-shema/drakon-shema.js` (русские надписи, окно ввода текста, меню, сохранение, короткий формат схемы).
